# Decision Request: F40
**Type:** feature_start
**Feature:** Desafio do Dia (Daily Challenge) — sistema de seed diaria deterministica para gerar o mesmo mapa para todos os jogadores no dia. Jogador tem 1 tentativa por dia, com leaderboard filtrado por dia. Requer: novo parametro baseSeed no ChunkGenerator, campos mode/seed no Score (Prisma migration), endpoints backend para checar elegibilidade e leaderboard diario, botao DESAFIO DO DIA no menu, tela de resultado pos-game over com ranking do dia.
**Requested at:** 2026-09-30T18:03:00Z
**Pipeline:** plan-feature (Architect only, PLAN_ONLY mode)

## Decisions pendentes

1. **Seed hash function**: usar hash numerico simples de YYYYMMDD (e.g. somar char codes * prime). Nao precisa ser criptografico, so precisa ser deterministica e dar numeros bem distribuidos.

2. **Prisma mode field**: usar String com default "infinite" (nao enum nativo do Postgres) para simplicidade. Valores possiveis: "infinite", "daily", "level".

3. **1 attempt per day**: verificar via backend (GET /api/daily/can-play?playerId=X). Checar se existe Score com mode="daily" e seed=dailySeed para o playerId. Se existir, nao deixa jogar. Frontend desabilita botao se nao pode jogar.

4. **Daily leaderboard**: GET /api/daily/leaderboard?date=YYYY-MM-DD. Filtra scores por mode="daily" e seed que corresponde a data.

5. **Backward compatibility**: generateChunk recebe baseSeed=0 por default, mantendo seed formula identica ao comportamento atual (chunkIndex * 7919 + 31 + 0).
