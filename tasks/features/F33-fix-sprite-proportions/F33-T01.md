# Task F33-T01 — SpriteAnimator: carregar manifest e expor aspect ratio por frame

**Feature:** F33
**Wave:** 0
**Type:** frontend (game system)
**Depends on:** (none)
**Status:** planned

## User Story

As a developer, I need SpriteAnimator to load the sprite manifest at startup and
expose a per-frame aspect ratio function, so that Mel's mesh scale can be
dynamically adjusted to match each sprite's true dimensions.

## Objective

Modificar `SpriteAnimator.ts` para:
1. Carregar `manifest.json` via fetch durante `loadSprites()`
2. Armazenar o manifest em variavel module-level
3. Exportar funcao `getFrameAspectRatio(animName, elapsed)` que retorna o
   aspect ratio correto (`sourceSize[0] / sourceSize[1]`) do frame atual

### 2. Carregar manifest.json em loadSprites()

Modificar a funcao `loadSprites()` (linha 209) para tambem fazer fetch do
manifest. O fetch roda em paralelo com o carregamento das texturas.

```ts
export function loadSprites(): Promise<void> {
  const names = getAllSpriteNames();
  const missing: string[] = [];

  // Load manifest in parallel with textures
  const manifestPromise = fetch(`${SPRITE_BASE_PATH}manifest.json`)
    .then((res) => res.json())
    .then((data: SpriteManifest) => {
      spriteManifest = data;
    })
    .catch((err) => {
      console.warn("[SpriteAnimator] Failed to load manifest.json:", err);
    });

  const texturePromises = names.map((name) => {
    return new Promise<void>((resolve) => {
      const url = `${SPRITE_BASE_PATH}${name}.png`;
      loader.load(
        url,
        (texture) => {
          configureTexture(texture);
          textureCache.set(name, texture);
          resolve();
        },
        undefined,
        () => {
          missing.push(name);
          resolve();
        }
      );
    });
  });

  return Promise.all([manifestPromise, ...texturePromises]).then(() => {
    // Ensure fallback is available for any missing sprites
    const fallback = textureCache.get(FALLBACK_SPRITE);
    if (fallback) {
      for (const name of names) {
        if (!textureCache.has(name)) {
          textureCache.set(name, fallback);
        }
      }
    }
    if (missing.length > 0) {
      console.warn(
        `[SpriteAnimator] ${missing.length} sprites not found, using fallback: ${missing.join(", ")}`
      );
    }
  });
}
```

### 3. Exportar getFrameAspectRatio()

Adicionar apos a funcao `getFrameEvent()` (apos linha ~351):

```ts
/**
 * Get the aspect ratio (width / height) of the current frame's sprite
 * based on the manifest sourceSize data.
 *
 * Returns the ratio for the current frame, or a fallback of 1.0 if
 * the manifest is not loaded or the sprite is not found.
 *
 * @param animName - The animation name (e.g. "walk", "attack")
 * @param elapsed  - Seconds elapsed since the animation started
 * @returns width/height ratio for the current frame
 */
export function getFrameAspectRatio(
  animName: string,
  elapsed: number
): number {
  if (!spriteManifest) return 1.0;

  const anim = ANIMATIONS[animName] ?? ANIMATIONS.idle;
  const frameIndex = resolveFrameIndex(anim, elapsed);
  const spriteName = anim.frames[frameIndex];
  const entry = spriteManifest.sprites[spriteName];

  if (!entry) return 1.0;

  return entry.sourceSize[0] / entry.sourceSize[1];
}
```

### Design Decisions

- **Fallback ratio 1.0**: Se o manifest falhar no fetch, o sprite sera quadrado
  em vez de usar o ratio fixo antigo de 1.333. Isso e melhor que esticar
  horizontalmente, e o manifest raramente falhara (e um asset estatico local).
- **O(1) performance**: A funcao faz um lookup em `ANIMATIONS` (object key),
  `resolveFrameIndex` (math), e `spriteManifest.sprites` (object key). Sem
  loops ou allocacoes.
- **Reusar `resolveFrameIndex`**: Ja existe e computa o frame index correto para
  loop/one-shot animations. Sem duplicacao de logica.
- **Manifest fetch em paralelo**: Nao aumenta o tempo de loading pois roda
  concorrentemente com o carregamento das texturas.
