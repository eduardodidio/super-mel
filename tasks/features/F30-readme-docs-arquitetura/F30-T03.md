# F30-T03 — Doc-Review Gate no CLAUDE.md

**Wave:** 1
**Type:** docs / process
**Depends on:** F30-T01
**Status:** done

## User Story

As a team member, I want every new feature to check if documentation needs updating, so that docs never go stale.

## Objective

Adicionar regra explicita no CLAUDE.md de que toda feature deve incluir revisao de docs como parte do processo. Criar template de checklist de docs.

## Dev Notes

### Regra a adicionar no CLAUDE.md

Na secao "Documentation Maintenance Rules", adicionar:

```markdown
## Doc-Review Gate (obrigatorio por feature)

Toda feature que ship DEVE passar por este checklist antes de ser considerada "done":

- [ ] README.md atualizado com nota sobre a feature (secao Features Entregues)
- [ ] README.md Arquitetura atualizada se a feature mudou a estrutura
- [ ] docs/README.md indice atualizado se novos docs foram criados
- [ ] Diagramas F<XX>-architecture.mmd e F<XX>-journey.mmd criados/atualizados
- [ ] ADR criado se houve decisao arquitetural significativa
- [ ] PRD existe para a feature (pode ser inline no F<XX>-README.md)
```

### Template de checklist

Criar `docs/templates/doc-review-checklist.md` com o checklist acima formatado para copiar em cada feature.

### Arquivos a modificar/criar
- `CLAUDE.md` — adicionar regra na secao Documentation Maintenance Rules
- `docs/templates/doc-review-checklist.md` — novo template

## Acceptance Criteria
