## Implementation Details

```typescript
type AnimState =
  | "idle" | "walk" | "run"
  | "jump_rise" | "jump_air" | "jump_fall" | "jump_land"
  | "attack_prep" | "attack_1" | "attack_2" | "attack_end"
  | "hurt_light" | "hurt_medium" | "hurt_heavy"
  | "death"
  | "sit" | "lie_down"
  | "affection" | "wait";

interface AnimInput {
  velX: number;
  velY: number;
  grounded: boolean;
  attackPressed: boolean;
  damaged: boolean;       // true no frame do dano
  damageLevel: 0|1|2|3;   // 0=nenhum, 1=leve, 2=medio, 3=grave
  dead: boolean;
  idleTime: number;        // segundos sem input
}

class AnimationStateMachine {
  state: AnimState;
  stateTime: number;       // tempo no estado atual
  facing: "left" | "right";

  update(input: AnimInput, delta: number): AnimState;
  canInterrupt(): boolean;
  onStateExit(state: AnimState): void;
  onStateEnter(state: AnimState): void;
}
```

### Regras de transicao (prioridade alta → baixa)

1. `dead` → death (terminal)
2. `damaged` → hurt_light/medium/heavy (nao interrompivel)
3. `attackPressed` && canAttack → attack sequence (nao interrompivel por walk)
4. `!grounded && velY > 1` → jump_rise/air
5. `!grounded && velY < -1` → jump_fall
6. `grounded && just_landed` → jump_land (2 frames)
7. `|velX| > 4` → run
8. `|velX| > 0.5` → walk
9. `idleTime > 8` → sit → `idleTime > 16` → lie_down
10. default → idle

## Test Scenarios

- Happy path: idle → walk (velX > 0.5) → run (velX > 4) → idle (velX = 0)
- Priority: walk + damage → hurt (interrupts walk)
- Priority: attack + walk → stays attack (not interrupted)
- One-shot: attack_prep → attack_1 → attack_2 → attack_end → idle
- Edge: grounded flip durante jump → nao muda estado
- Boundary: velX = 0.5 exato → walk, velX = 0.49 → idle
- Idle timeout: 8.0s → sit, 16.0s → lie_down, qualquer input → idle
