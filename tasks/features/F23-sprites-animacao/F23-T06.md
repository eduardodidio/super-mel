**Wave:** 3
**Type:** frontend
**Depends on:** F23-T01, F23-T04

## User Story

As a player, I want to see Mel's portrait in the HUD that changes expression based on my remaining lives, so that I have an emotional connection to my character's health.

## Objective

Adicionar portrait da Mel ao HUD que muda conforme a vida restante.

## Implementation Details

1. Adicionar `<img>` do portrait no canto superior esquerdo, antes dos coracoes
2. Logica de troca:
   ```typescript
   const getPortraitSrc = (lives: number) => {
     if (lives >= 3) return "/sprites/mel/ui_portrait.png";
     if (lives === 2) return "/sprites/mel/ui_portrait.png"; // fallback: tint amarelo via CSS
     return "/sprites/mel/ui_portrait.png"; // fallback: tint vermelho via CSS
   };
   ```
3. CSS filter para fallback: `filter: hue-rotate(...)` ou `filter: sepia(1) saturate(5) hue-rotate(0deg)` para vermelho
4. Portrait size: ~48x48px no HUD, com borda pixel-art (2px solid dourado)
5. `image-rendering: pixelated` para manter pixel art crisp
