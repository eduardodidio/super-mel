**Wave:** 0
**Type:** frontend / infra
**Depends on:** —

## User Story

As a developer, I want the new sprite assets extracted and organized in a standard directory structure, so that subsequent tasks can reference them directly.

## Objective

Extrair os 34 sprites da folha de referencia (`novosSpritesEPlanejamento/super_mel_ref_sprites.zip`), organizar em `packages/frontend/public/sprites/mel/`, e criar um manifest JSON com metadata de cada sprite.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/01-asset-pipeline.md`.

- O zip contem sprites individuais ja recortados (~100-150px altura, celula 224x168)
- Nomear conforme convencao: `acao_direcao_NN.png` (ex: `walk_right_01.png`)
- Criar `sprites-manifest.json` mapeando nome → dimensoes, pivo, animacao
- O spritesheet antigo (`mel_spritesheet.png`) deve ser mantido temporariamente para nao quebrar o jogo ate T04 integrar

### Arquivos a criar/modificar

- `packages/frontend/public/sprites/mel/` — novo diretorio com PNGs extraidos
- `packages/frontend/public/sprites/mel/manifest.json` — metadata dos sprites
- Se o zip nao puder ser extraido programaticamente, extrair manualmente e commitar os PNGs

## Implementation Details

1. Extrair `novosSpritesEPlanejamento/super_mel_ref_sprites.zip` para diretorio temporario
2. Renomear cada sprite conforme convencao do plano (secao 1)
3. Copiar para `packages/frontend/public/sprites/mel/`
4. Gerar `manifest.json`:
   ```json
   {
     "frameSize": [224, 168],
     "pivot": [0.5, 0.893],
     "sprites": {
       "idle_right_01": { "file": "idle_right_01.png" },
       "walk_right_01": { "file": "walk_right_01.png" },
       ...
     }
   }
   ```

## Acceptance Criteria
