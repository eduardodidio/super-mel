# F23-T05 — Efeitos Visuais Separados (Dust, Stars, Hearts)

**Wave:** 2
**Type:** frontend
**Depends on:** F23-T02
**Status:** planned

## User Story

As a player, I want to see particle effects like dust when running, stars when hurt, and hearts during affection, so that the game feels alive and expressive.

## Objective

Criar sistema de efeitos visuais com sprites separados, independentes da Mel. Cada efeito e instanciado, animado e destruido automaticamente.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/03-effects-and-ui.md`.

- Efeitos sao sprites 2D animados posicionados no mundo 3D
- Nao tem colisao (exceto bark_wave que ja tem via Projectile)
- Usar pooling simples para evitar GC pressure

- `packages/frontend/src/game/systems/EffectManager.tsx` — gerencia spawn/despawn de efeitos

## Implementation Details

### EffectSprite

Componente R3F que renderiza uma sequencia de sprites e se auto-destroi ao terminar:

```typescript
interface EffectSpriteProps {
  type: "dust" | "stars" | "heart" | "exclamation";
  position: [number, number, number];
  onComplete: () => void;
  scale?: number;
}
```

- Usa `useFrame` para avancar frames
- Aplica `NearestFilter` para pixel art
- Fade out no ultimo frame (alpha → 0)

### EffectManager

Recebe eventos do jogo e spawna efeitos:

```typescript
interface EffectManagerProps {
  playerX: number;
  playerY: number;
  playerState: AnimState;
  playerGrounded: boolean;
  playerVelX: number;
}
```

Regras de spawn:
- `dust`: a cada 0.15s enquanto `run`, posicao nas patas (playerY - 0.5)
- `dust_land`: ao transitar de `jump_fall` → `jump_land`
- `stars`: ao entrar em `hurt_medium`, posicao na cabeca (playerY + 0.8)
- `heart`: ao entrar em `affection` ou `jump_on_owner`, sobe lentamente
