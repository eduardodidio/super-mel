# F23-T02 — Novo SpriteAnimator com Suporte a Sprites Individuais

**Wave:** 1
**Type:** frontend
**Depends on:** F23-T01
**Status:** planned

## User Story

As a developer, I want a new sprite animation system that loads individual sprite textures and plays named animation sequences, so that the game can use the new high-quality 2D sprites.

## Objective

Reescrever `SpriteAnimator.ts` para suportar sprites individuais (nao grid fixo), com definicoes de animacao por nome, FPS configuravel, loop/one-shot, e fallback para frames ausentes.

## Implementation Details

```typescript
// Nova interface
interface SpriteAnimationDef {
  name: string;
  frames: string[];        // nomes dos sprites no manifest
  fps: number;
  loop: boolean;
  // eventos por frame (ex: disparar projetil no frame 2)
  events?: Record<number, string>;
}

// Animacoes conforme plano secao 2
const ANIMATIONS: Record<string, SpriteAnimationDef> = {
  idle: {
    name: "idle",
    frames: ["idle_right_01"],  // fallback: 1 frame com bob procedural
    fps: 6,
    loop: true,
  },
  walk: {
    name: "walk",
    frames: ["walk_right_01", "walk_right_02", ...],
    fps: 10,
    loop: true,
  },
  // ... todas as animacoes do plano
};
```

- `loadSprites(manifest)` — pre-carrega todas as texturas
- `getFrame(animName, elapsed)` → `THREE.Texture` do frame atual
- `isFinished(animName, elapsed)` → boolean para one-shots
- Fallback: se frame nao existe no manifest, usar o frame anterior ou `idle_right_01`

## Acceptance Criteria

- [ ] Todas as animacoes do plano estao definidas (idle, walk, run, jump, fall, attack, hurt, death, sit)
- [ ] `loadSprites()` pre-carrega texturas e retorna Promise
- [ ] `getFrame()` retorna textura correta para cada animacao/tempo
- [ ] One-shot animations retornam `finished=true` apos ultimo frame
- [ ] Loop animations ciclam infinitamente
- [ ] Fallback funciona quando sprite PNG nao existe
