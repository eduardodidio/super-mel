# Task F38-T05 -- Floating "+1" Coin Popup

**Feature:** F38
**Wave:** 1
**Type:** frontend (HUD / VFX)
**Depends on:** (none)
**Status:** planned

## User Story

As a player, I want to see a floating "+1" text popup when I collect a coin, so I get immediate visual feedback that the coin was collected and the experience feels polished and game-like.

## Objective

Create a `CoinPopup` system that renders floating "+1" text at the coin's world position, rising upward and fading out over ~0.6 seconds. Implemented as an HTML overlay using world-to-screen coordinate projection.

## Dev Notes

### 1. New file: `packages/frontend/src/game/systems/CoinPopup.tsx`

This component manages a list of active popups and renders them as absolute-positioned HTML elements.

```typescript
import { useState, useCallback, useRef, useEffect } from "react";
import { useThree, useFrame } from "@react-three/fiber";
import * as THREE from "three";

interface PopupData {
  id: number;
  worldX: number;
  worldY: number;
  createdAt: number;  // timestamp from useFrame clock
}

const POPUP_DURATION = 0.6;   // seconds
const POPUP_RISE_PX = 40;     // pixels to rise
const MAX_POPUPS = 8;

let nextPopupId = 0;

export interface CoinPopupHandle {
  spawn: (worldX: number, worldY: number) => void;
}

export function CoinPopupLayer({ popupRef }: { popupRef: React.MutableRefObject<CoinPopupHandle | null> }) {
  const { camera, size } = useThree();
  const [popups, setPopups] = useState<PopupData[]>([]);
  const clockRef = useRef(0);

  // Expose spawn function via ref
  useEffect(() => {
    popupRef.current = {
      spawn: (worldX: number, worldY: number) => {
        setPopups(prev => {
          const newPopup: PopupData = {
            id: nextPopupId++,
            worldX,
            worldY,
            createdAt: clockRef.current,
          };
          const combined = [...prev, newPopup];
          return combined.slice(-MAX_POPUPS);
        });
      },
    };
  }, [popupRef]);

  // Track time and remove expired popups
  useFrame((state) => {
    clockRef.current = state.clock.elapsedTime;
    setPopups(prev => prev.filter(p => (clockRef.current - p.createdAt) < POPUP_DURATION));
  });

  // Project world coordinates to screen coordinates
  const projectToScreen = (worldX: number, worldY: number): { x: number; y: number } => {
    const vec = new THREE.Vector3(worldX, worldY, 0);
    vec.project(camera);
    return {
      x: (vec.x * 0.5 + 0.5) * size.width,
      y: (-vec.y * 0.5 + 0.5) * size.height,
    };
  };

  if (popups.length === 0) return null;

  return (
    <>
      {popups.map(popup => {
        const age = clockRef.current - popup.createdAt;
        const t = Math.min(age / POPUP_DURATION, 1);
        const screen = projectToScreen(popup.worldX, popup.worldY + 0.5);
        const risePx = t * POPUP_RISE_PX;
        const opacity = t > 0.5 ? 1 - (t - 0.5) / 0.5 : 1;

        return (
          <div
            key={popup.id}
            style={{
              position: "absolute",
              left: screen.x,
              top: screen.y - risePx,
              transform: "translate(-50%, -50%)",
              color: "#DC143C",
              fontSize: "18px",
              fontWeight: "bold",
              fontFamily: "monospace",
              textShadow: "1px 1px 0 #000, -1px -1px 0 #000, 1px -1px 0 #000, -1px 1px 0 #000",
              opacity,
              pointerEvents: "none",
              zIndex: 15,
              transition: "none",
              willChange: "transform, opacity",
            }}
          >
            +1
          </div>
        );
      })}
    </>
  );
}
```

**Design rationale:**
- Uses R3F's `useThree` to get camera and canvas size for world-to-screen projection
- Popups are HTML divs for crisp text rendering
- Color `#DC143C` matches the existing coin counter color in HUD3D
- Font matches HUD style (monospace, bold)
- Rise 40px and fade out over 0.6s
- Max 8 simultaneous popups to prevent spam

**Important R3F note:** Since this component uses `useFrame` and `useThree`, it MUST be rendered inside the R3F `Canvas` tree, specifically inside an `<Html>` wrapper or as a portal. However, the HUD3D is rendered OUTSIDE the Canvas.

**Revised approach:** Render the popups outside Canvas but pass the camera ref for projection. Actually, the simplest working approach is:

Option A: Use R3F's `<Html>` component from `@react-three/drei` -- but that adds a dependency.

Option B: Render the popup container outside Canvas and project using a shared camera ref.

Option C: Render the CoinPopupLayer inside Canvas using `createPortal` to render HTML.

**Recommended: Option B** -- Keep CoinPopupLayer as a regular React component OUTSIDE Canvas. Pass a `cameraRef` from the Canvas scene. Use the projection math manually.

**Simplest working approach:** Render CoinPopupLayer next to HUD3D in the main game layout. Pass the Three.js camera via a ref stored in a Zustand store or a React context. Since the camera is available via `useThree()` only inside Canvas, store it in a ref from inside CameraRig:

In CameraRig.tsx (or GameScene3D.tsx), store the camera in a shared ref:
```typescript
// In a small store or context
export const cameraRef = { current: null as THREE.Camera | null };
// In CameraRig's useFrame: cameraRef.current = camera;
```

Then CoinPopupLayer reads from `cameraRef` outside the Canvas.

**Or even simpler:** Make CoinPopupLayer a pure component that receives screen coordinates directly. GameScene3D computes the screen position and passes it as a prop/callback. This avoids the camera-sharing issue entirely.

**Final recommended approach:**

1. GameScene3D stores popup data (worldX, worldY, timestamp) in a Zustand slice or local state
2. The popup rendering happens in the parent component (Game3D.tsx) alongside HUD3D, using the camera stored in a module-level ref
3. CameraRig already has camera access -- export the camera ref

The developer should choose the simplest approach that works. The key requirements are:
- "+1" text appears at the coin's screen position
- It rises ~40px and fades over 0.6s
- Color matches the HUD coin counter (#DC143C)

## Testing

### Manual Tests
1. Collect a static coin (from ChunkRenderer) -- "+1" appears and floats up
2. Collect a dropped coin (from block destruction) -- "+1" appears at coin position
3. Collect multiple coins quickly -- multiple "+1" popups appear, each independent
4. "+1" fades out smoothly over ~0.6s
5. "+1" color matches the HUD coin counter (crimson red)
6. Font is monospace bold with black outline

### Edge Cases
- Collecting >8 coins very rapidly -- oldest popups are evicted (MAX_POPUPS = 8)
- Coin collected at screen edge -- popup should still appear (may be partially clipped, that is fine)
- Camera moving while popup is active -- popup may drift slightly (acceptable for 0.6s lifetime)
- Paused game -- popups should not appear (no coins collected while paused)
