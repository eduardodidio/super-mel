# Task F38-T06 -- Audio Pitch Randomization (SFX Infrastructure)

**Feature:** F38
**Wave:** 0
**Type:** frontend (audio)
**Depends on:** (none)
**Status:** planned

## User Story

As a player, I want repeated sound effects (coin collect, block break, jump) to have slight pitch variations so they do not sound robotic and repetitive, making the game feel more organic and polished.

## Objective

Add a `playSFX(name, opts?)` function to AudioManager3D.ts that plays one-shot sound effects with automatic pitch randomization of +-10% via the `playbackRate` property. This establishes the SFX infrastructure for the game -- actual audio files are out of scope for F38 and will be added in a future feature.

## Dev Notes

### AudioManager3D.ts changes

**Add SFX type and registry:**

```typescript
type SFXName = "coin" | "block_break" | "jump" | "hurt" | "attack" | "heart";

const SFX_PATHS: Record<SFXName, string> = {
  coin: "/audio/sfx/coin.mp3",
  block_break: "/audio/sfx/block_break.mp3",
  jump: "/audio/sfx/jump.mp3",
  hurt: "/audio/sfx/hurt.mp3",
  attack: "/audio/sfx/attack.mp3",
  heart: "/audio/sfx/heart.mp3",
};
```

**SFX pool for performance:**

Instead of creating a new `Audio()` element for every SFX play, maintain a small pool of reusable elements per SFX name:

```typescript
const SFX_POOL_SIZE = 3; // max simultaneous instances per sound
const sfxPools: Map<SFXName, HTMLAudioElement[]> = new Map();

function getSFXPool(name: SFXName): HTMLAudioElement[] {
  let pool = sfxPools.get(name);
  if (!pool) {
    pool = [];
    for (let i = 0; i < SFX_POOL_SIZE; i++) {
      const audio = new Audio(SFX_PATHS[name]);
      audio.preload = "auto";
      audio.volume = 0.5;
      pool.push(audio);
    }
    sfxPools.set(name, pool);
  }
  return pool;
}
```

**Main playSFX function:**

```typescript
interface SFXOptions {
  /** Override volume (0-1). Default: 0.5 */
  volume?: number;
  /** Pitch randomization range (0 = none, 0.1 = +-10%). Default: 0.1 */
  pitchVariation?: number;
  /** Force a specific playback rate (overrides randomization). */
  playbackRate?: number;
}

export function playSFX(name: SFXName, opts?: SFXOptions): void {
  if (muted) return;

  const pool = getSFXPool(name);

  // Find a free (ended or not-yet-played) element in the pool
  let audio = pool.find(a => a.paused || a.ended);
  if (!audio) {
    // All instances busy -- steal the oldest one
    audio = pool[0];
  }

  // Configure
  audio.volume = opts?.volume ?? 0.5;

  if (opts?.playbackRate !== undefined) {
    audio.playbackRate = opts.playbackRate;
  } else {
    const variation = opts?.pitchVariation ?? 0.1;
    audio.playbackRate = 1 + (Math.random() * 2 - 1) * variation;
  }

  // Reset and play
  audio.currentTime = 0;
  audio.play().catch(() => {
    // Autoplay blocked -- silently skip (SFX are not critical)
  });
}
```

**Key behaviors:**
- `playbackRate = 1.0` means normal pitch. With `pitchVariation = 0.1`, the rate varies between 0.9 and 1.1 (+-10%).
- The `muted` flag (already exists as a module-level variable) silences SFX too.
- Pool of 3 per SFX prevents creating unlimited Audio elements.
- `play().catch()` silently handles autoplay restrictions -- SFX are non-critical.

**Pre-load function (optional):**

```typescript
export function preloadSFX(): void {
  for (const name of Object.keys(SFX_PATHS) as SFXName[]) {
    getSFXPool(name); // Creates the pool, which triggers preload
  }
}
```

Call this from the game's initialization (e.g., when entering "playing" scene) to warm up the audio pools. This is optional -- lazy initialization also works.

**Export the new types:**


### File structure for future SFX files

The SFX paths point to `/audio/sfx/*.mp3`. Create the directory structure:

```
packages/frontend/public/audio/sfx/
```

For now, this directory can be empty or contain placeholder files. The `playSFX` function handles missing files gracefully (the `play().catch()` silently ignores errors).

**Note for future features (F40+):** When adding actual SFX audio files, simply place `.mp3` files in `public/audio/sfx/` matching the names in `SFX_PATHS`. No code changes needed -- the infrastructure is ready.

## Testing

### Manual Tests (with placeholder audio files)
1. Create a test `.mp3` file (e.g., a short beep) and place it at `public/audio/sfx/coin.mp3`
2. Call `playSFX("coin")` from browser console or from a temporary button
3. Verify the sound plays
4. Call `playSFX("coin")` rapidly 5 times -- should hear overlapping sounds with slight pitch variation
5. Toggle mute (`toggleMute()`) -- subsequent `playSFX` calls should be silent
6. Call `playSFX("coin", { pitchVariation: 0 })` -- should play at exact normal pitch
7. Call `playSFX("coin", { playbackRate: 1.5 })` -- should play at 1.5x speed/pitch

### Without audio files
1. Call `playSFX("coin")` -- should silently fail (no console errors, no crashes)
2. No runtime errors from missing `.mp3` files

### Edge Cases
- All 3 pool instances busy -- oldest is stolen and restarted (no crash)
- `playSFX` called before user interaction -- silently ignored (autoplay policy)
- muted state carries over from `toggleMute()` -- SFX also muted
