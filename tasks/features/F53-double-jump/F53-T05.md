# Task F53-T05 -- EffectManager + MissionTracker + GameEventBus + InfiniteMissions: Double Jump Effects and Missions

**Feature:** F53
**Wave:** 1
**Type:** frontend (effects + missions + events)
**Depends on:** F53-T01 (double jump in Mel.tsx), F53-T02 (double_jump in AnimationStateMachine)
**Status:** planned

## User Story

As a player, I want to see a dust puff effect when I double jump and I want missions that track my double jumps, so that the double jump mechanic feels polished and integrated into the game's progression systems.

## Objective

1. Add a dust puff effect in `EffectManager` when Mel enters the `"double_jump"` animation state.
2. Add `"double_jump"` event to `GameEventBus`.
3. Add `doubleJumpsPerformed` counter to `MissionTracker` and replace the deprecated `"fly_duration"` mission condition with `"double_jump_count"`.
4. Replace the `"inf-fly-5s"` infinite mission with a double-jump mission.
5. Emit the `"double_jump"` event from `Mel.tsx` when the double jump is triggered.

### Gotchas

- The `GameEventBus.ts` file may use a typed event map or a simple string union. Inspect the actual implementation before adding the new event type.
- The `onFlyTick` method in `MissionTracker` can be kept but will never be called (since `fly_tick` is never emitted after T03 removes the emitter). Mark it as deprecated.
- Make sure the `useInfiniteMissions` hook's event listener cleanup (`gameEventBus.off(...)`) is updated for the new event name.
- The `"inf-fly-5s"` mission ID changes to `"inf-djump-10"`. If any user has progress saved under the old ID in localStorage, it will be ignored (new mission = fresh progress). This is acceptable since the old mission tracked a mechanic that no longer exists.
