### 3. `packages/frontend/src/game/hooks/useAssistMode.ts`

**Option A (recommended): Keep `unlimitedFlight` in the interface but make the setter a no-op.** This avoids breaking localStorage parsing for users who had it enabled:

```typescript
export interface AssistModeSettings {
  invincible: boolean;
  unlimitedFlight: boolean;  // DEPRECATED: fly removed in F53, kept for localStorage compat
  fiveHearts: boolean;
  gameSpeed: number;
}
```

The `setUnlimitedFlight` method stays but the toggle is hidden from UI. If a user had `unlimitedFlight: true` in localStorage, it will be loaded but have no effect (since Mel.tsx never reads it anymore).

**Option B: Remove entirely.** If localStorage compat is not a concern, remove `unlimitedFlight` from the interface, default settings, and store actions. Add a migration in `loadSettings()` to strip it:
```typescript
function loadSettings(): AssistModeSettings {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    if (!raw) return DEFAULT_SETTINGS;
    const parsed = JSON.parse(raw);
    return {
      invincible: Boolean(parsed.invincible),
      // unlimitedFlight removed
      fiveHearts: Boolean(parsed.fiveHearts),
      gameSpeed: [0.7, 0.85, 1.0].includes(parsed.gameSpeed) ? parsed.gameSpeed : 1.0,
    };
  } catch {
    return DEFAULT_SETTINGS;
  }
}
```

**Go with Option A** for safety. The field persists in the type but is unused.
