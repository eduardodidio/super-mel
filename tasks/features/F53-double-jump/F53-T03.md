# Task F53-T03 -- HUD, Game3D, GameScene3D, useGameState: Remove Fly State Plumbing

**Feature:** F53
**Wave:** 1
**Type:** frontend (UI + state cleanup)
**Depends on:** F53-T01 (fly logic removed from Mel.tsx)
**Status:** planned

## User Story

As a player, I should no longer see the "FLY" stamina bar in the HUD since the fly mechanic has been replaced by double jump.

## Objective

Remove the entire fly state pipeline: the `StaminaBar` component from HUD, the `isFlying`/`flyTimeRemaining` props, the `setFlyState` action from the game state store, and the `onFlyStateUpdate` callback plumbing in GameScene3D. Clean up the `useGameState` store to remove fly-related fields.
