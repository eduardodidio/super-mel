# Task F53-T01 -- Mel.tsx: Remove Fly Logic + Implement Double Jump

**Feature:** F53
**Wave:** 0
**Type:** frontend (game mechanics)
**Depends on:** None
**Status:** planned

## User Story

As a player, I want to press Space a second time while in the air to perform a double jump, instead of the broken fly mechanic, so that I have reliable air control in the platformer.

## Objective

Replace the fly mechanic in `Mel.tsx` with a clean double jump. Remove all fly-related constants, refs, and logic. Add a `doubleJumpUsed` ref that tracks whether the double jump has been consumed. Reset it on landing and on stomp bounce.

### 6. Replace fly logic block (lines 195-225) with double jump

Remove the entire `--- Fly ---` section (lines 195-225, from "// --- Fly (max 5s..." to "onFlyStateUpdate?.(...)"):

Replace with:
```typescript
// --- Double Jump ---
if (jumpPressed && !lastJumpPressed.current && !grounded.current && !doubleJumpUsed.current && !jumping.current) {
  doubleJumpUsed.current = true;
  rb.setLinvel({ x: newVelX, y: DOUBLE_JUMP_FORCE, z: 0 }, true);
}

// Reset double jump on ground
if (grounded.current) {
  doubleJumpUsed.current = false;
}
```

**Important:** The double jump check must happen AFTER the normal jump logic (lines 178-191) and AFTER `lastJumpPressed.current = jumpPressed` (line 193). The condition `!lastJumpPressed.current` ensures edge detection (only on press, not hold). The condition `!jumping.current` ensures we don't double-jump on the first frame of a normal jump (since `jumping` is set to true when a normal jump starts and set to false when Space is released).

Wait -- we need to be careful with the order. The normal jump section already sets `lastJumpPressed.current = jumpPressed` on line 193. If we check `!lastJumpPressed.current` after that line, it will always be equal to the current frame's state. So the double jump check must be integrated into the existing jump logic flow.

**Revised approach:** Insert the double jump as an `else if` in the jump pressed edge detection:

```typescript
// --- Jump ---
const canJump = grounded.current || coyoteTimer.current > 0;
const jumpPressed = ctrl.jump;

if (jumpPressed && !lastJumpPressed.current && canJump) {
  // Normal ground jump
  jumping.current = true;
  jumpHoldTimer.current = 0;
  coyoteTimer.current = 0;
  rb.setLinvel({ x: newVelX, y: JUMP_FORCE, z: 0 }, true);
} else if (jumpPressed && !lastJumpPressed.current && !canJump && !doubleJumpUsed.current) {
  // Double jump (airborne, not yet used)
  doubleJumpUsed.current = true;
  jumpHoldTimer.current = 0;
  jumping.current = true;
  rb.setLinvel({ x: newVelX, y: DOUBLE_JUMP_FORCE, z: 0 }, true);
} else if (jumpPressed && jumping.current && jumpHoldTimer.current < MAX_JUMP_HOLD) {
  // Variable height hold (works for both normal and double jump)
  jumpHoldTimer.current += delta;
  const holdVel = vel.y + JUMP_HOLD_FORCE * delta;
  rb.setLinvel({ x: newVelX, y: Math.max(vel.y, holdVel), z: 0 }, true);
} else {
  if (!jumpPressed) jumping.current = false;
  if (grounded.current) jumping.current = false;
  rb.setLinvel({ x: newVelX, y: vel.y, z: 0 }, true);
}

lastJumpPressed.current = jumpPressed;

// --- Reset double jump on ground ---
if (grounded.current) {
  doubleJumpUsed.current = false;
}
```

### Gotchas

- The `jumpHoldTimer` variable-height jump should still work for the double jump. When the player presses Space for the double jump and holds it, the hold force adds a bit more height. This is desirable for feel.
- Coyote time should NOT grant a double jump. The `canJump` check covers coyote time for the ground jump. The double jump check explicitly requires `!canJump` (meaning: truly airborne, not in coyote time).
- The `flying` field in `AnimInput` is set to `false` always. This ensures the AnimationStateMachine never enters the `"fly"` state. The `"fly"` sprite/state definition remains for future use.
- Do NOT remove the `useAssistMode.getState().unlimitedFlight` line yet -- T04 handles AssistMode cleanup.

## Testing

- Press Space on ground: Mel jumps normally (JUMP_FORCE = 10)
- Press Space again while airborne: Mel performs a second jump (DOUBLE_JUMP_FORCE = 9)
- Press Space a third time while airborne: nothing happens
- Land on ground, then jump and double jump again: works (counter reset)
- Stomp an enemy, then press Space: double jump works (counter reset on stomp bounce)
- Hold Space on ground: variable height jump still works
- Hold Space after double jump: variable height extension still works
- Hold Space indefinitely: does NOT activate fly (no upward sustained force)
- Coyote time still works: walk off edge, press Space within 0.1s = normal jump (not double jump)
- Fall off edge without jumping, press Space: this counts as the GROUND jump (coyote time), not double jump. Press Space again: double jump.
