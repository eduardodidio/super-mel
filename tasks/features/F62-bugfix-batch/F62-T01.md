# F62-T01: Console Warnings Cleanup

**Wave:** 0
**Priority:** Medium
**Depends on:** none

## User Story

As a developer, I want the browser console to be free of warnings during normal gameplay, so that real errors are easy to spot and performance isn't degraded by excessive logging.

## Dev Notes

### Investigation

There are 5 explicit `console.warn` calls in the source code:

1. `packages/frontend/src/main.tsx:19` — SW registration failure (intentional, keep)
2. `packages/frontend/src/game/scenes/EditorWrapper.tsx:126` — sessionStorage overflow (intentional, keep)
3. `packages/frontend/src/game/scenes/GameScene3D.tsx:132` — "Level has no goal entity" (fires every render in infinite mode where there's no goal — fix)
4. `packages/frontend/src/game/systems/SpriteAnimator.ts:262` — Failed to load manifest.json (fires if manifest doesn't exist — fix)
5. `packages/frontend/src/game/systems/SpriteAnimator.ts:294` — Sprites not found, using fallback (fires every session if sprites missing — fix)

### Likely Runtime Warnings (investigate at runtime)

- **THREE.js deprecation warnings**: Check for deprecated property access, material updates, texture format warnings
- **R3F prop warnings**: The `material={materials}` prop on `<mesh>` in `Block.tsx` passes an array — verify R3F doesn't warn about this
- **React warnings**: Missing `key` props, useEffect dependency array warnings, StrictMode double-renders (dev only)
- **Rapier physics warnings**: Possible warnings about collider configurations

### Files to Modify

1. **`GameScene3D.tsx` (line 130-133)**: The "Level has no goal" warning fires on EVERY render in infinite mode. Gate it behind `levelData` check (only warn for level mode).

2. **`SpriteAnimator.ts` (line 262)**: Change `console.warn` to a one-time warning using a flag, or downgrade to `console.debug`.

3. **`SpriteAnimator.ts` (line 294)**: Same — use one-time flag or `console.debug` to avoid spam.

4. **`Block.tsx`**: If `material={materials}` (array prop) causes R3F warnings, either:
   - Use `material` as an array (R3F supports this for multi-group geometry) and verify no warnings
   - Or attach materials via `ref` callback: `ref={(mesh) => { if (mesh) mesh.material = materials; }}`

### Approach

```
Step 1: Run the game in browser, open console, play for 2 minutes in both infinite and campaign mode
Step 2: Catalog ALL warnings that appear (with source file + line)
Step 3: Fix each warning:
  - Intentional warnings → keep but add // eslint-disable or gate behind debug flag
  - Unintentional warnings → fix root cause
  - Spam warnings → add one-time flag
Step 4: Re-run and verify console is clean (only expected SW/editor warnings remain)
```
