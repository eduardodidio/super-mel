# F62-T03: Fix Red Block Destruction (Brick Destructible + Visual Feedback)

**Wave:** 0
**Priority:** HIGH
**Depends on:** none

## User Story

As a player, I want red brick blocks to break when I hit them with the Bola do Infinito, with proper visual feedback (particles, block disappears, collider removed), so that the gameplay matches my expectations from Mario-style platformers.

## Problem Analysis

The user reports that when "destroying" red blocks, they turn white and don't disappear, with colliders remaining. Investigation reveals:

1. **`brick` blocks (`#B22222`) have `destructible: false`** in BLOCK_PROPERTIES — the projectile cannot destroy them at all. This contradicts player expectations (in Mario, bricks break).

2. **`item_block` blocks (`#DC143C` crimson red) are also not destructible** — they get "activated" (turn gray `#555555`) when hit. The gray color on a low-brightness screen could appear "white" to the user. The activated block retains its collider (by design — it becomes an inert solid block).

3. **When a non-destructible block is hit by the projectile**, `handleBlockHit` in GameScene3D checks `BLOCK_PROPERTIES[blockType]?.destructible` — if false, nothing happens. The projectile bounces/disappears but the block stays unchanged. No visual feedback at all.

### Fix Plan

1. Make `brick` blocks destructible in BLOCK_PROPERTIES
2. Ensure the full destroy lifecycle works: setState → filter from render → cleanup collider → spawn particles
3. Add a subtle "hit" feedback even for non-destructible blocks (screen shake is already there for destructibles; consider a small visual flash for indestructibles)
