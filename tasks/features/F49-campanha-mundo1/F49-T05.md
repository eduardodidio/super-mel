## User Story

As a player, I want to see a world map with 8 levels that unlock in sequence so that I can track my campaign progress and choose which level to play.

## Objective

## Dev Notes

### 1. Create `packages/frontend/src/game/systems/LevelLoader.ts`

A simple utility for fetching and caching campaign levels:

```typescript
import { migrateLevelData } from "@super-mel/shared";
import type { LevelDataV2 } from "@super-mel/shared";

export interface CampaignManifest {
  levels: CampaignLevelMeta[];
}

export interface CampaignLevelMeta {
  id: string;         // e.g. "1-1"
  name: string;       // e.g. "Quintal da Mel"
  file: string;       // e.g. "1-1.json"
  theme: string;      // e.g. "forest"
}

const levelCache = new Map<string, LevelDataV2>();
let manifestCache: CampaignManifest | null = null;

export async function loadCampaignManifest(): Promise<CampaignManifest> {
  if (manifestCache) return manifestCache;
  const res = await fetch("/levels/campaign/manifest.json");
  if (!res.ok) throw new Error("Failed to load campaign manifest");
  manifestCache = await res.json();
  return manifestCache!;
}

export async function loadCampaignLevel(fileOrId: string): Promise<LevelDataV2> {
  if (levelCache.has(fileOrId)) return levelCache.get(fileOrId)!;
  const file = fileOrId.endsWith(".json") ? fileOrId : `${fileOrId}.json`;
  const res = await fetch(`/levels/campaign/${file}`);
  if (!res.ok) throw new Error(`Failed to load level: ${file}`);
  const raw = await res.json();
  const level = migrateLevelData(raw);
  levelCache.set(fileOrId, level);
  return level;
}
```

### 2. Create `packages/frontend/src/game/scenes/WorldMapScene.tsx`

An HTML overlay scene (following the same pattern as `LevelSelectOverlay`):

**Layout:**
- Title: "MUNDO 1 -- QUINTAL E PARQUE" (or similar)
- 8 level nodes displayed as a vertical list or 2x4 grid
- Each node shows:
  - Level name (from manifest)
  - Stars earned (0-3, from campaign progress)
  - Bone count (0-3, from campaign progress)
  - Lock icon if not yet unlocked
- Clicking an unlocked node loads and starts the level
- "VOLTAR" button returns to the main menu

**Node unlock logic:**
- Level 1-1 is always unlocked
- Level N is unlocked if level N-1 has at least 1 star in campaign progress
- Campaign progress is read from localStorage (key `supermel_campaign_progress`) and synced to backend by T09

**State source:**
- Read campaign progress from a dedicated localStorage key (`supermel_campaign_progress`):
  ```json
  {
    "levelsCleared": ["1-1", "1-2"],
    "stars": { "1-1": 3, "1-2": 2 },
    "bones": { "1-1": 3, "1-2": 1 }
  }
  ```
- Default: empty `{ levelsCleared: [], stars: {}, bones: {} }`
- Save after each level completion

**Level start flow:**
1. User clicks an unlocked level node
2. Show loading indicator on the node
3. Call `loadCampaignLevel(level.file)` to fetch the JSON
4. Set theme from the manifest's `level.theme`
5. Call `startLevel(level.id, levelData)` with the additional `campaignIndex` (order index)
6. Store `campaignLevelId` and `campaignIndex` in useGameState

### Gotchas

- The world map reads campaign progress from localStorage. This is consistent with how `totalCoins` works today (localStorage first, backend sync as enhancement in T09).
- `loadCampaignManifest()` and `loadCampaignLevel()` are async. WorldMapScene should show a loading state while fetching.
- The manifest is fetched once and cached. Individual level files are also cached after first fetch.
- Campaign levels are NOT in the database. They are static files served from `public/levels/campaign/`. This avoids the need for a database seed/migration.
- `campaignIndex` is used by LevelClearOverlay (T08) to know which level comes next.
- The theme is set from the manifest metadata, not from the level JSON's `theme` field (they should match, but the manifest is authoritative for the world map display).

## Test Scenarios

- **Happy path:** Open world map -> click 1-1 -> level loads and plays -> complete -> world map shows 1 star for 1-1
- **Unlock chain:** Complete 1-1 -> 1-2 unlocks -> complete 1-2 -> 1-3 unlocks
- **Locked level:** Click a locked level -> nothing happens (no loading, no crash)
- **Cache:** Open world map, load 1-1, go back, load 1-1 again -> second load is instant (cached)
- **Edge case:** Network error loading level -> show error message, don't crash
