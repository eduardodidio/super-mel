```typescript
const handleNextLevel = async () => {
  try {
    const manifest = await loadCampaignManifest();
    const nextIndex = campaignIndex + 1;
    if (nextIndex >= manifest.levels.length) {
      // Last level completed -- show congratulations or go to world map
      setScene("worldmap");
      return;
    }
    const nextLevel = manifest.levels[nextIndex];
    const levelData = await loadCampaignLevel(nextLevel.file);
    setTheme(nextLevel.theme as any);
    startCampaignLevel(nextLevel.id, nextIndex, levelData);
  } catch {
    // Fallback to world map on error
    setScene("worldmap");
  }
};
```

Create a helper `saveCampaignProgress`:
```typescript
function saveCampaignProgress(levelId: string, stars: number, bones: number) {
  try {
    const raw = localStorage.getItem("supermel_campaign_progress");
    const progress = raw ? JSON.parse(raw) : { levelsCleared: [], stars: {}, bones: {} };

    // Add to levelsCleared if not already there
    if (!progress.levelsCleared.includes(levelId)) {
      progress.levelsCleared.push(levelId);
    }

    // Keep the best star rating
    progress.stars[levelId] = Math.max(progress.stars[levelId] ?? 0, stars);

    // Keep the best bone count
    progress.bones[levelId] = Math.max(progress.bones[levelId] ?? 0, bones);

    localStorage.setItem("supermel_campaign_progress", JSON.stringify(progress));
  } catch {
    // localStorage quota or access error -- ignore
  }
}
```

### Gotchas

- `handleNextLevel` is async (fetches level data). Show a brief loading state on the button ("...") while loading.
- Campaign progress uses `Math.max` for stars and bones so replaying a level never reduces your best score.
- The "MENU" button on LevelClearOverlay should go to the main menu, NOT the world map. The "MAPA" button goes to the world map.
- When the last campaign level (1-8) is completed, "PROXIMA FASE" should go to the world map (with a congratulatory message in WorldMapScene -- stretch goal).
- The `startCampaignLevel` action sets `campaignLevelId` and `campaignIndex`. The regular `startLevel` (used for community levels) leaves `campaignLevelId = null`. This is how LevelClearOverlay distinguishes campaign from community levels.
- Make sure the existing `handleRepeat` function in LevelClearOverlay uses `startCampaignLevel` (not `startLevel`) when replaying a campaign level, so `campaignLevelId` and `campaignIndex` are preserved.
