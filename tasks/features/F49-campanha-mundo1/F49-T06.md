# Task F49-T06 -- HUD Bone Counter + Bone Collection Wiring

**Feature:** F49
**Wave:** 2
**Type:** frontend
**Depends on:** F49-T03 (Bones rendered in GameScene3D)
**Status:** done

## User Story

As a player, I want to see how many bones I have collected in the current level so that I know my progress toward finding all hidden bones.

## Objective

Add a bone counter to the HUD that shows `X/3` when the current level contains bones. Wire the bone collection callback in `GameScene3D.tsx` to the `addBone()` action in `useGameState`.

## Dev Notes

### 1. Modify `packages/frontend/src/game/systems/HUD3D.tsx`

Add a bone counter that only appears when playing a level that has bones.

Props addition:
```typescript
interface HUD3DProps {
  // ...existing props...
  levelBones?: number;   // bones collected this attempt
  totalBones?: number;   // total bones in the level (from sceneObjects)
}
```

Render the bone counter next to the existing coin counter:
```tsx
{totalBones !== undefined && totalBones > 0 && (
  <div style={styles.boneStat}>
    <span style={styles.boneIcon}>&#x1F9B4;</span> {/* Unicode bone emoji, or use text "OSSO" */}
    <span>{levelBones ?? 0}/{totalBones}</span>
  </div>
)}
```

Styling: position near the coin counter, white text on dark background, matching existing HUD style.

If the bone emoji `U+1F9B4` does not render well in all browsers, use a simple text label "OSSO" or a colored circle instead.

### 2. Modify `packages/frontend/src/game/scenes/GameScene3D.tsx`

Wire the bone collection callback to `addBone()`:

```typescript
const addBone = useGameState((s) => s.addBone);

const handleBoneCollected = useCallback((boneId: string) => {
  addBone();
  // Optional: screen shake, SFX, or popup effect
  shake(0.08, 0.12);
}, [addBone, shake]);
```

Update the Bone rendering to use this handler (replacing the placeholder from T03):
```tsx
{boneEntities.map((b) => (
  <Bone
    key={b.id}
    position={[b.x, b.y, 0]}
    onCollect={() => handleBoneCollected(b.id)}
  />
))}
```

### 3. Pass bone counts to HUD

In `Game3D.tsx`, pass the bone counts to `HUD3D`:

```typescript
const levelBones = useGameState((s) => s.levelBones);
const currentLevelData = useGameState((s) => s.currentLevelData);

// Count total bones in the current level
const totalBones = useMemo(() => {
  if (!currentLevelData) return 0;
  return currentLevelData.entities.filter(e => e.type === "bone").length;
}, [currentLevelData]);

<HUD3D
  // ...existing props...
  levelBones={levelBones}
  totalBones={totalBones}
/>
```

### Gotchas

- The bone counter should ONLY appear when the level has bones (`totalBones > 0`). This means infinite mode and levels without bones show no bone counter.
- `levelBones` resets to 0 when a level starts (handled by `startLevel` / `startCampaignLevel`).
- If the player dies and respawns at a checkpoint, already-collected bones stay collected (the Bone component already handles this via its `collected.current` ref). The `levelBones` count should NOT reset on death. This is naturally handled because `loseLife()` in level mode does not reset `levelBones`.
- The HUD already shows lives, score, and coins. The bone counter should not crowd the display. Position it below or next to the coin counter.
