# Task F49-T01 -- Bone Collectible Entity (Bone.tsx)

**Feature:** F49
**Wave:** 0
**Type:** frontend
**Depends on:** F37 (EntityType "bone" already in LevelDataV2)
**Status:** planned

## User Story

As a player, I want to find hidden bones in campaign levels so that I have a reason to explore and replay levels for 100% completion.

## Objective

Create a Bone entity component that renders a bone-shaped mesh in the 3D scene, detects collision with Mel via sensor, and triggers a collection callback. Follow the same architecture pattern as `Coin.tsx`.

## Dev Notes

### 1. Create `packages/frontend/src/game/entities/Bone.tsx`

Follow the `Coin.tsx` pattern exactly:
- `RigidBody` type="fixed", sensor, name="bone"
- `onIntersectionEnter` checks `payload.other.rigidBodyObject?.name === "mel"`
- Props: `position: [number, number, number]`, `onCollect: () => void`
- Guard: `collected.current` ref prevents double-collection
- Return `null` after collection (unmount visual)

### 2. Visual: Bone-Shaped Mesh

Build a simple bone shape from THREE primitives (no external model needed):
- Central cylinder (height ~0.5, radius ~0.08) in white `#F5F5DC`
- Two sphere caps at each end (radius ~0.12) for the knob look
- Entire group rotated ~30 degrees for a diagonal presentation
- Scale: roughly 0.6 units wide total (smaller than a block but visible)

### 3. Animation and Polish

- **Bob:** gentle vertical oscillation like Coin.tsx (`Math.sin(time * 2) * 0.1`)
- **Spin:** slow Y rotation (`delta * 1.5`) so the bone rotates and catches the eye
- **Glow:** golden point light (intensity 0.3, distance 3, color `#FFD700`) to signal collectibility
- **Emissive:** subtle emissive on the bone material (`emissive: "#FFD700"`, `emissiveIntensity: 0.15`)

### 4. Collision

- On intersection with Mel: call `onCollect()` once
- The parent scene (GameScene3D) handles state updates -- Bone.tsx only fires the callback

### Relevant Files

- `packages/frontend/src/game/entities/Coin.tsx` -- primary pattern to follow
- `packages/frontend/src/game/entities/Heart.tsx` -- bob animation reference
- `packages/shared/src/types.ts` -- EntityType "bone" already declared

### Gotchas

- Do NOT mutate game state inside Bone.tsx. Only call `onCollect()`.
- Position is world-space (1 unit = 1 block).
- Bones should be slightly more visually prominent than coins (golden glow, larger) since they are rarer and more important.
- Use `useMemo` for materials and geometries to avoid re-creation on every render.
