# Task F49-T07 -- Campaign Level JSON Files (8 Levels)

**Feature:** F49
**Wave:** 3
**Type:** content / frontend
**Depends on:** F49-T05 (LevelLoader reads manifest and level files)
**Status:** planned

## User Story

As a player, I want 8 campaign levels with increasing difficulty and different themes so that I have a fun and varied first-time experience.

## Objective

Author 8 campaign levels as LevelDataV2 JSON files, plus a `manifest.json`, in `packages/frontend/public/levels/campaign/`. Each level has a goal, at least one checkpoint, 3 hidden bones, coins, and signs (especially in level 1-1 for tutorial).

### 3. Level Design Guidelines

Each level is a valid LevelDataV2 JSON with:
- `version: 2`
- `grid[][]` with BlockCell entries (type + x + y)
- `entities[]` with EntityData entries
- `width` and `height` (level dimensions in blocks)

**Entity requirements per level:**
- 1 `spawn` entity (start position)
- 1 `goal` entity (end position, placed far to the right)
- 1-3 `checkpoint` entities (evenly spaced between spawn and goal)
- 3 `bone` entities (hidden in hard-to-reach places: behind destructible blocks, above floating platforms requiring flight, in pits requiring careful navigation)
- 5-15 `coin` entities (along the main path and as breadcrumbs to secrets)
- 2-5 `heart` entities (near dangerous sections)
- 0-3 `sign` entities (tutorial signs in 1-1, optional hints in other levels)

**Level dimensions:**
- Width: 40-80 blocks (short levels for 1-1/1-2, longer for 1-7/1-8)
- Height: 15-20 blocks

### 4. Level-by-Level Design

**1-1 "Quintal da Mel" (Tutorial)** -- theme: forest, width: 50, height: 15
- Flat terrain introduction. Signs teach each control in sequence:
  - Sign 1: "Use SETAS para andar (Mobile: D-pad)"
  - Sign 2: "Aperte ESPACO para pular (Mobile: botao A)"
  - Sign 3: "Segure ESPACO para voar (Mobile: segure A)"
  - Sign 4: "Aperte Z para atacar (Mobile: botao B)"
  - Sign 5: "Passe pela casinha para salvar" (near checkpoint)
- Simple platforms, no gaps, 1 checkpoint halfway, gentle terrain
- Bones: 1 behind a destructible glass block, 1 on a high platform (requires flight), 1 inside a pit you must fly out of

**1-2 "Cerca do Vizinho"** -- theme: forest, width: 55, height: 15
- Introduction to gaps and jumping. Short gaps (2-3 blocks) to teach jump timing.
- Leaf platforms as stepping stones. 1 checkpoint.
- Bones: 1 on top of a tall fence (high jump/fly), 1 behind wood blocks, 1 under a floating platform

**1-3 "Pracinha do Parque"** -- theme: forest, width: 60, height: 18
- Vertical sections: platforms going up. Introduction to item_blocks.
- Multiple paths (low = easy, high = bones). 2 checkpoints.
- Bones: all 3 on the high path that requires flight and precision

**1-4 "Lago dos Patos"** -- theme: ocean, width: 60, height: 18
- Water hazard introduction. Water blocks on the ground. Leaf platforms above water.
- Need to fly over water sections. 2 checkpoints.
- Bones: 1 on a tiny island, 1 above a water gap, 1 behind iron blocks accessible from below

**1-5 "Trilha da Montanha"** -- theme: desert, width: 65, height: 20
- Ascending terrain. Sand and stone blocks. Wider gaps. Introduction to lava.
- Tighter platforming. 2 checkpoints.
- Bones: 1 in a hidden cave (break glass to enter), 1 on a peak requiring precise flight, 1 behind a lava section

**1-6 "Ponte Quebrada"** -- theme: desert, width: 60, height: 18
- Broken bridge sections (leaf platforms with gaps). Strong horizontal focus.
- Requires confident jumping and some flight. 2 checkpoints.
- Bones: 1 under the bridge (fall + fly back), 1 at the end of a detour path, 1 behind destructible wood

**1-7 "Aterro Noturno"** -- theme: night, width: 70, height: 20
- Dark aesthetic. Mix of all terrain types. Lava pits. Dense block formations.
- Multiple checkpoints (3). More challenging platforming.
- Bones: all hidden in hard-to-see places (behind solid structures, in pits)

**1-8 "Telhado da Casa"** -- theme: night, width: 80, height: 20
- Final level. Rooftop setting with high platforms and long gaps.
- Combines all skills: jumping, flying, attacking blocks, navigation.
- 3 checkpoints. Goal at the very top.
- Bones: extremely well-hidden (requires mastery of flight and exploration)

### 5. JSON Structure Example (1-1 abbreviated)

```json
{
  "version": 2,
  "width": 50,
  "height": 15,
  "grid": [
    [{"type": "dirt", "x": 0, "y": 0}, {"type": "dirt", "x": 1, "y": 0}, ...]
  ],
  "entities": [
    {"type": "spawn", "x": 2, "y": 2},
    {"type": "goal", "x": 47, "y": 3},
    {"type": "checkpoint", "x": 25, "y": 2},
    {"type": "bone", "x": 10, "y": 8},
    {"type": "bone", "x": 30, "y": 10},
    {"type": "bone", "x": 40, "y": 1},
    {"type": "coin", "x": 5, "y": 3},
    {"type": "sign", "x": 3, "y": 2, "props": {"text": "Use SETAS para andar"}},
    {"type": "heart", "x": 20, "y": 3}
  ],
  "theme": "forest"
}
```

### Gotchas

- Each level JSON must be a valid LevelDataV2 that passes `migrateLevelData()` without error.
- Grid coordinates: y=0 is the bottom of the level. Blocks at higher y values are higher in the scene.
- The grid array is indexed as `grid[row][col]` where row 0 is the bottom.
- Ensure `width` and `height` match the actual grid dimensions.
- Empty cells should still have `{"type": "empty", "x": col, "y": row}` or can be omitted if the converter handles sparse grids (check `levelToSceneObjects`).
- Level files should be reasonably sized (not megabytes). A 80x20 grid with sparse blocks is fine.
- Enemy entities can be included in the JSON (e.g., `{"type": "enemy", "x": 30, "y": 5, "props": {"kind": "vacuum"}}`) but they will be silently ignored until F43 ships. Include 2-3 per level starting from 1-4 for future-proofing.
