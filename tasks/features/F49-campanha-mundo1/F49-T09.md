# Task F49-T09 -- Campaign Progress Sync to Backend

**Feature:** F49
**Wave:** 4
**Type:** frontend
**Depends on:** F49-T08 (Campaign progress saved to localStorage)
**Status:** done

## User Story

As a registered player, I want my campaign progress to sync to the backend so that I do not lose my progress when I switch browsers or devices.

## Objective

Extend `useProgressSync` to include campaign progress (`levelsCleared`, `stars`, `bones`) in the `progress.data` payload sent to the backend. On mount, merge backend campaign progress with localStorage using the same conflict-resolution strategy (take the best values).

## Dev Notes

### 1. Modify `packages/frontend/src/game/hooks/useProgressSync.ts`

**On mount (registered users): merge campaign progress from backend.**

In the existing `fetchProgress` handler, after resolving `totalCoins`:

```typescript
// Merge campaign progress
const backendCampaign = (progress.data?.campaign as CampaignProgress | undefined) ?? {
  levelsCleared: [],
  stars: {},
  bones: {},
};

const localRaw = localStorage.getItem("supermel_campaign_progress");
const localCampaign: CampaignProgress = localRaw
  ? JSON.parse(localRaw)
  : { levelsCleared: [], stars: {}, bones: {} };

// Merge: union of levelsCleared, max of stars and bones per level
const mergedCampaign = mergeCampaignProgress(backendCampaign, localCampaign);

// Write merged back to localStorage
localStorage.setItem("supermel_campaign_progress", JSON.stringify(mergedCampaign));

// If local had data not in backend, push to backend
if (campaignNeedsSync(backendCampaign, mergedCampaign)) {
  putProgress(token, {
    totalCoins: resolvedCoins,
    data: { campaign: mergedCampaign },
  });
}
```

**Define campaign progress types and merge logic:**

```typescript
interface CampaignProgress {
  levelsCleared: string[];
  stars: Record<string, number>;
  bones: Record<string, number>;
}

function mergeCampaignProgress(a: CampaignProgress, b: CampaignProgress): CampaignProgress {
  const levelsCleared = [...new Set([...a.levelsCleared, ...b.levelsCleared])];
  const stars: Record<string, number> = { ...a.stars };
  const bones: Record<string, number> = { ...a.bones };

  for (const [key, val] of Object.entries(b.stars)) {
    stars[key] = Math.max(stars[key] ?? 0, val);
  }
  for (const [key, val] of Object.entries(b.bones)) {
    bones[key] = Math.max(bones[key] ?? 0, val);
  }

  return { levelsCleared, stars, bones };
}

function campaignNeedsSync(backend: CampaignProgress, merged: CampaignProgress): boolean {
  return (
    merged.levelsCleared.length > backend.levelsCleared.length ||
    Object.keys(merged.stars).length > Object.keys(backend.stars).length ||
    Object.values(merged.stars).some((v, i) =>
      v > (Object.values(backend.stars)[i] ?? 0)
    )
  );
}
```

### 3. Backend: no changes needed

The backend `PUT /api/progress` already supports `data: Record<string, unknown>` and performs a deep merge (arrays via set-union, objects via shallow overwrite). The campaign progress structure fits naturally into `progress.data.campaign`. No schema migration or backend code changes are needed.

### Relevant Files

- `packages/frontend/src/game/hooks/useProgressSync.ts` -- primary modification target
- `packages/backend/src/routes/progress.ts` -- no changes needed (verify merge behavior)

### Gotchas

- Campaign progress lives in a separate localStorage key (`supermel_campaign_progress`) from `totalCoins` (`supermel_total_coins`). Both are synced to the same backend `Progress.data` JSON.
- The `mergeProgressData` function in `progress.ts` (backend) uses set-union for arrays (`levelsCleared`) and shallow overwrite for objects (`stars`, `bones`). Since we always send the full merged `stars` and `bones` objects, the backend overwrite is correct (the client already computed Math.max).
- For guests (no token), the sync is a complete no-op -- campaign progress stays in localStorage only.
- The `flushProgress()` function (called on logout) should also include campaign data.
- Avoid syncing on every bone/star collection during gameplay -- only sync on scene transitions (worldmap, levelclear, menu, gameover).
