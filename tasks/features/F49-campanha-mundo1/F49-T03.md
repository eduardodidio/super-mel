# Task F49-T03 -- LevelSceneConverter Updates for Bones and Signs

**Feature:** F49
**Wave:** 1
**Type:** frontend
**Depends on:** F49-T01 (Bone.tsx), F49-T02 (Sign.tsx)
**Status:** done

## User Story

As a developer, I want the LevelSceneConverter to extract bone and sign entities into dedicated arrays so that GameScene3D can render them properly.

## Objective

Extend `LevelSceneConverter.ts` to handle "bone" and "sign" entity types, moving them from the catch-all `otherEntities` array into dedicated typed arrays in the `SceneObjects` interface. Update `GameScene3D.tsx` to render Bone and Sign components from these arrays.

## Dev Notes

### 1. Modify `packages/frontend/src/game/systems/LevelSceneConverter.ts`

Add to the `SceneObjects` interface:

```typescript
export interface SceneObjects {
  // ...existing fields...
  /** Bone collectibles extracted from entities */
  bones: { x: number; y: number; id: string }[];
  /** Sign entities with text and optional icon */
  signs: { x: number; y: number; text: string; icon?: string }[];
}
```

In the `levelToSceneObjects` function, add cases in the entity switch:

```typescript
case "bone":
  bones.push({
    x: entity.x,
    y: entity.y,
    id: `bone-${entity.x}-${entity.y}`,
  });
  break;
case "sign":
  signs.push({
    x: entity.x,
    y: entity.y,
    text: (entity.props?.text as string) ?? "",
    icon: entity.props?.icon as string | undefined,
  });
  break;
```

Initialize the arrays at the top of the function:
```typescript
const bones: SceneObjects["bones"] = [];
const signs: SceneObjects["signs"] = [];
```

Include them in the return object.

### 2. Modify `packages/frontend/src/game/scenes/GameScene3D.tsx`

Add imports for Bone and Sign:
```typescript
import { Bone } from "../entities/Bone";
import { Sign } from "../entities/Sign";
```

Extract bones and signs from sceneObjects:
```typescript
const boneEntities = sceneObjects?.bones ?? [];
const signEntities = sceneObjects?.signs ?? [];
```

Add bone collection handler:
```typescript
const handleBoneCollected = useCallback((boneId: string) => {
  // addBone action will be added in T06
  // For now, just log
  console.log("Bone collected:", boneId);
}, []);
```

Render components in the JSX:
```tsx
{/* Bone entities from level data */}
{boneEntities.map((b) => (
  <Bone
    key={b.id}
    position={[b.x, b.y, 0]}
    onCollect={() => handleBoneCollected(b.id)}
  />
))}

{/* Sign entities from level data */}
{signEntities.map((s, i) => (
  <Sign
    key={`sign-${s.x}-${s.y}-${i}`}
    position={[s.x, s.y, 0]}
    text={s.text}
    icon={s.icon}
  />
))}
```

### Gotchas

- The `otherEntities` array should no longer contain "bone" or "sign" entries after this change. They are now handled explicitly.
- The `handleBoneCollected` callback is placeholder in this task. Full state tracking (`addBone()`, `levelBones`) is wired in T06.
- Signs have no collection/tracking -- they are read-only informational entities.
- Bone IDs use position-based keys (`bone-x-y`) which is unique per level (no two bones at the same position).
