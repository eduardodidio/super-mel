# Task F49-T04 -- Editor Palette: Bone and Sign Tools

**Feature:** F49
**Wave:** 1
**Type:** frontend
**Depends on:** F49-T01 (Bone.tsx), F49-T02 (Sign.tsx)
**Status:** done

## User Story

As a level creator, I want to place bones and signs in my levels using the editor so that I can create levels with hidden collectibles and tutorial hints.

## Objective

Add "Osso" (bone) to the Itens palette tab and "Placa" (sign) to the Especiais palette tab in the level editor. Add corresponding entity placement and visual marker rendering in `EditorScene3D.tsx`.

## Dev Notes

### 1. Modify `packages/frontend/src/game/scenes/EditorUI.tsx`

Add new EditorTool types:
```typescript
export type EditorTool =
  // ...existing types...
  | "entity_bone"
  | "entity_sign";
```

Add to `ITEM_PALETTE`:
```typescript
{ tool: "entity_bone", label: "Osso", color: "#F5F5DC", symbol: "B" },
```

Add to `SPECIAL_PALETTE`:
```typescript
{ tool: "entity_sign", label: "Placa", color: "#A0522D", symbol: "!" },
```

When `entity_sign` is selected, show a text input field (similar to the item_block content dropdown) for the sign's text message:
```tsx
{selectedTool === "entity_sign" && (
  <div style={styles.contentDropdown}>
    <label style={styles.dropdownLabel}>Texto:</label>
    <input
      type="text"
      style={styles.dropdownSelect}
      value={signText}
      onChange={(e) => onSignTextChange(e.target.value)}
      maxLength={40}
      placeholder="Texto da placa..."
    />
  </div>
)}
```

Add `signText` and `onSignTextChange` to `EditorUIProps`:
```typescript
signText: string;
onSignTextChange: (text: string) => void;
```

### 2. Modify `packages/frontend/src/game/scenes/EditorScene3D.tsx`

In the entity placement logic (the click handler that processes entity tools):

For `entity_bone`:
```typescript
case "entity_bone":
  // Add bone entity at (x, y)
  addEntity({ type: "bone", x, y });
  break;
```

For `entity_sign`:
```typescript
case "entity_sign":
  // Add sign entity at (x, y) with text from current signText state
  addEntity({ type: "sign", x, y, props: { text: signText } });
  break;
```

Add visual markers in the editor grid for bone and sign entities:
- **Bone marker:** White sphere (radius 0.2) with golden emissive -- same colors as the actual Bone entity
- **Sign marker:** Brown cylinder (post) with a small rectangle (board) on top -- simplified version of the Sign visual

Add `signText` state in `EditorScene3D` or `EditorWrapper`:
```typescript
const [signText, setSignText] = useState("Texto aqui");
```

Pass it to `EditorUI` as props.

### Gotchas

- The existing entity placement logic in `EditorScene3D` already handles `entity_coin`, `entity_heart`, etc. Follow the exact same pattern for bone and sign.
- The sign text input should be a controlled component. The text is stored in `entity.props.text`.
- When loading an existing level that has sign entities, the text should be displayed if the user selects a sign entity in the editor (stretch goal -- not required for this task).
- The editor's `entities` state already stores `EntityData[]`. No type changes needed in shared types (bone and sign are already in `EntityType`).
- Bone and sign markers in the 3D editor should be distinct from coins and checkpoints (use different colors/shapes).
