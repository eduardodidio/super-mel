# Task F49-T02 -- Tutorial Sign Entity (Sign.tsx)

**Feature:** F49
**Wave:** 0
**Type:** frontend
**Depends on:** F37 (EntityType "sign" already in LevelDataV2)
**Status:** done

## User Story

As a new player, I want to see signs with instructions when Mel approaches them so that I learn the controls naturally during gameplay.

## Objective

Create a Sign entity component that renders a signpost in the 3D scene and shows a floating text balloon when Mel enters a proximity sensor range (~3 blocks). The balloon disappears when Mel moves away.

## Dev Notes

### 1. Create `packages/frontend/src/game/entities/Sign.tsx`

Props:
```typescript
interface SignProps {
  position: [number, number, number];
  text: string;       // from entity.props.text
  icon?: string;      // optional: path to icon image (e.g. "/sprites/mel/ui_icon_ability_paw.png")
}
```

### 2. Visual: Signpost Mesh

Build from THREE primitives:
- **Post:** tall thin box (0.1 x 1.2 x 0.1) in brown `#6B4226`, positioned so it stands on the ground
- **Board:** wider flat box (0.8 x 0.5 x 0.08) in lighter wood `#A0522D`, attached to the top of the post
- **Exclamation mark:** a small yellow box on the board face as a visual hint that this is interactive

No collision physics for the post itself -- it is purely visual. The sensor for proximity is separate.

### 3. Proximity Detection

Use a second `RigidBody` sensor with a larger collider to detect Mel's approach:
- Sensor cuboid collider: 6 x 4 x 2 (3 blocks radius horizontally, 2 blocks vertically)
- `onIntersectionEnter` with Mel: set `showBalloon = true`
- `onIntersectionExit` with Mel: set `showBalloon = false`
- Use a `useState<boolean>(false)` for balloon visibility

### 4. Text Balloon (HTML Overlay via drei Html)

When `showBalloon === true`, render a `<Html>` component from `@react-three/drei`:
- Positioned above the sign (~1.5 units above the board)
- Contains a styled div with:
  - The `text` prop as content
  - Optional `icon` rendered as a small `<img>` tag
  - Styling: dark background (`rgba(0,0,0,0.85)`), white text, rounded corners, monospace font, max-width 200px, padding 8px 12px, border `1px solid #555`
  - CSS pointer-events: none (don't block input)
- Fade in/out with CSS opacity transition (0.2s)

### 5. Animation

- No bob for the signpost itself (it is planted in the ground)
- When balloon appears: subtle scale-up animation on the Html container (CSS transform transition)
- The exclamation mark on the board can pulse gently (emissive intensity oscillation)

### Relevant Files

- `packages/frontend/src/game/entities/Coin.tsx` -- RigidBody sensor pattern
- `@react-three/drei` -- `Html` component for in-scene HTML overlays (already a dependency)
- `packages/frontend/public/sprites/mel/ui_icon_ability_paw.png` -- available icon for signs

### Gotchas

- The `Html` component from drei renders HTML in screen space anchored to a 3D position. It handles occlusion naturally. Use `zIndexRange={[0, 0]}` to avoid z-fighting with HUD.
- The proximity sensor MUST be a separate RigidBody from any potential visual collider. Use `sensor={true}`.
- `text` comes from `entity.props.text` which is `Record<string, unknown>`, so cast appropriately.
- Signs are non-interactive beyond the proximity trigger -- Mel walks through them.
- Keep the balloon text short (max ~30 characters recommended). The campaign levels will use concise instructions like "Aperte ESPACO para pular".
- Mobile: the balloon should mention the mobile control equivalent too (e.g., "Aperte ESPACO / botao A para pular").
