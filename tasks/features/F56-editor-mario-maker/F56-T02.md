# F56-T02: Camera 3D Controls in EditorScene3D

**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a level creator, I want to pan the camera with WASD/arrow keys, zoom with
the scroll wheel, and drag-pan with middle mouse button, so that I can navigate
large levels efficiently instead of being stuck at a fixed camera position.

## Objective

Replace the fixed camera at `[15, 6, 25]` with a user-controllable camera.
Implement keyboard panning, scroll zoom, and middle-click drag panning.
Display camera position in the top bar and clamp to level bounds.

## Dev Notes

### Camera setup change in EditorWrapper

File: `packages/frontend/src/game/scenes/EditorWrapper.tsx` (line 351)

The Canvas currently creates a perspective camera at a fixed position:

Change to a controlled camera by adding state:
```typescript
const [cameraPos, setCameraPos] = useState({ x: 15, y: 6, z: 25 });
```

Pass `cameraPos` and `onCameraChange={setCameraPos}` to `EditorScene3D`.

The Canvas camera prop is only the initial position. The actual camera will be
controlled imperatively inside EditorScene3D via `useThree()`.

#### Keyboard panning (WASD + arrows)

Add a `useEffect` that attaches `keydown`/`keyup` listeners on `window`.
Track pressed keys in a `Set<string>` ref. In `useFrame`, if keys are pressed
AND document.activeElement is not an input/select/textarea, apply movement:

```typescript
const CAMERA_PAN_SPEED = 15; // units per second
const keysRef = useRef(new Set<string>());

useEffect(() => {
  const onKeyDown = (e: KeyboardEvent) => keysRef.current.add(e.key.toLowerCase());
  const onKeyUp = (e: KeyboardEvent) => keysRef.current.delete(e.key.toLowerCase());
  window.addEventListener("keydown", onKeyDown);
  window.addEventListener("keyup", onKeyUp);
  return () => {
    window.removeEventListener("keydown", onKeyDown);
    window.removeEventListener("keyup", onKeyUp);
  };
}, []);
```

In `useFrame((_state, delta))`:
```typescript
const keys = keysRef.current;
const isInputFocused = ["INPUT", "TEXTAREA", "SELECT"].includes(
  document.activeElement?.tagName ?? ""
);
if (!isInputFocused) {
  let dx = 0, dy = 0;
  if (keys.has("a") || keys.has("arrowleft")) dx -= 1;
  if (keys.has("d") || keys.has("arrowright")) dx += 1;
  if (keys.has("w") || keys.has("arrowup")) dy += 1;
  if (keys.has("s") || keys.has("arrowdown")) dy -= 1;
  if (dx !== 0 || dy !== 0) {
    camera.position.x += dx * CAMERA_PAN_SPEED * delta;
    camera.position.y += dy * CAMERA_PAN_SPEED * delta;
    // clamp
    camera.position.x = Math.max(0, Math.min(levelWidth, camera.position.x));
    camera.position.y = Math.max(0, Math.min(levelHeight, camera.position.y));
    onCameraChange({ x: camera.position.x, y: camera.position.y, z: camera.position.z });
  }
}
```

#### Scroll zoom

Add a `wheel` event listener on the canvas container. Adjust camera Z:

```typescript
const ZOOM_SPEED = 2;
const MIN_ZOOM = 8;  // closest
const MAX_ZOOM = 50; // farthest

useEffect(() => {
  const canvas = gl.domElement;
  const onWheel = (e: WheelEvent) => {
    e.preventDefault();
    const dz = Math.sign(e.deltaY) * ZOOM_SPEED;
    camera.position.z = Math.max(MIN_ZOOM, Math.min(MAX_ZOOM, camera.position.z + dz));
    onCameraChange({ x: camera.position.x, y: camera.position.y, z: camera.position.z });
  };
  canvas.addEventListener("wheel", onWheel, { passive: false });
  return () => canvas.removeEventListener("wheel", onWheel);
}, [camera, gl.domElement, onCameraChange]);
```

Access `gl` via `const { camera, gl, raycaster, pointer } = useThree()`.

#### Middle-click drag pan

Track middle button state. On `pointerdown` with `event.button === 1`, start
drag. On `pointermove`, compute delta and move camera. On `pointerup`, stop.

```typescript
const midDragRef = useRef<{ active: boolean; lastX: number; lastY: number }>({
  active: false, lastX: 0, lastY: 0,
});
```

Attach listeners on the canvas element (gl.domElement), not on the R3F mesh.
Convert pixel delta to world units using camera.position.z as a scale factor:
```typescript
const scale = camera.position.z * 0.003; // approximate world-units-per-pixel
camera.position.x -= deltaX * scale;
camera.position.y += deltaY * scale;
```

#### Camera clamping

Clamp camera position to reasonable bounds:
- X: `[0, levelWidth]` (default levelWidth = 32, will be dynamic after T05)
- Y: `[0, levelHeight]` (default levelHeight = 16)
- Z: `[MIN_ZOOM, MAX_ZOOM]`

Accept `levelWidth` and `levelHeight` as props (default 32 and 16). These will
become dynamic when T05 adds level resize.

#### Sync camera on mount

In `useFrame`, on first frame, set camera.position to `cameraPos` prop if it
differs from current camera.position. Use a ref to track if initial sync is done.

7. **Clamp bounds:** Pan far left/right/up/down -- camera stops at level edges
8. **Info display:** Top bar shows current camera X, Y, Z values updating in real-time
9. **Block placement:** Left-click still places blocks correctly at hovered position
10. **Hover preview:** Wireframe preview cube still follows mouse cursor accurately
