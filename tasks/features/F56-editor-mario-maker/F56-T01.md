# F56-T01: Enemy Palette Tab in EditorUI

**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a level creator, I want to see an INIMIGOS tab in the editor palette with
buttons for each enemy type (Aspirador, Pombo, Abelha), so that I can select
enemies to place in my level just like I select blocks or items.

## Objective

Add a new "INIMIGOS" palette tab to the editor UI between ESPECIAIS and IMG,
with three enemy buttons and an enemy subtype selector pattern. Also extend
the `EditorTool` type union to include the new enemy tool.

## Dev Notes

### EditorTool type extension

File: `packages/frontend/src/game/scenes/EditorUI.tsx` (lines 7-22)

Add a single new tool entry to the `EditorTool` union:

```typescript
| "entity_enemy"
```

This follows the design decision to use a single tool with a subtype state
variable (same pattern as `entity_item_block` + `itemBlockContent`).

### New palette tab: INIMIGOS

File: `packages/frontend/src/game/scenes/EditorUI.tsx`

1. **Update `PaletteTab` type** (line 54):
   Change from `"blocos" | "itens" | "especiais" | "custom"` to
   `"blocos" | "itens" | "especiais" | "inimigos" | "custom"`.

2. **Add ENEMY_PALETTE constant** (after SPECIAL_PALETTE, around line 50):
   ```typescript
   const ENEMY_PALETTE: { subtype: EnemySubtype; label: string; symbol: string }[] = [
     { subtype: "vacuum", label: "Aspirador", symbol: "A" },
     { subtype: "pigeon", label: "Pombo", symbol: "P" },
     { subtype: "bee", label: "Abelha", symbol: "B" },
   ];
   ```
   Import `EnemySubtype` from `@super-mel/shared`.

3. **Update tab bar** (line 137):
   Replace the array `["blocos", "itens", "especiais", "custom"]` with
   `["blocos", "itens", "especiais", "inimigos", "custom"]`.
   For the `inimigos` tab, display label "INIMIGOS" (the existing pattern
   shows custom maps to "IMG" -- add a mapping for inimigos).

4. **Add tab content for INIMIGOS** (after the ESPECIAIS block, around line 248):
   ```tsx
   {activeTab === "inimigos" && (
     <>
       {ENEMY_PALETTE.map((enemy) => (
         <button
           key={enemy.subtype}
           style={{
             ...styles.paletteBtn,
             borderColor:
               selectedTool === "entity_enemy" && enemySubtype === enemy.subtype
                 ? "#fff" : "#555",
             backgroundColor: "#CC2222",
           }}
           onClick={() => {
             onSelectTool("entity_enemy");
             onEnemySubtypeChange(enemy.subtype);
           }}
           title={enemy.label}
         >
           {enemy.symbol}
         </button>
       ))}
     </>
   )}
   ```
