## Dev Notes

### Architecture diagram

File: `docs/diagrams/F56-architecture.mmd`

Create a Mermaid flowchart showing the editor component data flow with the
new F56 additions. Focus on:

1. **EditorWrapper** as the state hub:
   - blocks[], entities[], selectedTool, enemySubtype
   - cameraPos, levelWidth, levelHeight
   - saveEditorState / restoreEditorState cycle

2. **EditorUI** as the input surface:
   - Palette tabs: BLOCOS, ITENS, ESPECIAIS, INIMIGOS, IMG
   - Top bar: Z controls, dimensions (W/H), name, actions (TESTAR, DAQUI, SALVAR, PUBLICAR, VOLTAR)
   - Camera info display

3. **EditorScene3D** as the 3D viewport:
   - Camera controls (keyboard, scroll, middle-drag)
   - Click plane + raycaster
   - Block/entity rendering (including enemy markers by subtype)
   - Hover position tracking

4. **sessionStorage** as the persistence layer:
   - EDITOR_STATE_KEY for state preservation
   - supermel_editor_test_cleared for clear-check
   - supermel_test_level for test data

5. **Data flow arrows**:
   - EditorWrapper -> EditorScene3D (blocks, entities, camera, dimensions)
   - EditorScene3D -> EditorWrapper (hover position, camera changes)
   - EditorWrapper -> EditorUI (all display state)
   - EditorUI -> EditorWrapper (tool selection, resize, test actions)
   - EditorWrapper -> sessionStorage (save before test)
   - sessionStorage -> EditorWrapper (restore on mount)
   - EditorWrapper -> LevelDataV2 -> GameScene3D (test flow)

### User journey diagram

File: `docs/diagrams/F56-journey.mmd`

Create a BPMN-style user flow covering the main F56 scenarios:

1. **Enemy placement flow:**
   Select INIMIGOS tab -> Choose subtype -> Click grid -> Enemy placed -> Test

2. **Camera navigation flow:**
   Pan with WASD -> Zoom with scroll -> Middle-drag to fine-tune -> Place blocks at new position

3. **Test-from-cursor flow:**
   Hover over target position -> Click DAQUI -> Mel spawns at cursor -> Play test -> Return to editor with state preserved

4. **Level resize flow:**
   Change W/H inputs -> Confirmation if shrinking -> Grid resizes -> Place blocks in new area

5. **Edit-test-edit cycle:**
   Edit level -> Click TESTAR -> State saved -> Play test -> Die/clear -> Return to editor -> State restored
