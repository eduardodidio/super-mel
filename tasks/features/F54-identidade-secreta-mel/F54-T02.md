# Task F54-T02 -- Rafa Character Entity (Voxel Boy)

**Feature:** F54
**Wave:** 0
**Type:** frontend / entities
**Depends on:** None (standalone component)
**Status:** planned

## User Story

As a player, I want to see Rafa -- Mel's owner -- as a recognizable character in the end-of-level cutscene so that the story of Mel returning home feels personal and heartwarming.

## Objective

Create a `Rafa` React Three Fiber component that renders a voxel-style boy character built entirely from THREE box primitives (same approach as the existing `Goal.tsx` owner figure, but more detailed and with multiple display states).

## Dev Notes

### 1. Create `packages/frontend/src/game/entities/Rafa.tsx`

This component renders Rafa as a standing voxel boy. It does NOT use physics (`RigidBody`) -- it is a purely visual entity for the cutscene.

### 2. Props

```typescript
interface RafaProps {
  position: [number, number, number];
  state: "idle" | "crouch" | "hug" | "happy";
  facingRight?: boolean;  // default true
}
```

### 3. Visual Design (Voxel Minecraft Style)

Build Rafa from `boxGeometry` meshes, consistent with the existing Goal entity's voxel person but with more color and personality:

**Head** (0.5 x 0.5 x 0.45):
- Skin color: `#DEB887` (same as Goal entity head)
- Hair on top: small dark brown box `#4a3728` (0.5 x 0.15 x 0.45) on top of head
- Two small black cubes for eyes (0.06 x 0.06 x 0.02) on front face

**Body/Torso** (0.5 x 0.7 x 0.35):
- T-shirt color: `#E74C3C` (red, kid-friendly)

**Arms** (0.18 x 0.6 x 0.25 each):
- Same red as torso
- Position at sides: x = +/-0.34

**Legs** (0.22 x 0.55 x 0.3 each):
- Pants color: `#3498DB` (blue jeans)
- Position: x = +/-0.13, below torso

**Shoes** (0.24 x 0.12 x 0.35 each):
- Color: `#2C3E50` (dark)

### 4. State Animations

Each state changes arm/body position. Use `useFrame` for smooth interpolation:

- **idle**: Arms at sides, slight breathing bob (y oscillation 0.02 amplitude, 1Hz)
- **crouch**: Body translates down 0.3 units, knees bend (legs rotate slightly). Used when Mel arrives at the door.
- **hug**: Arms rotate forward ~60 degrees (reaching down to hug Mel). Body crouches slightly.
- **happy**: Arms raised up ~45 degrees in celebration. Small vertical bounce (0.05 amplitude, 3Hz).

Use refs for arm group rotation and body position. Lerp between target values for smooth transitions between states.

### 5. Scale

Rafa should be about 1.8 blocks tall (total mesh height ~1.8 units). This makes him taller than Mel (~1.2 units from sprite proportions) -- a kid, not an adult.

### Relevant Files

- `packages/frontend/src/game/entities/Goal.tsx` -- primary reference for voxel person construction from box geometries
- `packages/frontend/src/game/entities/Checkpoint.tsx` -- reference for animated materials and state transitions

### Gotchas

- Use `useMemo` for all `MeshStandardMaterial` instances to avoid per-frame allocation.
- All meshes should have `castShadow` enabled.
- The component must handle `facingRight` by applying `scale.x = -1` on the root group when facing left.
- Keep materials simple -- `roughness: 0.7`, no emissive (Rafa is not a glowing entity). Rafa is a normal kid.
- State transitions should be smooth (lerp over ~0.3s) not instant -- use `useFrame` with `THREE.MathUtils.lerp`.
