# Task F54-T03 -- HidingSpot + MelHouse (Cutscene Stage Meshes)

**Feature:** F54
**Wave:** 0
**Type:** frontend / entities
**Depends on:** None (standalone components)
**Status:** planned

## User Story

As a player, I want to see a recognizable home environment in the end-of-level cutscene -- a bush to hide behind and a house with a door -- so that the scene of Mel sneaking home feels natural and charming.

## Objective

Create two React Three Fiber components: `HidingSpot` (a bush or large object Mel walks behind to remove her cape) and `MelHouse` (a simple house with an animated door). Both are purely visual -- no physics.

## Dev Notes

### Part A: HidingSpot.tsx

#### 1. Create `packages/frontend/src/game/entities/HidingSpot.tsx`

```typescript
interface HidingSpotProps {
  position: [number, number, number];
  variant?: "bush" | "doghouse";  // default "bush"
  showCape?: boolean;  // when true, a small folded cape appears behind the bush
}
```

#### 2. Bush Variant (default)

Build a round bush from overlapping spheres with a leaf-green material:

- **Base sphere** (radius 0.8): position [0, 0.6, 0], color `#2E8B57` (sea green)
- **Top sphere** (radius 0.6): position [0.1, 1.2, 0.1], color `#3CB371` (medium sea green)
- **Side sphere** (radius 0.5): position [-0.3, 0.7, 0.2], color `#228B22` (forest green)
- All meshes use `SphereGeometry` with `widthSegments: 8, heightSegments: 6` (low-poly voxel-ish feel)
- Roughness: 0.9 (matte foliage)
- Subtle wind sway: root group rotation.z oscillates +/- 0.02 radians at 0.8Hz via `useFrame`

#### 3. Doghouse Variant

Reuse the existing `Checkpoint.tsx` doghouse visual but without physics/sensor:

- Same wall, roof, and base geometry as Checkpoint
- No flag pole, no sensor, no glowing materials
- Slightly larger scale (1.2x) to serve as a hiding spot

#### 4. Cape Prop

When `showCape={true}`, render a small folded cape behind the bush:

- Small red/magenta plane (0.3 x 0.15) at ground level behind the bush
- Color: `#DC143C` (crimson -- Mel's hero cape color)
- Slightly crumpled look: rotate it 10 degrees on X and 5 degrees on Z
- Z-position behind the bush (z = -0.3) so it peeks out slightly

### Part B: MelHouse.tsx

#### 1. Create `packages/frontend/src/game/entities/MelHouse.tsx`

```typescript
interface MelHouseProps {
  position: [number, number, number];
  doorOpen: boolean;  // animates door rotation
  doorProgress?: number;  // 0..1, optional override for fine control
}
```

#### 2. Visual Design

A simple house built from box geometries. Should look cozy and domestic:

**Walls** (2.5 x 2.0 x 2.0):
- Color: `#FAEBD7` (antique white -- cream colored walls)
- Roughness: 0.8

**Roof** -- two angled boxes forming a triangle:
- Color: `#B22222` (firebrick red roof)
- Similar to Checkpoint roof but larger
- Each side: (1.6 x 0.12 x 2.2), rotated +/- 0.5 radians on Z

**Door** (0.6 x 1.2 x 0.08):
- Color: `#8B4513` (saddle brown)
- Positioned at front face of house, slightly left of center
- Pivot point at left edge (so it swings open to the left)
- **Animation:** when `doorOpen` changes from false to true, rotate the door on Y axis from 0 to -PI/2 (90 degrees open). Use `useFrame` + lerp over ~0.5s.

**Window** (0.5 x 0.5 x 0.05):
- Color: `#87CEEB` (light sky blue)
- Emissive: `#FFE4B5` (warm glow from inside), emissiveIntensity: 0.3
- Positioned above and to the right of the door
- Warm point light inside (color `#FFE4B5`, intensity 0.3, distance 3) visible through the window

**Doorframe** (0.7 x 1.3 x 0.04):
- Color: `#654321` (darker brown)
- Behind the door mesh

**Pet door** (small):
- Optional: a small flap at the bottom of the door (0.3 x 0.35 x 0.04) in slightly different brown
- This is where Mel enters conceptually

**Chimney** (0.3 x 0.6 x 0.3):
- On the roof, offset to one side
- Color: `#A0522D` (sienna)

#### 3. Door Animation

```typescript
const doorRotationRef = useRef(0);
const targetRotation = doorOpen ? -Math.PI / 2 : 0;

useFrame((_, delta) => {
  doorRotationRef.current = THREE.MathUtils.lerp(
    doorRotationRef.current,
    targetRotation,
    delta * 4
  );
  doorGroupRef.current.rotation.y = doorRotationRef.current;
});
```

The door group's pivot is at its left edge (translate geometry so the left edge is at origin, then rotate the group).

### Gotchas

- Use `useMemo` for all materials.
- Both components are purely visual -- no RigidBody, no physics.
- The bush must be tall enough (about 1.5 units) to visually occlude Mel's sprite (~1.2 units).
- The house should face the camera (front face at z > 0, door visible).
- Door pivot: translate door geometry by `[0.3, 0, 0]` so the left edge is at the group origin, then rotate the group on Y.
- The window's warm glow should be subtle -- this is a cozy home, not a spotlight.
