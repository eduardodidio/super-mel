# Task F54-T06 -- EndLevelCutscene Scene Assembly

**Feature:** F54
**Wave:** 2
**Type:** frontend / scenes
**Depends on:** T01 (CutsceneEngine), T02 (Rafa), T03 (HidingSpot + MelHouse), T04 (Mel sprites + cape), T05 (useGameState cutscene flow)
**Status:** planned

## User Story

As a player, after completing a level I want to watch a charming cutscene where Mel sneaks home, removes her hero cape behind a bush, enters her house, and hugs her owner Rafa -- making me smile every time.

## Objective

Create the `EndLevelCutscene` React Three Fiber component that orchestrates the full end-of-level cutscene using the CutsceneEngine, rendering the stage (HidingSpot, MelHouse, Rafa) and animating Mel's sprite through the sequence.

### 3. Scene Layout (Stage)

The cutscene takes place on a small stage, viewed from a fixed side-view camera:

```
Camera at [5, 3, 12], looking at [5, 2, 0]

                 [House]        [Bush]
                 with door      hiding spot

    |            |  D  |        (())        |
    |    Rafa--> | oor |        (\/)        |  <-- Mel enters from right
    |            |_____|        bush        |
    =============================================  ground
    x=0          x=3            x=7             x=12
```

- **Ground plane**: a flat box (14 x 0.2 x 4) at y=0, color `#4a7a3a` (grass green)
- **MelHouse**: positioned at [3, 0, 0], facing right (door on right side)
- **HidingSpot** (bush): positioned at [7, 0, 0]
- **Rafa**: positioned at [3.5, 0, 0], facing right, starts in `state="idle"` inside the doorway
- **Mel sprite**: starts off-screen at [13, 0.7, 0.1], walks left

### 4. Camera Setup

Use a fixed perspective camera for the cutscene (not the gameplay CameraRig):

```typescript
// In the Canvas, this component sets its own camera
<PerspectiveCamera makeDefault position={[5, 3, 12]} fov={50} />
```

The camera looks at [5, 2, 0] -- centered on the stage.

### 5. Cutscene Steps (using CutsceneEngine)

Define the cutscene as a `CutsceneStep[]` array:

**Step 0 -- "entrance" (1.5s):**
- Mel sprite appears at x=12, walks left at speed 3 units/s
- Cape overlay is visible, fluttering
- Animation: `walk_slow`
- Mel moves from x=12 to x~7.5 (near the bush)

**Step 1 -- "approach_bush" (1.0s):**
- Mel continues walking left toward the bush center (x=7)
- Speed slows to 2 units/s
- Animation: `walk_slow`

**Step 2 -- "behind_bush" (0.8s):**
- Mel moves behind the bush (z-position moves to -0.5, behind bush mesh)
- At start: cape overlay becomes hidden
- Mel sprite is occluded by the bush (z-ordering)
- Animation switches to `peek` (looking left and right)

**Step 3 -- "cape_drop" (0.8s):**
- Still behind bush
- Small cape drop animation: a red plane falls from Mel's position to ground level behind the bush
- Bush's `showCape` prop set to true at end of step
- Audio cue: soft fabric sound (or none -- no audio dependency in this task)

**Step 4 -- "emerge" (0.8s):**
- Mel emerges from left side of bush (z back to 0.1)
- No cape overlay (hidden since step 2)
- Animation: `walk_slow`
- Mel walks from x=7 toward x=4 (near the house door)

**Step 5 -- "approach_door" (1.2s):**
- Mel walks from x=4 to x=3.5 (house door position)
- MelHouse `doorOpen` set to true (door swings open)
- Rafa state changes from `idle` to `crouch` (bending down to greet Mel)

**Step 6 -- "enter_house" (0.8s):**
- Mel walks through the door (x moves from 3.5 to 2.5)
- Mel's sprite scale shrinks slightly (entering the house, perspective)
- Mel's sprite opacity fades to 0 as she enters (going inside)

**Step 7 -- "hug" (2.0s):**
- Show the `jump_on_owner.png` sprite at the door position (same as current celebration)
- Rafa state changes to `hug`
- Heart particles: spawn 3-4 small heart meshes that float up from the hug position
- After 1.5s within this step: Rafa switches to `happy`

**Step 8 -- "fade_out" (1.5s):**
- Full-screen black overlay fades in (opacity 0 -> 1 over 1.5s)
- At end: trigger `onComplete()`

**Total: ~10.4s** (skippable at any point)

### 6. Mel Sprite Rendering in Cutscene

Use the `SpriteAnimator` functions (`getFrame`, `getFrameAspectRatio`) to render Mel as a `<sprite>` element:

```typescript
// In the render loop
const melAnimName = melAnimRef.current;  // "walk_slow", "peek", etc.
const texture = getFrame(melAnimName, melAnimElapsed.current);

<sprite
  position={[melXRef.current, melYRef.current, melZRef.current]}
  scale={[melScaleRef.current * aspectRatio, melScaleRef.current, 1]}
>
  <spriteMaterial
    map={texture}
    transparent
    opacity={melOpacityRef.current}
  />
</sprite>
```

Flip the sprite horizontally when Mel is walking left (scale.x negative or use `material.rotation`).

### 7. Heart Particles

During the hug step, spawn simple heart particles:

```typescript
// Heart mesh: extruded heart shape, or simpler: two spheres + triangle
// For simplicity, use emoji-like text sprites or small red cubes
// that float up with y += delta * 2 and fade out
```

Use 3-4 small red meshes (box 0.15 x 0.15 x 0.05, color `#FF6B6B`) that:
- Spawn at the hug position
- Float up (y += delta * 1.5)
- Drift slightly left/right (random x offset)
- Fade out (opacity 1 -> 0 over 1.5s)
- Despawn when opacity hits 0

### 8. Skip Handling

- Listen for keydown (any key) and touch/click events
- After 1 second of cutscene, show a small hint: "Pressione para pular" (monospace, bottom-center, semi-transparent)
- On input: call `onSkip()`

```typescript
useEffect(() => {
  let canSkip = false;
  const timer = setTimeout(() => { canSkip = true; }, 1000);

  const handleSkip = () => {
    if (canSkip) {
      engine.skip();
      onSkip();
    }
  };

  window.addEventListener("keydown", handleSkip);
  window.addEventListener("pointerdown", handleSkip);

  return () => {
    clearTimeout(timer);
    window.removeEventListener("keydown", handleSkip);
    window.removeEventListener("pointerdown", handleSkip);
  };
}, []);
```

### Gotchas

- The cutscene runs inside the existing R3F Canvas with Physics. Since there are no physics bodies in the cutscene, Physics is effectively idle. This is fine.
- Mel's sprite needs to be flipped when walking left. Use negative scale.x on the sprite.
- The `jump_on_owner.png` texture is already loaded by `GameScene3D`. In the cutscene, load it fresh with `TextureLoader` (it will be GPU-cached).
- The fade-out is an HTML overlay on top of the Canvas, not a 3D effect. It is a `<div>` with `position: absolute` and animated opacity.
- Use `useFrame` to drive the CutsceneEngine's `update(delta)` call.
- All animated values (melX, melY, melZ, melOpacity, etc.) should use refs, not state, to avoid re-renders on every frame.
- Clean up event listeners in the useEffect return.
