# Task F32-T01 — Tornar sand e dirt solid

**Feature:** F32
**Wave:** 0
**Type:** shared (types)
**Depends on:** (none)
**Status:** done

## User Story

As a player, I want Mel to land and walk on sand and dirt blocks so that the terrain behaves as solid ground instead of being passable.

## Objective

Alterar `BLOCK_PROPERTIES` para que `sand` e `dirt` tenham `solid: true`, fazendo com que o Block.tsx crie colliders fisicos (nao-sensor) para esses blocos.

## Dev Notes

- Arquivo: `packages/shared/src/types.ts`
- Secao: `BLOCK_PROPERTIES` (linhas 80-92)

### Alteracoes exatas

**Linha 82 — sand:**
```diff
- sand: { solid: false, destructible: false, dangerous: false, platform: false },
+ sand: { solid: true, destructible: false, dangerous: false, platform: false },
```

**Linha 85 — dirt:**
```diff
- dirt: { solid: false, destructible: false, dangerous: false, platform: false },
+ dirt: { solid: true, destructible: false, dangerous: false, platform: false },
```

### Por que funciona

1. `Block.tsx:65` usa `sensor={!props.solid && !props.dangerous}`:
   - Com `solid: true` → `sensor=false` → collider fisico real
   - Mel nao atravessa mais o bloco

2. `Mel.tsx:96-99` ray cast com `solid=true` (3o arg):
   - Rapier `castRay` com solid=true so detecta colliders nao-sensor
   - Com dirt/sand agora solidos, o ray cast detecta o chao corretamente
   - `grounded.current` fica true, habilitando pulo, resetando fly timer, etc.

3. `ChunkGenerator.ts:77` gera dirt como camada de superficie:
   - Agora o chao do jogo inteiro se torna solido

### O que NAO alterar

- `water`: deve permanecer `solid: false` (player nada/atravessa)
- `lava`: `solid: false, dangerous: true` → sensor=false por causa de dangerous → ja funciona
- `leaf`: `solid: false, platform: true` → mecanica de plataforma propria
