# Task F39-T05 — "Como Jogar" screen with control illustrations

**Feature:** F39
**Wave:** 1
**Type:** frontend (component)
**Depends on:** F39-T03 (PauseOverlay as mount point), F39-T01 (lastInputType in zustand)
**Status:** planned

## User Story

As a new player, I want to see a clear explanation of the controls with visual aids so I can learn how to play without trial and error.

## Objective

Create a `ComoJogarScreen.tsx` component that displays control illustrations for the current input type (keyboard, touch, gamepad). Accessible from the Pause menu via the "COMO JOGAR" button.

### 1. ComoJogarScreen component

```typescript
interface ComoJogarScreenProps {
  onBack: () => void;
}
```

**Layout:**

- Full-screen overlay (same `rgba(0,0,0,0.8)` background as PauseOverlay)
- Title: "COMO JOGAR" in yellow
- Content card centered, max-width ~500px
- Tab-like buttons at top to switch between Keyboard / Touch / Gamepad views
  - Default to `lastInputType` from zustand
  - Player can tap the other tabs to see other control schemes
- VOLTAR button at bottom — calls `onBack`
- `zIndex: 55` (above PauseOverlay at 50)

**Keyboard controls section:**

```
MOVER           A / D  ou  Setas
PULAR           Space
VOAR            Segurar Space (no ar)
ABAIXAR         S / Seta Baixo
OLHAR PRA CIMA  W / Seta Cima
ATIRAR          Z / J
PAUSAR          Esc
```

**Touch controls section:**

```
MOVER           D-pad esquerdo
PULAR / VOAR    Botao A (segurar = voar)
ATIRAR          Botao B
PAUSAR          (nao disponivel via touch — use Esc)
```

**Gamepad controls section:**

```
MOVER           D-pad / Analogico esquerdo
PULAR / VOAR    A / X (segurar = voar)
ATIRAR          X / Quadrado
PAUSAR          Start
```

**Visual style:**

- Each row: action label on left (bold, colored), key/button label on right (monospace, lighter color)
- Rows separated by subtle horizontal lines or spacing
- Use Unicode symbols for keys where helpful:
  - Arrows: ← → ↑ ↓
  - Gamepad: standard text labels (A, B, X, Y, Start)
- No images needed — pure text/CSS layout (matches minimalist game aesthetic)

### 2. Wire into Game3D pause sub-screen system

In Game3D.tsx, the `pauseSubScreen` state from T04 controls which sub-screen is shown:

```tsx
{paused && scene === 'playing' && pauseSubScreen === 'comojogar' && (
  <ComoJogarScreen onBack={() => setPauseSubScreen('main')} />
)}
```

When `pauseSubScreen === 'comojogar'`, show ComoJogarScreen instead of (or on top of) PauseOverlay. The PauseOverlay can remain behind it (dimmed), or be hidden — simpler to just show ComoJogarScreen alone.

### 3. Gameplay tips section (optional but nice)

Below the controls, add a "DICAS" (tips) section:

```
- Segure Space para voar por ate 5 segundos!
- Atire na Bola do Infinito para destruir blocos
- Colete coracoes para recuperar vida
- Moedas vermelhas valem pontos — pegue todas!
```

### Design decisions

- **Text-only, no sprites:** Keeps it simple and maintainable. The game has a minimalist pixelated aesthetic — monospace text fits perfectly.
- **Tab switching:** Even though we auto-detect input type, allowing manual tab switch lets curious players see all control schemes.
- **Sub-screen pattern:** ComoJogarScreen is rendered as a sibling to PauseOverlay in Game3D, controlled by local state. No routing needed.
