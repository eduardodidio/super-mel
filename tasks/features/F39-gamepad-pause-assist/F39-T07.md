### 1. useGameFrame hook (useGameFrame.ts)

A thin wrapper around R3F's `useFrame` that scales `delta` by `gameSpeed`:

```typescript
import { useFrame } from '@react-three/fiber';
import { useAssistMode } from './useAssistMode';
import { useGameState } from './useGameState';

type FrameCallback = (state: any, delta: number) => void;

export function useGameFrame(callback: FrameCallback, priority?: number): void {
  useFrame((state, delta) => {
    // Skip if paused
    if (useGameState.getState().paused) return;

    // Scale delta by game speed
    const gameSpeed = useAssistMode.getState().gameSpeed;
    const scaledDelta = delta * gameSpeed;

    callback(state, scaledDelta);
  }, priority);
}
```

**Usage:** Replace `useFrame` with `useGameFrame` in all gameplay components:
- `Mel.tsx`
- `ProjectileManager.tsx`
- `CameraRig.tsx` (optional — camera could run at full speed for smoother feel)
- Any other component with gameplay-tied `useFrame`

This also incorporates the pause guard from T04, so T04 and T07 both affect the same `useFrame` calls. The developer implementing T07 should ensure the pause guard and speed scaling are both present. If T04 was implemented first with inline `if (paused) return`, T07 replaces that pattern with `useGameFrame`.

### 2. Invincibility (Mel.tsx / GameScene3D.tsx)

In `GameScene3D.tsx`, the `handleDamage` callback currently checks `invincibleRef`:

```typescript
const handleDamage = useCallback(() => {
  if (invincibleRef.current) return;
  loseLife();
  invincibleRef.current = true;
  window.setTimeout(() => {
    invincibleRef.current = false;
  }, INVINCIBILITY_MS);
}, [loseLife]);
```

Add assist mode check:

```typescript
const assistInvincible = useAssistMode((s) => s.invincible);

const handleDamage = useCallback(() => {
  if (invincibleRef.current || assistInvincible) return;
  loseLife();
  invincibleRef.current = true;
  window.setTimeout(() => {
    invincibleRef.current = false;
  }, INVINCIBILITY_MS);
}, [loseLife, assistInvincible]);
```

Also pass `invincible={invincibleRef.current || assistInvincible}` to `<Mel>` so the blinking effect does NOT activate for assist mode invincibility (we do NOT want Mel to blink permanently):

```tsx
<Mel
  controlsRef={controlsRef}
  invincible={invincibleRef.current}  // Only flash on damage, not assist mode
  // ...
/>
```

The assist invincibility is "silent" — no visual indicator on Mel herself. The damage simply does not register.

### 3. Unlimited flight (Mel.tsx)

In `Mel.tsx`, the flight timer check at line ~164:

```typescript
if (flyTimer.current >= MAX_FLY_TIME) {
  flying.current = false;
}
```

Add assist mode bypass:

```typescript
const unlimitedFlight = useAssistMode.getState().unlimitedFlight;
if (flyTimer.current >= MAX_FLY_TIME && !unlimitedFlight) {
  flying.current = false;
}
```

Read via `getState()` inside `useFrame` to avoid re-renders. The fly timer still counts for the stamina bar display, but it never triggers the cutoff.

Also, for the stamina bar: when unlimited flight is active, report timeRemaining as MAX_FLY_TIME (always full) so the bar stays full:

```typescript

  ? MAX_FLY_TIME

onFlyStateUpdate?.(flying.current, reportedTime);
```

### Gotchas

- **Circular dependency risk:** `useGameFrame` imports `useAssistMode` and `useGameState`. These must not import `useGameFrame`. Check the dependency graph.
- **`getState()` vs selector:** Inside `useFrame`/`useGameFrame` callbacks, always use `getState()` to avoid R3F component re-renders. Outside (React render), use selectors.
- **Speed scaling affects physics feel:** At 70% speed, Mel's jump height is the same (velocity is the same) but she hangs in the air longer. Rapier physics runs at real-time; only the `delta` in `useFrame` is scaled. Rapier's own `timeStep` is NOT scaled. This means:
  - Rapier steps normally (gravity applies normally)
  - Only movement logic in `useFrame` (acceleration, friction, jump force) is slowed
  - This might feel slightly inconsistent. **Alternative:** Scale `world.timestep` in Rapier too.
  - **Recommendation:** Scale both. In Game3D.tsx, pass `timeStep` to Physics:
    ```tsx
    <Physics gravity={[0, -15, 0]} paused={paused} timeStep={1/60 * gameSpeed}>
    ```
    This scales the physics simulation step itself, making everything consistently slower.
- **5 hearts display:** Hearts need to fit on small screens. 5 hearts at 24px = 120px + gaps. Should be fine.
