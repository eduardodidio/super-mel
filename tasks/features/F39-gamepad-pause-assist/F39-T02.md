# Task F39-T02 — Input type detection + HUD hint switching

**Feature:** F39
**Wave:** 1
**Type:** frontend (UI)
**Depends on:** F39-T01 (lastInputType in zustand, gamepadConnected)
**Status:** planned

## User Story

As a player, I want the on-screen controls hint to show the correct button labels for whatever input device I am currently using, so I am not confused by irrelevant key names.

## Objective

1. Update HUD3D.tsx to read `lastInputType` from zustand and display appropriate control labels.
2. Update TouchControls3D.tsx to hide when a gamepad is connected.
3. Set `lastInputType` to `'touch'` when touch controls are used.

### 1. HUD3D — Dynamic controls hint (HUD3D.tsx)

Currently the controls hint is hardcoded at line 158:

```tsx
<span style={styles.controls}>
  A/D = andar &nbsp; Space = pular &nbsp; Z = atirar
</span>
```

Replace with a function that returns the correct hint:

```typescript
function getControlsHint(inputType: InputType): string {
  switch (inputType) {
    case 'keyboard':
      return 'A/D = andar   Space = pular   Z = atirar';
    case 'touch':
      return 'D-pad = andar   A = pular   B = atirar';
    case 'gamepad':
      return '\u{1F3AE} Stick = andar   A = pular   X = atirar   Start = pausar';
    default:
      return 'A/D = andar   Space = pular   Z = atirar';
  }
}
```

Read `lastInputType` from zustand inside HUD3D:

```typescript
import { useGameState, type InputType } from '../hooks/useGameState';

export function HUD3D({ lives, score, coins, scene, isFlying, flyTimeRemaining }: HUD3DProps) {
  const lastInputType = useGameState((s) => s.lastInputType);
  // ...
  <span style={styles.controls}>
    {getControlsHint(lastInputType)}
  </span>
```

Note: Use text labels, not actual emoji/icons for the gamepad hint (except the gamepad emoji prefix which is optional). Keep it monospace-friendly.

### 3. Touch input type tracking (TouchControls3D.tsx)

In the `set` function that handles touch events, add input type tracking:

```typescript
const set = (key: keyof Controls, value: boolean) => (e: React.TouchEvent | React.MouseEvent) => {
  e.preventDefault();
  e.stopPropagation();
  if (controlsRef.current) controlsRef.current[key] = value;
  // Track touch input type
  if (value) {
    const state = useGameState.getState();
    if (state.lastInputType !== 'touch') {
      state.setLastInputType('touch');
    }
  }
};
```

### Design decisions

- Only switch `lastInputType` when an input is actually pressed (not on release) to avoid flicker.
- The zustand selector `(s) => s.lastInputType` ensures HUD3D only re-renders when the input type actually changes, not every frame.
- Gamepad hint includes "Start = pausar" since that is unique to gamepad.
