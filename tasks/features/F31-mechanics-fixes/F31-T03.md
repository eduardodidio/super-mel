## User Story

As a player, I want the Bola do Infinito to travel exactly 10 blocks so that the attack has a balanced range.

## Objective

Ajustar o alcance do projetil de 45 blocos (SPEED=15 * LIFETIME=3) para 10 blocos. Manter velocidade visual agradavel.

## Dev Notes

- Arquivo: `packages/frontend/src/game/entities/Projectile.tsx`
- Secao a editar: **Constantes (linhas 15-20)**

### Calculo

- 1 bloco = 1 world unit (Block.tsx: `boxGeometry args={[1, 1, 1]}`)
- Alcance desejado: 10 blocos = 10 world units
- Opcao escolhida: SPEED = 15 (manter velocidade rapida), LIFETIME = 10/15 = 0.667s
- Alternativa: SPEED = 10, LIFETIME = 1.0 (projetil mais lento mas vive mais)

**Recomendacao:** Usar SPEED = 15, LIFETIME = 0.667 para manter a sensacao rapida do ataque.

### Codigo atual (linhas 15-20):
```typescript
const SPEED = 15;

// Scale interpolation for the bark wave sprite
const SCALE_START = 0.8;
const SCALE_END = 1.5;
const LIFETIME = 3; // seconds
```

### Codigo novo:
```typescript
const SPEED = 15;

// Scale interpolation for the bark wave sprite
const SCALE_START = 0.8;
const SCALE_END = 1.5;
const LIFETIME = 10 / SPEED; // ~0.667s = 10 blocks range
```

### Impacto na animacao de escala

A interpolacao de escala usa `lifeRef.current / LIFETIME` (linha 75). Com LIFETIME menor, o sprite vai escalar mais rapido de SCALE_START(0.8) para SCALE_END(1.5). Isso e aceitavel — o projetil vive menos tempo, entao a escala muda mais rapido proporcionalmente.
