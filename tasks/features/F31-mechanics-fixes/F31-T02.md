# Task F31-T02 — Fix Colisao (Explicit CuboidCollider)

**Feature:** F31
**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** done

## User Story

As a player, I want Mel to collide properly with solid blocks so that I can walk on platforms and bump into walls.

## Objective

Trocar o `colliders="cuboid"` auto-gerado do RigidBody por um `CuboidCollider` explicito com dimensoes corretas (0.3, 0.45, 0.25 = metade de 0.6, 0.9, 0.5), garantindo que Mel colida com blocos solidos.

## Dev Notes

- Arquivo: `packages/frontend/src/game/entities/Mel.tsx`
- Secao a editar: **JSX return (linhas 255-284)**
- NAO alterar a secao useFrame (linhas 79-253). T01 cuida dessa parte.

### Problema

O RigidBody usa `colliders="cuboid"` que auto-gera um cuboid a partir de TODOS os meshes filhos. Existem 2 meshes:
1. Sprite plane: `scale={[SPRITE_WIDTH(2.67), SPRITE_HEIGHT(2), 1]}` com `planeGeometry args={[1,1]}`
2. Invisible box: `boxGeometry args={[0.6, 0.9, 0.5]}`

O auto-collider esta provavelmente usando o sprite plane (muito maior) como base, criando um collider gigante que causa comportamento errado de colisao.

### Solucao

1. Importar `CuboidCollider` de `@react-three/rapier`
2. Mudar `colliders="cuboid"` para `colliders={false}` no RigidBody
3. Adicionar `<CuboidCollider args={[0.3, 0.45, 0.25]} />` como filho direto do RigidBody
4. Remover o mesh invisivel (nao serve mais como guia de collider)

- Import atual (linha 3):
```typescript
import { RigidBody, type RapierRigidBody, useRapier } from "@react-three/rapier";
```
- Import novo:
```typescript
import { RigidBody, CuboidCollider, type RapierRigidBody, useRapier } from "@react-three/rapier";
```

- JSX atual (linhas 255-284):
```tsx
<RigidBody
  ref={rigidBodyRef}
  position={[2, 5, 0]}
  mass={1}
  linearDamping={0}
  lockRotations
  enabledTranslations={[true, true, false]}
  colliders="cuboid"
  name="mel"
  friction={0}
>
  <mesh ref={spriteRef} position={[0, 0.3, 0]} scale={[SPRITE_WIDTH, SPRITE_HEIGHT, 1]}>
    <planeGeometry args={[1, 1]} />
    <meshStandardMaterial transparent alphaTest={0.1} side={THREE.DoubleSide} roughness={1} metalness={0} />
  </mesh>
  <mesh visible={false}>
    <boxGeometry args={[0.6, 0.9, 0.5]} />
    <meshBasicMaterial />
  </mesh>
</RigidBody>
```

- JSX novo esperado:
```tsx
<RigidBody
  ref={rigidBodyRef}
  position={[2, 5, 0]}
  mass={1}
  linearDamping={0}
  lockRotations
  enabledTranslations={[true, true, false]}
  colliders={false}
  name="mel"
  friction={0}
>
  <CuboidCollider args={[0.3, 0.45, 0.25]} />
  <mesh ref={spriteRef} position={[0, 0.3, 0]} scale={[SPRITE_WIDTH, SPRITE_HEIGHT, 1]}>
    <planeGeometry args={[1, 1]} />
    <meshStandardMaterial transparent alphaTest={0.1} side={THREE.DoubleSide} roughness={1} metalness={0} />
  </mesh>
</RigidBody>
```

### Nota sobre ground check raycast

O raycast de ground check (linha 90) usa `pos.y - 0.55` como origem. Com o CuboidCollider de half-height 0.45, a base do collider esta em `pos.y - 0.45`. O ray origin em -0.55 esta 0.1 unidade abaixo da base, e o ray distance e 0.3. Isso deve funcionar corretamente — o ray comeca logo abaixo do collider e detecta o chao ate 0.3 unidades abaixo.
