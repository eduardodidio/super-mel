# Task F44-T07 -- HUD Integration: Power-Up Timer + Equipped Icons

**Feature:** F44
**Wave:** 2
**Type:** frontend
**Depends on:** F44-T04 (ShopOverlay + equipped state), F44-T05 (usePowerUpState), F44-T06 (power-up effects wired)
**Status:** done

## User Story

As a player, I want to see which upgrades I have equipped (2 small icons near my portrait) and a countdown timer when a power-up is active, so I know what abilities are affecting my gameplay and how much time is left.

## Objective

Add two HUD elements to `HUD3D.tsx`: (1) equipped upgrade icons near Mel's portrait, and (2) a `PowerUpHUD` component showing the active power-up icon + timer bar.

## Dev Notes

### 1. Create `packages/frontend/src/game/systems/PowerUpHUD.tsx`

A self-contained component that reads `usePowerUpState` and renders a timer bar:

```
  [ICON] [==========---] 6.2s
```

Layout:
- Positioned below the hearts/coins row, or in the center of the screen just below the controls hint
- Shows ONLY when a power-up is active (`activePowerUp !== null`)
- Icon: a colored circle/square matching the power-up's color
- Label: power-up name from `POWER_UP_DEFS[type].label`
- Timer bar: fill ratio = `timeRemaining / totalDuration`, color = power-up color
- Timer text: `timeRemaining.toFixed(1)` + "s"
- When `timeRemaining < 3`, the bar and icon should pulse/blink to warn the player

Style reference: Use the same pattern as `StaminaBar` in `HUD3D.tsx` (lines 39-131). The PowerUpHUD is similar in concept -- a bar that drains over time.

### 2. Equipped upgrade icons in HUD3D.tsx

Near the portrait (top-left area), show 2 small icons representing the equipped upgrades:

```
  [Portrait] [Heart Heart Heart] [Coins: 42]
             [Slot1] [Slot2]           <-- NEW
             [FLY ===== 3.2s]
```

For each equipped upgrade:
- Show a small colored square (12x12 px) with a 1-letter abbreviation or icon:
  - `extra_heart`: red square, "+"
  - `fly_boost`: blue square, "F"
  - `coin_magnet`: magnet red, "M"
  - `double_ball`: gold square, "2"
  - `double_jump`: green square, "J"
  - `turbo_cape`: cyan square, "T"
  - `gentle_fall`: white square, "P" (paraquedas)
- Tooltip on hover (desktop): upgrade name
- Empty slots: show a faint gray square with "--"

Read from `useShopState((s) => s.equipped)`.

### 3. Integrate into HUD3D.tsx

Modify `HUD3D.tsx`:

- Import `PowerUpHUD` and render it inside the container
- Import `useShopState` and read `equipped` for the upgrade icons
- Position the power-up timer bar on the left side, below the fly stamina bar
- Position the equipped icons below the hearts row

The HUD should remain clean and not feel cluttered. Keep icons small (12-16px). The power-up timer only appears during gameplay when active, so it's not permanent visual noise.

### 4. Update StaminaBar for dynamic maxFlyTime

The existing `StaminaBar` calculates ratio as `flyTimeRemaining / 5` (hardcoded). With the `fly_boost` upgrade, max fly time can be 8s:

```typescript
// In StaminaBar:
const maxFlyTime = useResolvedConfig().maxFlyTime ?? 5;
const ratio = flyTimeRemaining / maxFlyTime;
```

Or pass `maxFlyTime` as a prop from `HUD3D`. The prop approach is simpler and avoids importing the resolved config hook:

```typescript
function StaminaBar({ isFlying, flyTimeRemaining, maxFlyTime = 5 }: {
  isFlying: boolean;
  flyTimeRemaining: number;
  maxFlyTime?: number;
}) {
  // ...
  const ratio = flyTimeRemaining / maxFlyTime;
  // ...
}
```

Wire it from `Game3D.tsx` or `HUD3D` by reading the resolved config.

### Gotchas

- **PowerUpHUD visibility.** It should only render when `activePowerUp !== null`. When no power-up is active, it should be completely hidden (not just invisible -- no DOM element).
- **Timer blink at low time.** When `timeRemaining < 3`, use `Math.sin(time * 8) > 0` for a blink effect, similar to Mel's invincibility blink. This gives the player a clear "about to expire" warning.
- **StaminaBar ratio fix.** If the fly_boost is equipped, the stamina bar must reflect the new max time. A bar that shows "full" at 5s when max is 8s would be confusing. Make sure the `flyTimeRemaining` value from `Mel.tsx` also reports based on the new max (it should, since T03 wires Mel to use `configRef.current.maxFlyTime`).
- **Re-render performance.** `usePowerUpState` updates every frame via `tick()`. The `PowerUpHUD` subscribes to `timeRemaining` which changes every frame when active. This is acceptable for a small HTML element (like StaminaBar which has the same pattern). Use `style` with inline transforms for the bar width rather than expensive re-layout.
- **Mobile layout.** On small screens, the equipped icons should not push other HUD elements off-screen. Consider hiding the equipped labels on narrow viewports (< 400px) and showing only the colored squares.
