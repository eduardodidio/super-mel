# Task F44-T04 -- Shop UI Overlay (ShopOverlay.tsx)

**Feature:** F44
**Wave:** 1
**Type:** frontend
**Depends on:** F44-T02 (useShopState)
**Status:** done

## User Story

As a player, I want to open a shop from the main menu, see upgrades I can buy with my coins, purchase them, and equip 2 at a time so that I can customize my gameplay experience.

## Objective

Build the `ShopOverlay` component -- a full-screen overlay accessible from the menu. It displays the upgrade catalog, coin balance, purchase/equip/unequip buttons, and the 2 equipment slots. Wire the "LOJA" button in `Game3D.tsx`'s menu.

### 2. Catalog display

Read `UPGRADE_CATALOG` from `@super-mel/shared`. For each upgrade:
- Show name, description, price
- If NOT purchased: show "COMPRAR" button (disabled if coins insufficient, with reduced opacity)
- If purchased but NOT equipped: show "EQUIPAR" button
- If purchased AND equipped: show "REMOVER" button + "EQUIPADO (Slot 1/2)" label
- Visual differentiation: purchased items have a green check, equipped items have a yellow border/glow

### 3. Equipment slots UI

Show 2 slots at the top:
- Each slot shows the upgrade name (or "vazio" if empty)
- Clicking an empty slot does nothing (equip from the catalog list)
- Clicking an occupied slot unequips it

When equipping and both slots are full, prompt the player to unequip one first (or auto-replace the first slot -- keep it simple for kids).

### 4. Wire into Game3D.tsx

Add "LOJA" button to the menu overlay (between "RANKING" and "TEMA"):

```tsx
<button style={styles.btn} onClick={() => setShowShop(true)}>
  LOJA
</button>
```

Use a local boolean state `showShop` instead of a new GameScene to avoid complexity. When `showShop` is true, render `<ShopOverlay onClose={() => setShowShop(false)} />` on top of the menu.

Alternatively, if cleaner, add `"shop"` to the `GameScene` union and use `setScene("shop")`. But this adds more wiring -- the boolean approach is simpler and recommended.

### 5. Style conventions

Follow existing overlay styles:
- `position: "absolute"`, full width/height, `pointerEvents: "auto"`
- Background: `rgba(0,0,0,0.85)` (darker than menu's 0.4 to focus attention)
- Font: monospace, white, consistent with `PauseOverlay` / `GameOverOverlay`
- Buttons: same `styles.btn` patterns from `Game3D.tsx`
- Scrollable catalog: `overflowY: "auto"`, `maxHeight: "60vh"`

### 6. Coin balance display

Read `totalCoins` from `useGameState`. Show it prominently at the top-right with the coin icon (same style as HUD).

### 7. Animation/feedback on purchase

When the player successfully purchases:
- Brief flash/highlight on the item
- Coin counter updates immediately
- Button changes from "COMPRAR" to "EQUIPAR"

No SFX required for now (SFX system doesn't have a "purchase" sound yet).

### Gotchas

- **Do NOT close the shop on purchase.** The player should be able to buy multiple items and equip them before returning to the menu. Only the "VOLTAR" button closes the overlay.
- **Coin balance must be live.** If the player buys something, the displayed `totalCoins` must update immediately. Use `useGameState((s) => s.totalCoins)` directly.
- **Mobile-friendly.** The shop must be usable on touch screens. Buttons should be large enough (min 44px touch target). Scrolling should work on mobile.
- **Empty state.** If the player has 0 coins and nothing purchased, show a helpful message: "Colete moedas jogando para comprar upgrades!"
