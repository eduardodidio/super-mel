# Task F44-T06 -- Item Block Power-Up Drops + Power-Up Effects Wiring

**Feature:** F44
**Wave:** 2
**Type:** frontend
**Depends on:** F44-T03 (Mel/Projectile wired to config), F44-T05 (PowerUp entity + usePowerUpState)
**Status:** planned

## User Story

As a player, I want item_blocks to sometimes drop power-ups (star, magnet, fire ball, wings) in addition to coins, and I want the active power-up effects to work during gameplay.

## Objective

Extend the item_block hit system in `GameScene3D.tsx` to spawn `PowerUp` entities alongside coins. Wire the power-up timer tick into the game loop. Apply power-up effects to Mel (invincibility, magnet, unlimited fly) and Projectile (fire pass-through).

## Dev Notes

### 1. Modify `GameScene3D.tsx` -- item_block drop logic

Currently, `handleBlockHit` for item_blocks only spawns coins:
```typescript
if (blockType === "item_block") {
  const coinCount = 1 + Math.floor(Math.random() * 3);
  spawnDroppedCoins(blockPos.x, blockPos.y + 1, coinCount, ITEM_BLOCK_POP_VELOCITY);
}
```

Change to a weighted random system:
```typescript
const roll = Math.random();
if (roll < 0.60) {
  // 60% — coins (current behavior)
  const coinCount = 1 + Math.floor(Math.random() * 3);
  spawnDroppedCoins(blockPos.x, blockPos.y + 1, coinCount, ITEM_BLOCK_POP_VELOCITY);
} else if (roll < 0.70) {
  // 10% — heart (heal)
  // Spawn a Heart entity at the position (or call healLife directly for simplicity)
  handleHeartCollected();
} else {
  // 30% — power-up
  const powerUpRoll = Math.random();
  let powerUpType: PowerUpType;
  if (powerUpRoll < 0.33) powerUpType = "star";
  else if (powerUpRoll < 0.60) powerUpType = "coin_magnet_temp";
  else if (powerUpRoll < 0.83) powerUpType = "fire_ball";
  else powerUpType = "wings";

  spawnPowerUp(blockPos.x, blockPos.y + 1.5, powerUpType);
}
```

### 2. Manage spawned power-ups state

Add state for spawned power-up entities (similar to `droppedCoins`):

```typescript
interface SpawnedPowerUp {
  id: string;
  type: PowerUpType;
  position: [number, number, number];
}

const [spawnedPowerUps, setSpawnedPowerUps] = useState<SpawnedPowerUp[]>([]);
const powerUpIdRef = useRef(0);

const spawnPowerUp = useCallback((x: number, y: number, type: PowerUpType) => {
  powerUpIdRef.current++;
  setSpawnedPowerUps(prev => [...prev, {
    id: `pu-${powerUpIdRef.current}`,
    type,
    position: [x, y, 0],
  }]);
}, []);
```

### Gotchas

- **Drop rates are for infinite mode.** In level mode (with item_block entities from the editor), item_block_content entities (from F37) may specify what the block drops. If an `item_block_content` entity with `props.content` exists at the same position, use that instead of the random roll. For now, random rolls apply universally (level-specific content is a future feature).
- **Power-up entity limit.** Cap spawned power-ups at 3 to avoid clutter (same approach as `MAX_DROPPED_COINS = 20`).
- **Star effect vs Assist Mode invincibility.** Both make Mel invincible. They should coexist without conflict. The star adds a gold visual tint; Assist Mode does not. When star expires, invincibility should revert to Assist Mode's setting.
- **Power-up timer vs pause.** The `tick` call is inside a `useFrame` that checks `paused`. This is correct -- power-up timers freeze when paused.
- **DroppedCoin prop change.** `DroppedCoin.tsx` currently hardcodes `COLLECT_RADIUS = 1.2`. Add a `collectRadius` prop with default value 1.2 so it can be overridden by the magnet effect.
