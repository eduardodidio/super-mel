## User Story

As a player, I want to see floating power-up items appear from item_blocks and collect them to gain temporary abilities like invincibility, coin magnet, fire ball, or unlimited wings.

## Objective

Create the `PowerUp` entity component (floating pickup with icon and glow), the `usePowerUpState` Zustand store for tracking the active power-up and its timer, and the `PowerUpType` visual/duration definitions.

## Dev Notes

### 1. Create `packages/frontend/src/game/hooks/usePowerUpState.ts`

```typescript
import { create } from "zustand";
import type { PowerUpType } from "@super-mel/shared";

interface PowerUpState {
  activePowerUp: PowerUpType | null;
  timeRemaining: number;
  totalDuration: number;

  activate: (type: PowerUpType, duration: number) => void;
  tick: (delta: number) => void;
  clear: () => void;
}

export const usePowerUpState = create<PowerUpState>((set, get) => ({
  activePowerUp: null,
  timeRemaining: 0,
  totalDuration: 0,

  activate: (type, duration) => set({
    activePowerUp: type,
    timeRemaining: duration,
    totalDuration: duration,
  }),

  tick: (delta) => {
    const s = get();
    if (!s.activePowerUp) return;
    const remaining = s.timeRemaining - delta;
    if (remaining <= 0) {
      set({ activePowerUp: null, timeRemaining: 0, totalDuration: 0 });
    } else {
      set({ timeRemaining: remaining });
    }
  },

  clear: () => set({ activePowerUp: null, timeRemaining: 0, totalDuration: 0 }),
}));
```

### 3. Create `packages/frontend/src/game/entities/PowerUp.tsx`

Follow the same pattern as `Heart.tsx` and `Coin.tsx`:

```typescript
interface PowerUpProps {
```

Visual design (simple, kid-readable):
- **Star:** Yellow glowing box/sphere, rotating, strong point light
- **Coin Magnet:** Red+Blue box (magnet shape -- or just a red cube with "U" shape from 3 boxes)
- **Fire Ball:** Orange/red sphere with emissive glow, flickering light
- **Wings:** White feather shape (2 angled planes) or white glowing box

All power-ups share:
- `RigidBody type="fixed"`, `sensor`, name="powerup"
- Bob animation: `Math.sin(time * 3) * 0.2` (slightly faster/higher than coins for visibility)
- Point light with the power-up's color, intensity 1.5, distance 4
- `onIntersectionEnter` checks `payload.other.rigidBodyObject?.name === "mel"` and calls `onCollect(id, type)` once (same `collected.current` guard as Coin.tsx)

Power-ups do NOT expire automatically (unlike DroppedCoin). They float in place until collected. The parent (GameScene3D in T06) manages their spawning and cleanup.

Actually, reconsider: power-ups SHOULD expire after 8 seconds to avoid clutter. Add a `lifeRef` and expire with blink animation (like DroppedCoin at LIFETIME - 2):

### 4. Visual differentiation from coins/hearts

Power-ups must be visually distinct from existing collectibles:
- **Larger** than coins: scale ~0.6 to 0.8 (vs coin's 0.7 width)
- **Brighter** glow: stronger emissive and point light
- **Faster** bob: 3 Hz vs coin's 2 Hz
- **Rotating** on Y axis: 4 rad/s (faster than coin's 3 rad/s)
- **"?" icon** is not needed since item_blocks already have the question mark; the power-up that comes out should be self-explanatory by color/shape

### Gotchas

- **Only one active power-up at a time.** Collecting a new power-up replaces the current one. The `activate` action simply overwrites. No stacking.
- **Power-up timer must be ticked by the game loop.** The `tick(delta)` method should be called from `GameScene3D`'s `useFrame` (T06 wiring). Do NOT use `setInterval` -- it doesn't respect pause state.
- **Do NOT apply power-up effects here.** The `PowerUp` entity only handles spawning, visual, collision, and collection. The actual effects (invincibility, magnet radius, fire pass-through, unlimited fly) are applied in `Mel.tsx`, `Projectile.tsx`, and `GameScene3D.tsx` by reading `usePowerUpState.getState()` in their frame loops (T06/T07).
- **Pause-aware:** The bob animation and lifetime timer should check `useGameState.getState().paused` before updating.
