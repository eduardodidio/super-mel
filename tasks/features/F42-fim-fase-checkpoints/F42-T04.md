# Task F42-T04 -- Result Screen (LevelClearOverlay.tsx)

**Feature:** F42
**Wave:** 1
**Type:** frontend
**Depends on:** F42-T03 (useGameState has levelclear scene + level stats fields)
**Status:** planned

## User Story

As a player who just completed a level, I want to see a result screen showing my performance (coins, time, deaths, stars) so that I know how well I did and can decide to replay or return to the menu.

## Objective

Create a `LevelClearOverlay` React component that displays the level completion results with a 1-3 star rating, level stats, and action buttons. Follows the same overlay pattern as `GameOverOverlay`.

## Dev Notes

### 1. Create `packages/frontend/src/game/scenes/LevelClearOverlay.tsx`

Follow the pattern of `GameOverOverlay` (same file at `packages/frontend/src/game/scenes/GameOverScene3D.tsx`):
- An absolutely-positioned overlay div covering the full screen
- Semi-transparent dark background
- Centered content with game stats
- Action buttons at the bottom

### 2. Layout

```
+----------------------------------+
|                                  |
|      ★ FASE COMPLETA! ★         |  (title, golden #FFD700)
|                                  |
|      ★ ★ ★   (or ★ ★ ☆ etc)    |  (star display)
|                                  |
|      Moedas:  12 / 15           |  (levelCoins / totalCoinsInLevel if known, else just count)
|      Tempo:   1:23              |  (elapsed time formatted mm:ss)
|      Coracoes: ♥♥♥              |  (remaining hearts as red hearts)
|      Mortes:  2                 |  (deaths count)
|                                  |
|      [  REPETIR  ]              |  (green btn, restarts the level)
|      [   MENU    ]              |  (secondary btn, back to menu)
|                                  |
+----------------------------------+
```

### 3. Star Calculation

Read from useGameState: `deaths`, `levelCoins` (or `coins`), and derive:
- **1 star:** Always awarded (level was completed)
- **2 stars:** `deaths === 0`
- **3 stars:** `deaths === 0 && allCoinsCollected`

For "all coins collected": since we may not know the total coins in the level at this point, use a simpler heuristic for now:
- If `levelCoins >= 1` and `deaths === 0` -> 3 stars
- If future feature provides `totalLevelCoins`, switch to `levelCoins >= totalLevelCoins`

Display stars as filled (★, color #FFD700) or empty (☆, color #555). Use simple text characters or styled spans.

### 4. Time Display

Calculate elapsed time:
```typescript
const levelStartTime = useGameState((s) => s.levelStartTime);
const elapsed = Math.floor((Date.now() - levelStartTime) / 1000);
const minutes = Math.floor(elapsed / 60);
const seconds = elapsed % 60;
const timeStr = `${minutes}:${seconds.toString().padStart(2, "0")}`;
```

Note: `levelStartTime` is set by `startLevel()` in T03. If it's 0 (infinite mode somehow), show "--:--".

### 5. Score Submission

On mount (same pattern as GameOverOverlay), POST to `/api/scores`:
```typescript
useEffect(() => {
  if (submitted.current) return;
  submitted.current = true;
  const playerId = localStorage.getItem("supermel_player_id") || "";
  const levelId = useGameState.getState().levelId;
  if (playerId && levelId) {
    fetch("/api/scores", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        playerId,
        distance: Math.floor(useGameState.getState().coins),
        levelId,
      }),
    }).catch(() => {});
  }
}, []);
```

### 6. Action Buttons

- **REPETIR:** Calls `startLevel(levelId)` to restart the same level. Gets `levelId` from useGameState.
- **MENU:** Calls `setScene("menu")`.

(A future "PROXIMO" button is mentioned in requirements but deferred to the campaign feature B-03.)

### 7. Styling

Follow the project's styling pattern (inline `React.CSSProperties` object, monospace font, dark overlay):
- Background: `rgba(0,0,0,0.75)` (slightly darker than gameover to feel more "celebratory")
- Title color: `#FFD700` (gold)
- Star color filled: `#FFD700`, empty: `#555`
- Stats text: `#fff`, labels: `#aaa`
- REPETIR button: `#4a8a4a` green (same as JOGAR)
- MENU button: `#4a4a8a` blue (same as secondary)

### Gotchas

- Use `useGameState.getState()` for the score POST (not a hook selector) since it runs in useEffect.
- The overlay must have `pointerEvents: "auto"` on the content area so buttons are clickable.
- The parent overlay container in Game3D.tsx has `pointerEvents: "none"` -- the LevelClearOverlay needs its own `pointerEvents: "auto"`.
- Stars should be visually large and prominent -- they are the primary feedback.
- Heart display: Show filled hearts (e.g., red ♥ for remaining lives). Use `lives` from useGameState.
- No audio changes in this task (T05 handles audio wiring).
