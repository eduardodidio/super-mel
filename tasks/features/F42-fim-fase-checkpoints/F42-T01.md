# Task F42-T01 -- Goal Entity Component (Goal.tsx) + Collision Detection

**Feature:** F42
**Wave:** 0
**Type:** frontend
**Depends on:** F37 (EntityType "goal" in LevelDataV2)
**Status:** planned

## User Story

As a player, I want to reach the "dono da Mel" (owner) at the end of a level so that I know the level is complete and see a celebration animation.

## Objective

Create a Goal entity component that renders the owner figure as a billboard sprite in the 3D scene, detects collision with Mel, and triggers a callback that the parent scene uses to start the level-completion flow.

## Dev Notes

### 1. Create `packages/frontend/src/game/entities/Goal.tsx`

Follow the same pattern as `Coin.tsx` and `Heart.tsx`:
- RigidBody type="fixed", sensor, name="goal"
- `onIntersectionEnter` checks `payload.other.rigidBodyObject?.name === "mel"`
- Props: `position: [number, number, number]`, `onGoalReached: () => void`

### 2. Visual: Owner Sprite

The goal visual is the "owner" part of the `jump_on_owner.png` sprite. Since that sprite contains both Mel and the owner together, for the idle goal state, create a simple placeholder visual:
- Option A (preferred): Use a billboard sprite with a human-shaped silhouette. Create a simple mesh group: a tall box (body) + box (head) in a warm color (#DEB887 tan/beige) to represent the owner standing. Scale ~2 units tall to be visible.
- Option B: If a separate `owner.png` sprite exists or can be extracted, use it as a textured plane (like Coin.tsx does with coin.png).

The `jump_on_owner.png` sprite is used AFTER collision as the celebration overlay -- not as the idle goal visual. See F42-T05 for the celebration flow.

### 3. Visual Polish

- Add a gentle bob animation (like Heart.tsx: `Math.sin(time * 2) * 0.15`)
- Add a subtle particle/glow effect to make the goal noticeable from a distance:
  - A yellow point light (intensity 0.5, distance 5) at the goal position
  - Or a pulsing emissive on the mesh

### 4. Collision

- On intersection with Mel: call `onGoalReached()` once (use a `collected.current` ref guard, same pattern as Coin/Heart)
- The callback is fire-once per goal instance

### Relevant Files

- `packages/frontend/src/game/entities/Coin.tsx` -- follow this pattern for RigidBody sensor + collision
- `packages/frontend/src/game/entities/Heart.tsx` -- follow this pattern for bob animation
- `packages/frontend/public/sprites/mel/jump_on_owner.png` -- celebration sprite (171x154), used in T05
- `packages/frontend/public/sprites/mel/manifest.json` -- sprite metadata reference

### Gotchas

- Do NOT transition scenes or mutate game state inside Goal.tsx. The component only calls `onGoalReached()`. The parent (GameScene3D in T05/T06) handles the rest.
- The goal should be slightly taller than a block (1 unit) so it stands out. Suggest 2 units tall for the owner figure.
- Position is world-space (same coordinate system as blocks: 1 unit = 1 block).
