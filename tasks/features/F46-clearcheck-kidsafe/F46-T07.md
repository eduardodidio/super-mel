# Task F46-T07 -- Code Lookup + Sharing Flow

**Feature:** F46
**Wave:** 3
**Type:** frontend
**Depends on:** F46-T02 (GET /code/:code endpoint), F46-T05 (level select overhaul)
**Status:** done

## User Story

As a player, I want to enter a 6-character code to instantly find and play my friend's level, so I don't have to scroll through the entire community list.

## Objective

Add a "Buscar por codigo" input field to the level select screen and implement the lookup + play flow. Also ensure the editor sharing flow (from T04) works end-to-end: after publishing, the code is displayed and can be shared.

## Dev Notes

### 1. Code input in Level Select (`LevelSelectScene3D.tsx`)

Add a code input area at the top of the level select overlay, below the title and above the sort tabs:

```tsx
<div style={styles.codeSearch}>
  <input
    type="text"
    placeholder="CODIGO (6 letras)"
    value={codeInput}
    onChange={(e) => setCodeInput(e.target.value.toUpperCase().slice(0, 6))}
    maxLength={6}
    style={styles.codeInput}
  />
  <button
    onClick={handleCodeSearch}
    disabled={codeInput.length !== 6 || codeLoading}
    style={styles.codeBtn}
  >
    {codeLoading ? "..." : "IR"}
  </button>
</div>
```

Style the input to look like a code entry: monospace, uppercase, large font, centered text, letter-spacing.

### 2. Code search handler

```typescript
const handleCodeSearch = async () => {
  setCodeLoading(true);
  setCodeError(null);
  try {
    const res = await fetch(`/api/levels/code/${codeInput}`);
    if (!res.ok) {
      setCodeError("Codigo nao encontrado");
      return;
    }
    const level = await res.json();
    // Directly play the level
    const levelData: LevelDataV2 = migrateLevelData(level.data);
    if (level.background) {
      setTheme(level.background);
    }
    startLevel(level.id, levelData);
  } catch {
    setCodeError("Erro de conexao");
  } finally {
    setCodeLoading(false);
  }
};
```

On success: skip the level card and directly start playing. The player entered the code with intent to play.

On error: show the error message below the input (red text, small font).

### Gotchas

- The code input must auto-uppercase and strip non-alphanumeric characters. Only allow `[A-Z0-9]` -- the safe charset from T02 (no 0/O/1/I/L, but since input is uppercase, just limit to the valid chars).
- The code search bypasses Family Mode (by design). The `GET /code/:code` endpoint does not filter by `approved`.
- When starting a level from code, the attempt tracking (T05) should still work. Fire the `POST /:id/attempt` as normal.
- If the code lookup returns a level that's not published yet (edge case: code exists but `published=false`), the endpoint should still return it. The code is the creator's private link until they decide to publish to the browse list.
- Error state should clear when the user changes the code input.
- The copy-to-clipboard API (`navigator.clipboard.writeText`) requires HTTPS in some browsers. The game runs on Render (HTTPS), so this should work. Add a try-catch fallback for local dev (HTTP).
