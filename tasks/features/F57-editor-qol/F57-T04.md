# Task F57-T04 -- Selection Rectangle Rendering + Drag-Select in EditorScene3D

**Feature:** F57
**Wave:** 1
**Type:** frontend / 3D rendering
**Depends on:** F57-T02 (useEditorSelection hook + select tool type)
**Status:** planned

## User Story

As a level creator, I want to visually see the rectangular area I am selecting when I drag on the grid, so that I know exactly which blocks and entities will be affected by copy, move, or delete operations.

## Objective

Modify `EditorScene3D.tsx` to handle the "select" tool's pointer interactions (drag-to-select rectangle) and render visual feedback: a dashed rectangle outline for the selection area, and brightness highlights on blocks/entities within the selection.

### 2. Modify pointer interaction for "select" tool

Currently, `onPointerDown` / `onPointerMove` / `onPointerUp` (lines 232-250) always call `handleAction` which places/removes blocks. When `selectedTool === "select"`, these should instead drive the selection system.

Modify the three handlers:

**onPointerDown:**
```typescript
const onPointerDown = useCallback(() => {
  const pos = getGridPos();
  if (!pos) return;

  if (selectedTool === "select") {
    // Check if clicking inside existing selection (start move)
    if (selectionRect && selectionMode === "selected" &&
        pos.x >= selectionRect.x1 && pos.x <= selectionRect.x2 &&
        pos.y >= selectionRect.y1 && pos.y <= selectionRect.y2) {
      onStartMove(pos.x, pos.y);
    } else {
      // Start new selection
      onStartSelect(pos.x, pos.y);
    }
    return;
  }

  // Existing behavior for other tools
  isDragging.current = true;
  lastPlaced.current = "";
  handleAction(pos);
}, [getGridPos, handleAction, selectedTool, selectionRect, selectionMode, onStartSelect, onStartMove]);
```

**onPointerMove:**
```typescript
const onPointerMove = useCallback(() => {
  const pos = getGridPos();
  setHoverPos(pos);

  if (selectedTool === "select" && pos) {
    if (selectionMode === "selecting") {
      onUpdateSelect(pos.x, pos.y);
    } else if (selectionMode === "moving") {
      onUpdateMovePosition(pos.x, pos.y);
    }
    return;
  }

  // Existing behavior
  if (isDragging.current && pos) {
    handleAction(pos);
  }
}, [getGridPos, handleAction, selectedTool, selectionMode, onUpdateSelect, onUpdateMovePosition]);
```

**onPointerUp:**
```typescript
const onPointerUp = useCallback(() => {
  if (selectedTool === "select") {
    if (selectionMode === "selecting") {
      onEndSelect();
    } else if (selectionMode === "moving") {
      onCommitMove();
    }
    return;
  }

  // Existing behavior
  isDragging.current = false;
  lastPlaced.current = "";
}, [selectedTool, selectionMode, onEndSelect, onCommitMove]);
```

### 3. Render selection rectangle overlay

Add a `SelectionOverlay` component rendered when `selectionRect` is not null:

```tsx
function SelectionOverlay({ rect, currentZ }: { rect: SelectionRect; currentZ: number }) {
  const width = rect.x2 - rect.x1 + 1;
  const height = rect.y2 - rect.y1 + 1;
  const centerX = rect.x1 + (width - 1) / 2;
  const centerY = rect.y1 + (height - 1) / 2;

  return (
    <group position={[centerX, centerY, currentZ + 0.01]}>
      {/* Dashed rectangle outline using line segments */}
      <lineSegments>
        <edgesGeometry args={[new THREE.BoxGeometry(width, height, 0.02)]} />
        <lineDashedMaterial
          color="#00CCFF"
          dashSize={0.3}
          gapSize={0.15}
          linewidth={1}
        />
      </lineSegments>
      {/* Semi-transparent fill */}
      <mesh>
        <planeGeometry args={[width, height]} />
        <meshBasicMaterial
          color="#00CCFF"
          transparent
          opacity={0.08}
          side={THREE.DoubleSide}
        />
      </mesh>
    </group>
  );
}
```

Render it in the main JSX:
```tsx
{selectionRect && <SelectionOverlay rect={selectionRect} currentZ={currentZ} />}
```

### 7. Paste mode cursor handling

### Gotchas

- **lineDashedMaterial** requires calling `computeLineDistances()` on the line geometry for dashes to render correctly. Use a `useEffect` or `ref` callback to call this after mount.
- **Z-ordering of selection overlay:** Position at `currentZ + 0.01` to avoid z-fighting with blocks.
- **Performance of ghost rendering:** Ghost blocks are typically < 100 blocks. No need for instancing.
- **Hover preview still works:** When in select mode, the hover preview box should still show (but with the select tool color, e.g., cyan instead of white).
- Add `"select"` handling to `getHoverColor` function: return `"#00CCFF"`.
