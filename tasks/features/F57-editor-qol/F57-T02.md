## User Story

As a level creator, I want to select a rectangular region of my level so that I can copy, move, or delete groups of blocks and entities efficiently instead of editing one at a time.

## Objective

Create a standalone React custom hook `useEditorSelection` that manages selection rectangle state, clipboard contents, paste mode, and drag-move state. Also add `"select"` to the `EditorTool` union type in EditorUI.tsx.

### 4. Types

```typescript
import type { EntityData } from "@super-mel/shared";

interface EditorBlock {
  type: Exclude<BlockType, "empty">;
  x: number;
  y: number;
  z: number;
}

/** Normalized selection rectangle (x1 <= x2, y1 <= y2) */
export interface SelectionRect {
  x1: number;
  y1: number;
  x2: number;
  y2: number;
}

/** Clipboard contents with positions relative to selection origin */
export interface EditorClipboard {
  blocks: EditorBlock[];
  entities: EntityData[];
  width: number;   // x2 - x1 + 1
  height: number;  // y2 - y1 + 1
}

export type SelectionMode = "idle" | "selecting" | "selected" | "pasting" | "moving";

export interface SelectionState {
  mode: SelectionMode;
  rect: SelectionRect | null;
  clipboard: EditorClipboard | null;
  hasSelection: boolean;
  hasClipboard: boolean;
  /** During paste/move, the cursor grid position for ghost preview */
  ghostOrigin: { x: number; y: number } | null;
}
```

### 5. Hook API

```typescript
export function useEditorSelection(): {
  state: SelectionState;

  /** Start a drag-select from grid position */
  startSelect: (x: number, y: number) => void;

  /** Update the drag-select end position (called on pointer move) */
  updateSelect: (x: number, y: number) => void;

  /** Finish the drag-select (called on pointer up) */
  endSelect: () => void;

  /** Clear the selection */
  deselect: () => void;

  /** Copy blocks+entities within the selection rect to clipboard.
   *  Positions stored relative to (x1, y1). */
  copySelection: (blocks: EditorBlock[], entities: EntityData[]) => void;

  /** Enter paste mode. Ghost preview follows cursor. */
  startPaste: () => void;

  /** Update paste ghost position */
  updatePastePosition: (x: number, y: number) => void;

  /** Commit the paste at current ghost position.
   *  Returns the blocks+entities to add (absolute positions). */
  commitPaste: (cursorX: number, cursorY: number) => { blocks: EditorBlock[]; entities: EntityData[] } | null;

  /** Cancel paste mode */
  cancelPaste: () => void;

  /** Start drag-move of selected content */
  startMove: (x: number, y: number) => void;

  /** Update move ghost position */
  updateMovePosition: (x: number, y: number) => void;

  /** Commit the move. Returns { removeFrom: SelectionRect, addBlocks, addEntities } */
  commitMove: (
    blocks: EditorBlock[],
    entities: EntityData[],
    cursorX: number,
    cursorY: number
  ) => {
    removeRect: SelectionRect;
    addBlocks: EditorBlock[];
    addEntities: EntityData[];
  } | null;

  /** Cancel move */
  cancelMove: () => void;

  /** Get blocks+entities within the current selection rect */
  getSelectedContent: (blocks: EditorBlock[], entities: EntityData[]) => {
    blocks: EditorBlock[];
    entities: EntityData[];
    count: number;
  };

  /** Delete everything in the selection rect. Returns true if deletion happened. */
  shouldConfirmDelete: (blocks: EditorBlock[], entities: EntityData[]) => boolean;
}
```

### 6. Implementation Details

- **Selection normalization:** `startSelect` records the raw start position. `updateSelect` stores the raw end position. The `rect` in state is always normalized (x1 <= x2, y1 <= y2) by computing `min/max`.
- **Mode transitions:**
  - `idle` -> `selecting` (on startSelect)
  - `selecting` -> `selected` (on endSelect, if rect has area > 0)
  - `selecting` -> `idle` (on endSelect, if start === end, treated as deselect click)
  - `selected` -> `pasting` (on startPaste)
  - `selected` -> `moving` (on startMove)
  - `pasting` -> `selected` (on commitPaste or cancelPaste)
  - `moving` -> `selected` (on commitMove, with updated rect) or `idle` (on cancelMove)
  - Any -> `idle` (on deselect)
- **Clipboard relative positions:** When `copySelection` is called, filter blocks where `b.x >= x1 && b.x <= x2 && b.y >= y1 && b.y <= y2`. Store with `x - x1, y - y1` offsets. Same for entities.
- **commitPaste:** Takes cursor position, offsets clipboard contents by `(cursorX, cursorY)`, returns absolute-position blocks+entities ready to merge into state.
- **commitMove:** Takes the selection rect contents, computes delta from original rect origin to new cursor, returns the items to remove (original rect) and items to add (offset positions).
- **shouldConfirmDelete:** Returns true if the count of blocks + entities within the rect exceeds 20.
- Use `useState` for all state to ensure reactivity.

### Gotchas

- The hook does NOT directly mutate blocks/entities state. It returns data that the consumer (EditorWrapper) uses to call the appropriate setters.
- Selection rect uses grid coordinates (integers), not pixel coordinates.
- When filtering blocks for selection, respect the `z` layer -- only select blocks on the current Z layer, but select ALL entities (entities are 2D, no Z).
- The `currentZ` is needed for block filtering but should be passed as a parameter to `copySelection`/`getSelectedContent`, not stored in the hook.
