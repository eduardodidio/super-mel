# Task F57-T05 -- Keyboard Shortcuts (Undo/Redo/Delete/Copy/Paste)

**Feature:** F57
**Wave:** 1
**Type:** frontend / input handling
**Depends on:** F57-T01 (useEditorHistory), F57-T02 (useEditorSelection)
**Status:** planned

## User Story

As a level creator, I want to use familiar keyboard shortcuts (Ctrl+Z, Ctrl+C, Ctrl+V, Delete) in the editor so that my workflow is fast and intuitive, matching the conventions of other creative tools.

## Objective

Add a `useEffect` keyboard listener in `EditorWrapper.tsx` that handles all editor keyboard shortcuts: undo, redo, copy, paste, delete selection, and deselect (Escape). The listener must not interfere with text input fields (level name, sign text).

## Dev Notes

### 1. Add keyboard event listener

File: `packages/frontend/src/game/scenes/EditorWrapper.tsx`

Add a `useEffect` that registers a `keydown` listener on `window`:

```typescript
useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    // Skip if user is typing in an input/textarea
    const tag = (e.target as HTMLElement)?.tagName?.toLowerCase();
    if (tag === "input" || tag === "textarea" || tag === "select") return;

    const ctrl = e.ctrlKey || e.metaKey; // Support Cmd on Mac

    // Ctrl+Z -- Undo
    if (ctrl && !e.shiftKey && e.key === "z") {
      e.preventDefault();
      handleUndo();
      return;
    }

    // Ctrl+Shift+Z or Ctrl+Y -- Redo
    if ((ctrl && e.shiftKey && e.key === "z") || (ctrl && e.key === "y")) {
      e.preventDefault();
      handleRedo();
      return;
    }

    // Ctrl+C -- Copy selection
    if (ctrl && e.key === "c") {
      e.preventDefault();
      handleCopy();
      return;
    }

    // Ctrl+V -- Paste
    if (ctrl && e.key === "v") {
      e.preventDefault();
      handlePaste();
      return;
    }

    // Delete or Backspace -- Delete selection
    if (e.key === "Delete" || e.key === "Backspace") {
      e.preventDefault();
      handleDeleteSelection();
      return;
    }

    // Escape -- Deselect / cancel paste / cancel move
    if (e.key === "Escape") {
      e.preventDefault();
      handleEscape();
      return;
    }

    // S key -- Quick switch to select tool
    if (e.key === "s" || e.key === "S") {
      e.preventDefault();
      setSelectedTool("select");
      return;
    }
  };

  window.addEventListener("keydown", handleKeyDown);
  return () => window.removeEventListener("keydown", handleKeyDown);
}, [handleUndo, handleRedo, handleCopy, handlePaste, handleDeleteSelection, handleEscape, setSelectedTool]);
```

### 2. Implement handler functions

These handlers are defined in `EditorWrapper.tsx` using `useCallback`. They will be fully wired in T03 (undo/redo), T06 (copy/paste), and T07 (move). For this task, define the skeleton handlers:

```typescript
// handleCopy, handlePaste, handleDeleteSelection, handleEscape
// will be implemented in T06/T07. For now, define stubs that call
// the selection hook methods.

const handleCopy = useCallback(() => {
  if (!selection.state.hasSelection) return;
  selection.copySelection(blocks, entities);
}, [selection, blocks, entities]);

const handlePaste = useCallback(() => {
  if (!selection.state.hasClipboard) return;
  selection.startPaste();
}, [selection]);

const handleDeleteSelection = useCallback(() => {
  if (!selection.state.hasSelection || !selection.state.rect) return;

  // Check if confirmation needed
  if (selection.shouldConfirmDelete(blocks, entities)) {
    const content = selection.getSelectedContent(blocks, entities);
    if (!window.confirm(`Deletar ${content.count} elementos?`)) return;
  }

  // Push undo snapshot before delete
  pushSnapshot(getCurrentSnapshot());

  const rect = selection.state.rect;
  // Remove blocks within selection (respect currentZ for blocks)
  setBlocks(prev => prev.filter(b =>
    !(b.z === currentZ && b.x >= rect.x1 && b.x <= rect.x2 && b.y >= rect.y1 && b.y <= rect.y2)
  ));
  // Remove entities within selection
  setEntities(prev => prev.filter(e =>
    !(e.x >= rect.x1 && e.x <= rect.x2 && e.y >= rect.y1 && e.y <= rect.y2)
  ));
  markDataChanged();
  selection.deselect();
}, [selection, blocks, entities, currentZ, pushSnapshot, getCurrentSnapshot, markDataChanged]);

const handleEscape = useCallback(() => {
  if (selection.state.mode === "pasting") {
    selection.cancelPaste();
  } else if (selection.state.mode === "moving") {
    selection.cancelMove();
  } else if (selection.state.hasSelection) {
    selection.deselect();
  }
}, [selection]);
```

### 3. Prevent default browser shortcuts

Critical: `e.preventDefault()` must be called for Ctrl+Z, Ctrl+Y, Ctrl+C, Ctrl+V to prevent browser-native behavior (browser undo in text fields, system clipboard operations, etc.).

### 4. Input field guard

The `tag` check at the top of the handler ensures that when the user is typing in the level name input or sign text input, keyboard shortcuts do not fire. This is essential to avoid undoing while typing.

### Gotchas

- **Browser clipboard API:** Ctrl+C here does NOT write to the system clipboard (navigator.clipboard). It only copies to the internal editor clipboard (the `useEditorSelection` hook's clipboard state). This avoids async clipboard permission prompts.
- **Mac support:** Use `e.metaKey` in addition to `e.ctrlKey` for Mac users (Cmd+Z, Cmd+C, etc.).
- **Key casing:** `e.key` returns lowercase "z" even with Ctrl held, but "Z" when Shift is also held on some platforms. Check both `e.key.toLowerCase() === "z"` and `e.shiftKey` for robustness.
- **Backspace as delete:** The `Backspace` key is included alongside `Delete` because many laptop keyboards lack a dedicated Delete key.
- **No conflict with game controls:** This listener only fires when `scene === "editor"`. The editor is a separate scene from gameplay, so Space, Arrow keys, Z, X do not conflict.
- **Cleanup:** The `useEffect` cleanup removes the listener when the component unmounts (scene change away from editor).
