## User Story

As a player, I want to see my coin count in the HUD while playing, and I want coins to actually appear in the game world, so that the coin system is complete and functional.

## Objective

Wiring completo: moedas no ChunkRenderer, contador no HUD, callbacks no GameScene3D.

## Acceptance Criteria

- [ ] Moedas aparecem no mundo 3D nos chunks
- [ ] Mel coleta moedas ao tocar
- [ ] Contador de moedas visivel no HUD
- [ ] Contador incrementa em tempo real ao coletar
- [ ] Moedas coletadas nao reaparecem no chunk atual

## Testing

Validacao manual no browser: jogar, coletar moedas, verificar HUD.

## Test Scenarios

- Happy path: moedas visiveis, coletaveis, HUD atualiza
- Edge case: muitas moedas na tela → sem queda de FPS
- Edge case: voltar a um chunk ja visitado → moedas coletadas continuam sumidas
- Boundary: 0 moedas → HUD mostra "0"
