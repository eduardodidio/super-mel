# F24-T04 — Game State: Coins Counter + Persistencia

**Wave:** 1
**Type:** frontend
**Depends on:** F24-T01
**Status:** planned

## User Story

As a player, I want my coin count to persist between sessions, so that I feel like my collecting efforts are saved and meaningful.

## Objective

Adicionar `coins` (sessao) e `totalCoins` (persistente) ao `useGameState`, com persistencia localStorage.

## Dev Notes

- Arquivo: `packages/frontend/src/game/hooks/useGameState.ts`
- `coins`: moedas coletadas na sessao atual (reseta ao resetGame)
- `totalCoins`: total acumulado (persiste via localStorage, nunca reseta com resetGame)
- Key localStorage: `supermel_total_coins`
- Carregar `totalCoins` do localStorage no init do store

### Arquivos a modificar

- `packages/frontend/src/game/hooks/useGameState.ts`

## Implementation Details

1. Adicionar ao `GameState`:
   ```typescript
   coins: number;        // sessao
   totalCoins: number;   // persistente
   addCoin: () => void;
   ```
2. `addCoin`: incrementa `coins` e `totalCoins`, salva `totalCoins` no localStorage
3. Init: ler `totalCoins` do localStorage (fallback 0)
4. `resetGame`: zera `coins` (sessao), mantem `totalCoins`

## Acceptance Criteria

- [ ] `coins` incrementa ao coletar
- [ ] `totalCoins` persiste entre recargas da pagina
- [ ] `resetGame` zera `coins` mas mantem `totalCoins`
- [ ] localStorage key `supermel_total_coins` atualizado a cada coleta

## Testing

Validacao manual: coletar moedas, recarregar pagina, verificar total mantido.

## Test Scenarios

- Happy path: coletar 5 moedas → coins=5, totalCoins += 5
- Persistencia: recarregar pagina → totalCoins mantido
- Reset: game over → resetGame → coins=0, totalCoins inalterado
- Edge case: localStorage indisponivel → fallback sem crash
