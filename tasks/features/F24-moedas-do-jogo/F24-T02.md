# F24-T02 — Entidade Coin (Coletavel)

**Wave:** 1
**Type:** frontend
**Depends on:** F24-T01
**Status:** planned

## User Story

As a player, I want to see golden coins floating in the level that I can collect by touching them, so that I feel rewarded for exploring.

## Objective

Criar `Coin.tsx` seguindo o padrao de `Heart.tsx`: RigidBody sensor, animacao de rotacao/flutuacao, coleta ao tocar na Mel.

## Dev Notes

- Seguir o padrao exato de `packages/frontend/src/game/entities/Heart.tsx`
- RigidBody type="fixed", sensor, colliders="cuboid"
- Deteccao por `onIntersectionEnter` com `payload.other.rigidBodyObject?.name === "mel"`
- Animacao: rotacao Y continua + flutuacao senoidal (bob) + glow dourado
- Usar a textura de `coin.png` num plane com `meshStandardMaterial` transparent
- Se a textura nao renderizar bem (fundo vinho), usar fallback procedural: octaedro dourado (similar ao heart)
- Emissive amarelo/dourado para glow

### Arquivos a criar

## Implementation Details

```typescript
interface CoinProps {
  position: [number, number, number];
  onCollect: () => void;
}
```

- `useFrame`: rotate Y, bob Y (sin), pointLight pulsante amarelo
- Ao coletar: `collected.current = true`, chamar `onCollect()`
- Quando `collected.current === true`, retornar `null`
- Glow: `pointLight color="#FFD700" intensity={0.8} distance={2}`

## Acceptance Criteria
