# F24-T03 — Geracao de Moedas nos Chunks

**Wave:** 1
**Type:** frontend
**Depends on:** F24-T01
**Status:** planned

## User Story

As a player, I want coins to appear naturally throughout the level, so that I have something to collect while platforming.

## Objective

Adicionar `CoinData[]` ao `Chunk` e gerar moedas no `ChunkGenerator`, espalhadas em posicoes alcancaveis.

## Dev Notes

- Arquivo: `packages/frontend/src/game/systems/ChunkGenerator.ts`
- Seguir o padrao de `HeartData` / hearts generation
- Moedas sao MUITO mais frequentes que hearts (5-10x mais)
- Padroes de spawn:
  - Linhas de moedas ao longo de plataformas
  - Arcos de moedas sobre gaps (premiar pulos)
  - Clusters de 3-5 moedas em posicoes interessantes
- Usar a mesma funcao `seededRandom` para determinismo

### Arquivos a modificar

- `packages/frontend/src/game/systems/ChunkGenerator.ts` — adicionar `CoinData` e geracao

## Implementation Details

1. Adicionar interface `CoinData { x: number; y: number; }`
2. Adicionar `coins: CoinData[]` ao `Chunk`
3. No `generateChunk`:
   - Apos gerar blocos, colocar moedas:
   - ~30% chance por coluna de ter 1-3 moedas empilhadas acima do chao
   - Sobre gaps: arco de moedas (3-5 moedas em forma de parabola)
   - Moedas nunca dentro de blocos solidos
   - Moedas sempre 1-3 blocos acima do chao/plataforma

## Acceptance Criteria

- [ ] `Chunk` tem campo `coins: CoinData[]`
- [ ] Moedas geradas em posicoes alcancaveis
- [ ] Moedas nao sobrepoem blocos solidos
- [ ] Spawn determinístico (seeded random)
- [ ] 5-15 moedas por chunk (mais que hearts)

## Testing

Validacao manual: chunks geram moedas visiveis.

## Test Scenarios

- Happy path: chunks novos tem moedas em posicoes variadas
- Edge case: chunk 0 (spawn) tem moedas acessiveis
- Edge case: chunk com muitos gaps → arcos de moedas
- Boundary: dificuldade alta → mais moedas em posicoes arriscadas
