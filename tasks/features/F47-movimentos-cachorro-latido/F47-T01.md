# Task F47-T01 -- Bark Input + BarkSystem (Latido)

**Feature:** F47
**Wave:** 0
**Type:** frontend
**Depends on:** F43 (enemy AI provides stun/flee targets)
**Status:** done

## User Story

As a player, I want to press a bark button (X) so that Mel barks, creating a visible wave that stuns nearby enemies and shakes item_blocks, giving me tactical crowd control and a way to discover hidden content.

## Objective

Add the `bark` control input (KeyX / gamepad Y / touch C) to `useControls`, create a `BarkSystem` component that renders an expanding ring effect when bark is triggered, and define the callback interface for affecting enemies and item_blocks.

### 2. Create `packages/frontend/src/game/systems/BarkSystem.tsx`

A component that manages bark wave instances. Props:
```typescript
interface BarkSystemProps {
  controlsRef: React.RefObject<Controls>;
  playerPosRef: React.RefObject<{ x: number; y: number }>;
  onBarkWave: (x: number, y: number, radius: number) => void;
  onBarkStart?: () => void; // for animation trigger
}
```

Behavior:
- Track bark cooldown (1.0s between barks).
- On bark press (edge-detected: `bark && !lastBark`):
  - If cooldown <= 0: spawn a bark wave effect at player position, call `onBarkStart()`, start cooldown.
- Bark wave effect:
  - Expanding golden torus ring (or circle outline) starting at radius 0.5, expanding to radius 4 over 0.5s.
  - Color: `#FFD700` (gold), emissive, fading opacity from 0.8 to 0 over the lifetime.
  - At peak radius (0.5s), call `onBarkWave(playerX, playerY, 4)` to notify the scene.
  - The torus self-destructs after 0.5s.
- Use `useGameFrame` for the cooldown timer (respects pause).

Visual implementation:
```tsx
// Each bark wave is a <mesh> with a torusGeometry that scales up
<mesh position={[x, y, 0]} scale={[currentRadius, currentRadius, 1]}>
  <torusGeometry args={[1, 0.08, 8, 32]} />
  <meshStandardMaterial
    color="#FFD700"
    emissive="#FFD700"
    emissiveIntensity={1.5}
    transparent
    opacity={opacity}
    side={THREE.DoubleSide}
  />
</mesh>
```

### 3. `onBarkWave` callback contract

The callback `onBarkWave(x, y, radius)` is called by BarkSystem when the bark wave reaches full extent. GameScene3D wires this to:
1. **Enemy stun/flee** (from F43 enemy system): enemies within `radius` units of `(x, y)` enter a stunned/fleeing state for 1.5s.
2. **Item_block shake**: iterate visible item_blocks within `radius` and apply a brief shake animation (0.3s oscillation). This is done by passing the bark position to ChunkRenderer or by a separate query.

For now (before F43 is wired), `onBarkWave` can be a no-op in GameScene3D or log to console. The important thing is the interface is clean.

### 4. Add bark cooldown indicator (optional visual)

A small circular cooldown indicator near Mel (like a radial wipe) that shows bark availability. This is a stretch goal -- not required for acceptance.

### Gotchas

- KeyX must not conflict with existing KeyZ (shoot). They are separate keys.
- Bark is NOT the same as attack. `shoot` fires the Bola; `bark` creates an area wave. They can be used independently.
- Edge-detect bark press (`bark && !lastBark`) to prevent held-key from rapid-firing.
- The cooldown timer must respect `paused` state (use `useGameFrame`, not raw `useFrame`).
- Gamepad button 3 (Y/Triangle) is currently unused -- safe to assign.
- Do NOT import or reference enemy components directly. Use the callback pattern.
