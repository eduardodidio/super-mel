# Task F47-T04 -- Sniff / Farejar Highlight System

**Feature:** F47
**Wave:** 1
**Type:** frontend
**Depends on:** F47-T05 (AnimationStateMachine has `sniff` state -- can be parallelized since T05 only adds state declarations)
**Status:** planned

## User Story

As a player, I want to hold down while standing still for 1 second so that Mel sniffs the ground and highlights nearby hidden item_blocks and bone entities with a glowing outline, helping me find secrets without shooting blindly.

## Objective

Create a `SniffHighlight` component that renders glowing outlines around item_blocks and bone entities within a detection radius when the sniff state is active. Add sniff state detection logic in GameScene3D.

### 3. Collecting highlight targets

In `GameScene3D.tsx`, collect the list of sniff targets from ChunkRenderer data:

Add a method to `ChunkRendererHandle` (or compute externally):
```typescript
// Option A: compute in GameScene3D using getBlockAt in a radius scan
// Option B: add getBlocksInRadius to ChunkRendererHandle

// Preferred: Option A (simpler, no ChunkRenderer changes beyond T02's getBlockAt)
```

In GameScene3D, when sniff is active, scan for item_blocks in a radius:
```typescript
const sniffTargets = useMemo(() => {
  if (!sniffActive) return [];
  const targets: SniffTarget[] = [];
  const cx = Math.round(playerPosRef.current.x);
  const cy = Math.round(playerPosRef.current.y);
  const r = 8;

  // Scan grid positions in radius
  for (let dx = -r; dx <= r; dx++) {
    for (let dy = -r; dy <= r; dy++) {
      if (dx * dx + dy * dy > r * r) continue;
      const bx = cx + dx;
      const by = cy + dy;
      const blockType = chunkRef.current?.getBlockAt(bx, by, 0);
      if (blockType === "item_block") {
        targets.push({ x: bx, y: by, z: 0, type: "item_block" });
      }
    }
  }

  // Also check otherEntities for bones (from level data)
  if (sceneObjects?.otherEntities) {
    for (const entity of sceneObjects.otherEntities) {
      if (entity.type === "bone") {
        const dist = Math.sqrt(
          (entity.x - playerPosRef.current.x) ** 2 +
          (entity.y - playerPosRef.current.y) ** 2
        );
        if (dist <= r) {
          targets.push({ x: entity.x, y: entity.y, z: 0, type: "bone" });
        }
      }
    }
  }

  return targets;
}, [sniffActive, /* playerPos changes trigger rescan */]);
```

Note: The scan only runs when sniffActive changes, so performance is not a concern for continuous frames.

### Gotchas

- `melStateRef.current` type needs updating to include `sniffing: boolean`. Ensure the type is consistent across Mel.tsx and GameScene3D.tsx.
- The sniff scan (16x16 grid iteration) should NOT run every frame. Only recompute when `sniffActive` toggles to true, or when Mel moves significantly (but Mel is stationary during sniff, so toggle-only is sufficient).
- In infinite mode, there are no bone entities (only level mode has entities). Sniff still works for item_blocks in infinite mode.
- Item_blocks that have already been activated (hit by Bola) should NOT be highlighted. Check `activatedBlocks` in ChunkRenderer. This requires either exposing `activatedBlocks` or adding an `isBlockActivated(x,y,z)` method.
- Sniff deactivates instantly when Mel moves (`ctrl.left || ctrl.right || !grounded`). The timer resets to 0.
- The `useMemo` for targets should use a state variable for sniffActive (not a ref) to trigger re-renders.
