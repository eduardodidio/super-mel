#### Add dig wiring:

```typescript
// Dig state ref for Mel animation
const digActiveRef = useRef(false);
const digCooldownRef = useRef(0);

// Dig handler -- called from the attack flow
const handleDigAttempt = useCallback(() => {
  if (digCooldownRef.current > 0) return false;
  if (!chunkRef.current) return false;

  const result = tryDig(
    playerPosRef.current.x,
    playerPosRef.current.y,
    chunkRef.current.getBlockAt
  );

  if (!result.success) return false;

  // Destroy the block
  chunkRef.current.destroyBlock(result.blockX, result.blockY, result.blockZ);
  shake(0.06, 0.1);
  digCooldownRef.current = 0.4; // 400ms cooldown

  // Spawn drops
  if (result.dropType === "coin") {
    spawnDroppedCoins(result.blockX, result.blockY, 1, 5);
  } else if (result.dropType === "bone") {
    addScore(50);
  }

  // Signal Mel to play dig animation
  digActiveRef.current = true;
  setTimeout(() => { digActiveRef.current = false; }, 500);

  return true; // dig consumed the attack input
}, [shake, spawnDroppedCoins, addScore]);
```

Integrate into existing ProjectileManager's attack flow. The dig check must happen BEFORE the projectile fires. Modify the `onAttackFrame` flow:

The current flow is: Mel `onAttackFrame` -> ProjectileManager spawns projectile.

New flow:
1. Mel `onAttackFrame` fires.
2. GameScene3D checks: is Mel crouching + grounded?
3. If yes: call `handleDigAttempt()`. If dig succeeds, do NOT spawn projectile.
4. If no or dig fails: spawn projectile as before.

This requires changing the attack callback. Instead of Mel calling `onAttackFrame` directly wired to ProjectileManager, GameScene3D intercepts:

```typescript
const handleAttackFrame = useCallback(() => {
  // Check if we should dig instead of shoot
  const melState = melStateRef.current;
  if (melState.grounded && controlsRef.current?.down) {
    const didDig = handleDigAttempt();
    if (didDig) return; // dig consumed the attack
  }
  // Normal projectile spawn
  projectileManagerRef.current?.spawnProjectile();
}, [handleDigAttempt]);
```

Note: This requires ProjectileManager to expose a `spawnProjectile()` imperative method, OR GameScene3D manages the projectile spawn directly. The simplest approach: keep the existing callback but add a guard:

```typescript
const shouldSuppressProjectile = useRef(false);

const handleAttackFrame = useCallback(() => {
  const melState = melStateRef.current;
  if (melState.grounded && controlsRef.current?.down) {
    const didDig = handleDigAttempt();
    if (didDig) {
      shouldSuppressProjectile.current = true;
      return;
    }
  }
  // Projectile fires normally via ProjectileManager's internal detection
}, [handleDigAttempt]);
```

Alternative simpler approach: Mel.tsx already has an `attackTimer`. When dig succeeds, set `attackTimer` to 0 so the attack frame event does not trigger the projectile.

Collect sniff targets:
```typescript
const sniffTargets = useMemo<SniffTarget[]>(() => {
  if (!sniffActive) return [];
  const targets: SniffTarget[] = [];
  const cx = Math.round(playerPosRef.current.x);
  const cy = Math.round(playerPosRef.current.y);
  const r = 8;

  for (let dx = -r; dx <= r; dx++) {
    for (let dy = -r; dy <= r; dy++) {
      if (dx * dx + dy * dy > r * r) continue;
      const blockType = chunkRef.current?.getBlockAt(cx + dx, cy + dy, 0);
      if (blockType === "item_block") {
        targets.push({ x: cx + dx, y: cy + dy, z: 0, type: "item_block" });
      }
    }
  }

  // Bone entities from level data
  if (sceneObjects?.otherEntities) {
    for (const e of sceneObjects.otherEntities) {
      if (e.type === "bone") {
        const dist = Math.sqrt(
          (e.x - playerPosRef.current.x) ** 2 +
          (e.y - playerPosRef.current.y) ** 2
        );
        if (dist <= r) {
          targets.push({ x: e.x, y: e.y, z: 0, type: "bone" });
        }
      }
    }
  }

  return targets;
}, [sniffActive]);
```

### Gotchas

- The dig-vs-projectile priority is the trickiest part. Ensure that when dig succeeds, the projectile does NOT fire. The cleanest approach is to intercept the attack callback in GameScene3D before it reaches ProjectileManager.
- Touch controls: adding a third button on the right may crowd small screens. Consider making C slightly smaller or positioning it diagonally below B.
- The `sniffActive` state must be a React state variable (not just a ref) because it drives SniffHighlight rendering and useMemo dependencies.
- The `useGameFrame` for dig cooldown and sniff polling must run even during non-paused play. Ensure it uses `useGameFrame` (which skips when paused).
- Test all four abilities together: bark while standing, dig while crouching, sniff while holding down, and Bola return on shoot. They should not conflict.
- The `levelCompleting` guard should also freeze bark and dig (use `frozenControlsRef` which already has all inputs false).
