#### BarkRingEffect:
A golden ring that expands rapidly and fades (simpler version of BarkSystem's ring, for EffectManager spawning):
```typescript
function BarkRingEffect({ position, onComplete, scale = 1 }: Omit<EffectSpriteProps, "type">) {
  const meshRef = useRef<THREE.Mesh>(null);
  const matRef = useRef<THREE.MeshBasicMaterial>(null);
  const elapsed = useRef(0);

  useFrame((_, delta) => {
    elapsed.current += delta;
    const t = elapsed.current / 0.4; // 0.4s duration

    if (t >= 1) { onComplete(); return; }

    if (meshRef.current) {
      const r = THREE.MathUtils.lerp(0.3, 3, t) * scale;
      meshRef.current.scale.set(r, r, 1);
    }
    if (matRef.current) {
      matRef.current.opacity = THREE.MathUtils.lerp(0.7, 0, t);
    }
  });

  return (
    <mesh ref={meshRef} position={position} rotation={[0, 0, 0]}>
      <ringGeometry args={[0.9, 1.0, 24]} />
      <meshBasicMaterial
        ref={matRef}
        color={0xffd700}
        transparent
        opacity={0.7}
        depthWrite={false}
      />
    </mesh>
  );
}
```

#### DigDustEffect:
A burst of brown particles rising from the dig point:
```typescript
function DigDustEffect({ position, onComplete, scale = 1 }: Omit<EffectSpriteProps, "type">) {
  const groupRef = useRef<THREE.Group>(null);
  const elapsed = useRef(0);
  // 4 brown dust particles
  const particles = useRef([
    { dx: -0.2, dy: 0 }, { dx: 0.2, dy: 0 },
    { dx: -0.1, dy: 0.1 }, { dx: 0.15, dy: 0.05 },
  ]);

  useFrame((_, delta) => {
    elapsed.current += delta;
    const t = elapsed.current / 0.5;
    if (t >= 1) { onComplete(); return; }

    if (groupRef.current) {
      const children = groupRef.current.children;
      for (let i = 0; i < particles.current.length; i++) {
        const p = particles.current[i];
        children[i].position.set(
          p.dx * (1 + t * 2),
          p.dy + t * 0.8,
          0.1
        );
        const s = THREE.MathUtils.lerp(0.1, 0.02, t) * scale;
        children[i].scale.setScalar(s);
        const mat = (children[i] as THREE.Mesh).material as THREE.MeshBasicMaterial;
        mat.opacity = THREE.MathUtils.lerp(0.8, 0, t);
      }
    }
  });

  return (
    <group ref={groupRef} position={position}>
      {particles.current.map((_, i) => (
        <mesh key={i}>
          <sphereGeometry args={[0.15, 6, 4]} />
          <meshBasicMaterial color={0x8B4513} transparent opacity={0.8} depthWrite={false} />
        </mesh>
      ))}
    </group>
  );
}
```

### 3. Item_block shake on bark wave

When a bark wave reaches item_blocks, they should briefly shake to hint at content. This visual effect is implemented in `Block.tsx` or as a wrapper:

Add a `shaking` prop to `Block.tsx` (or use an external animation):

Option A (preferred -- minimal Block.tsx change):
In `GameScene3D.tsx`, when `handleBarkWave` fires, build a Set of item_block positions that are within the bark radius, and pass this Set to ChunkRenderer as a prop:

```typescript
const [shakingBlocks, setShakingBlocks] = useState<Set<string>>(new Set());

const handleBarkWave = useCallback((x: number, y: number, radius: number) => {
  // Find item_blocks in radius
  const shaking = new Set<string>();
  for (let dx = -Math.ceil(radius); dx <= Math.ceil(radius); dx++) {
    for (let dy = -Math.ceil(radius); dy <= Math.ceil(radius); dy++) {
      if (dx * dx + dy * dy > radius * radius) continue;
      const bx = Math.round(x) + dx;
      const by = Math.round(y) + dy;
      const blockType = chunkRef.current?.getBlockAt(bx, by, 0);
      if (blockType === "item_block") {
        shaking.add(`${bx},${by},0`);
      }
    }
  }
  if (shaking.size > 0) {
    setShakingBlocks(shaking);
    setTimeout(() => setShakingBlocks(new Set()), 300); // shake for 300ms
  }
}, []);
```

### 5. Edge cases and polish

- **Bark during fly:** Bark should work while airborne. The ring spawns at Mel's aerial position.
- **Dig while on edge:** If Mel is standing on the edge of a block (between two blocks), the dig should target the block under her center (`Math.round(melX)`).
- **Sniff during damage:** If Mel takes damage during sniff, sniff is interrupted (damage is higher priority in ASM).
- **Return ball + dig:** If Mel is crouching when the ball returns, the ball still homes to her and self-destructs on arrival. No conflict.
- **Multiple barks in quick succession:** Cooldown prevents this, but if two barks are somehow close, shakingBlocks should handle overlapping sets gracefully.

### Gotchas

- Adding new types to `EffectSpriteProps["type"]` union means updating `EFFECT_CONFIGS` for all new types, otherwise the duration defaults may cause issues.
- The item_block shake is a visual effect only -- it does NOT activate the block. The player still needs to hit it with the Bola to get coins.
- The EffectManager state name comparison (`playerState === "bark"`) depends on the ASM state names matching exactly. Verify with `AnimState` type.
- Block shake requires passing data from GameScene3D through ChunkRenderer to individual Block components. This adds a render prop. Consider memoization to avoid unnecessary re-renders of all blocks.
