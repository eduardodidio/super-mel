## User Story

Como jogador, quero que a Mel mantenha um tamanho visual consistente em todas
as animacoes, para que ela nao "cresca" ou "encolha" ao mudar de estado.

## Dev Notes

### Contexto

O `SpriteAnimator.ts` ja carrega o manifest.json e exporta
`getFrameAspectRatio()` que retorna `sourceSize[0] / sourceSize[1]`.
O problema e que `Mel.tsx` usa essa ratio apenas para calcular a largura,
mantendo a altura fixa em `SPRITE_HEIGHT = 2`. Isso faz sprites com
proporcoes diferentes (como lie_down 130x68) renderizarem com tamanho visual
completamente diferente do idle (101x138).

### O que fazer

1. **Nova funcao `getFrameNormalizedScale()`**:
   ```ts
   export function getFrameNormalizedScale(
     animName: string,
     elapsed: number
   ): { scaleX: number; scaleY: number } {
     if (!spriteManifest) return { scaleX: 1, scaleY: 1 };
     const anim = ANIMATIONS[animName] ?? ANIMATIONS.idle;
     const frameIndex = resolveFrameIndex(anim, elapsed);
     const spriteName = anim.frames[frameIndex];
     const entry = spriteManifest.sprites[spriteName];
     if (!entry) return { scaleX: 1, scaleY: 1 };

     const [refW, refH] = spriteManifest.frameSize; // [224, 168]
     // Normalize relative to frameSize height
     const scaleX = entry.sourceSize[0] / refH;
     const scaleY = entry.sourceSize[1] / refH;
     return { scaleX, scaleY };
   }
   ```

2. **Nova funcao `getFrameAnchorOffset()`** para calcular o offset Y do sprite
   baseado no anchor point, normalizando pelo frameSize:
   ```ts
   export function getFrameAnchorOffset(
     animName: string,
     elapsed: number
   ): number {
     if (!spriteManifest) return 0;
     const anim = ANIMATIONS[animName] ?? ANIMATIONS.idle;
     const frameIndex = resolveFrameIndex(anim, elapsed);
     const spriteName = anim.frames[frameIndex];
     const entry = spriteManifest.sprites[spriteName];
     if (!entry) return 0;

     const refH = spriteManifest.frameSize[1]; // 168
     // Anchor is pixel position from top-left. The anchor Y
     // relative to sprite bottom is (sourceSize[1] - anchor[1]).
     // Normalized to world units.
     const bottomOffset = (entry.sourceSize[1] - entry.anchor[1]) / refH;
     return bottomOffset;
   }
   ```

3. **Tratar sprites faltantes no ANIMATIONS**: Os frames `crouch`, `fly_1`,
   `fly_2`, `look_up` nao existem como arquivos PNG. Atualizar as definicoes
   de animacao para usar sprites que existem:
   - `crouch.frames` -> `["sit"]` (sit.png e a pose mais proxima de crouch)
   - `fly.frames` -> `["jump_air", "jump_rise"]` (poses de ar existentes)
   - `look_up.frames` -> `["idle_right"]` (ou manter fallback)
   - `dig.frames` -> `["sit", "sit"]` (em vez de crouch inexistente)

4. **Manter `getFrameAspectRatio()` para compatibilidade** mas marcar como
   deprecated com comentario.
