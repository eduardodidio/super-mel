# F51-T02 — Mel.tsx: usar escala normalizada e ajustar posicao Y do mesh

**Wave:** 1 (depende de T01)
**File:** `packages/frontend/src/game/entities/Mel.tsx`
**Depends on:** F51-T01
**Status:** done

## User Story

Como jogador, quero que a Mel nao "cresca" quando deita ou agacha, e que
seus pes fiquem sempre alinhados com o chao independente da animacao.

## Dev Notes

### Contexto

`Mel.tsx` atualmente (linhas 320-326) faz:
```ts
const ratio = getFrameAspectRatio(animName, stateMachine.current.stateTime);
const frameWidth = SPRITE_HEIGHT * ratio;
spriteRef.current.scale.set(
  facingRight.current ? frameWidth : -frameWidth,
  SPRITE_HEIGHT,
  1
);
```

Isso mantem Y fixo em 2.0 para TODOS os sprites. Um `lie_down` com 68px de
altura renderiza com a mesma altura que `idle_right` com 138px — o dobro do
que deveria ser.

### O que fazer

1. **Importar `getFrameNormalizedScale`** de SpriteAnimator (criada em T01)

2. **Substituir o calculo de escala** no bloco `useFrame` (linhas ~312-327):
   ```ts
   if (spritesLoaded.current) {
     const texture = getFrame(animName, stateMachine.current.stateTime);
     const mat = (spriteRef.current as THREE.Mesh).material as THREE.MeshStandardMaterial;
     if (mat.map !== texture) {
       mat.map = texture;
       mat.needsUpdate = true;
     }

     const { scaleX, scaleY } = getFrameNormalizedScale(
       animName,
       stateMachine.current.stateTime
     );
     const worldW = SPRITE_HEIGHT * scaleX;
     const worldH = SPRITE_HEIGHT * scaleY;

     spriteRef.current.scale.set(
       facingRight.current ? worldW : -worldW,
       worldH,
       1
     );

     // Ajustar posicao Y do sprite mesh para ancorar os pes no collider
     // O pivot padrao da planeGeometry e no centro.
     // Para ancorar no bottom, offsetY = worldH / 2
     // Subtrair metade da altura do collider (0.45) para alinhar
     // com o fundo do collider.
     const meshOffsetY = worldH / 2 - 0.15;
     spriteRef.current.position.y = meshOffsetY;
   }
   ```

3. **Remover import de `getFrameAspectRatio`** se nao for mais usado
   (ou manter se ha outros consumidores)

4. **Ajustar posicao inicial do mesh** no JSX:
   - Atual: `position={[0, 0.3, 0]}`
   - Manter como fallback — sera sobrescrito no primeiro frame pelo
     calculo dinamico

5. **Considerar suavizacao (lerp)** para evitar saltos bruscos de tamanho
   entre animacoes. Opcao: interpolar `worldW` e `worldH` entre o frame
   anterior e o novo usando um lerp rapido (fator ~0.3 por frame):
   ```ts
   // Refs para suavizacao
   const prevScaleX = useRef(SPRITE_HEIGHT);
   const prevScaleY = useRef(SPRITE_HEIGHT);

   // No useFrame:
   const smoothFactor = Math.min(1, delta * 15); // ~15 frames para convergir
   const smoothW = THREE.MathUtils.lerp(prevScaleX.current, worldW, smoothFactor);
   const smoothH = THREE.MathUtils.lerp(prevScaleY.current, worldH, smoothFactor);
   prevScaleX.current = smoothW;
   prevScaleY.current = smoothH;
   ```
   NOTA: A suavizacao deve ser sutil. Se causar efeito "gelatina" indesejado,
   usar fator mais agressivo (~0.5) ou remover.
