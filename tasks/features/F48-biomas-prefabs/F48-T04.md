# Task F48-T04 -- Visual Biome Transitions (Skybox + Lighting + BackgroundDecor)

**Feature:** F48
**Wave:** 1
**Type:** frontend
**Depends on:** F48-T01 (BiomeManager for `BiomeState` and transition factor)
**Status:** done

## User Story

As a player, I want the sky, lighting, and background scenery to smoothly transition between biomes so that the world feels continuous rather than abruptly switching visuals.

## Objective

Modify Skybox.tsx, Lighting.tsx, and BackgroundDecor.tsx to accept transition parameters (target theme + interpolation factor) and lerp their visual properties between two biome configurations. Create a BiomeTransition.tsx wrapper component that orchestrates these transitions using BiomeState from BiomeManager.

## Dev Notes

### 1. Create `packages/frontend/src/game/systems/BiomeTransition.tsx`

A React component that wraps the three visual systems and drives biome transitions:

```typescript
interface BiomeTransitionProps {
  biomeState: BiomeState; // from BiomeManager.getBiomeForChunk()
  playerXRef: React.RefObject<{ x: number; y: number }>;
}

export function BiomeTransition({ biomeState, playerXRef }: BiomeTransitionProps)
```

This component:
- Passes `biomeState.current` as the primary theme
- If `biomeState.next !== null` and `biomeState.transitionFactor > 0`, passes transition props to Skybox, Lighting, and BackgroundDecor
- Returns `<Skybox ... /> <Lighting ... /> <BackgroundDecor ... />`

### 2. Modify `packages/frontend/src/game/systems/Skybox.tsx`

Add optional transition props:

```typescript
interface SkyboxProps {
  theme: BackgroundTheme;
  nextTheme?: BackgroundTheme | null;
  transitionFactor?: number; // 0.0 to 1.0
}
```

When `nextTheme` is set and `transitionFactor > 0`:
- Create TWO canvas gradient textures (current and next theme)
- Blend the final texture colors using lerp on the RGB values of `top`, `mid`, `bottom`
- Lerp the fog color and fog near/far values
- Apply a SINGLE blended texture to `scene.background`
- Lerp fog: `new THREE.Fog(lerpedFogColor, lerpedFogNear, lerpedFogFar)`

Color lerp helper (implement locally or import from THREE):
```typescript
function lerpColor(a: string, b: string, t: number): string {
  const ca = new THREE.Color(a);
  const cb = new THREE.Color(b);
  ca.lerp(cb, t);
  return "#" + ca.getHexString();
}
```

Performance note: Only recreate the canvas texture when theme or transitionFactor changes by more than 0.05. Use a `useRef` to cache the last rendered factor and skip updates for tiny changes. This prevents texture thrashing.

### 3. Modify `packages/frontend/src/game/systems/Lighting.tsx`

Add optional transition props:

```typescript
interface LightingProps {
  theme?: BackgroundTheme;
  nextTheme?: BackgroundTheme | null;
  transitionFactor?: number;
}
```

When transitioning:
- Lerp `ambientIntensity`, `hemiIntensity`, `sunIntensity` between the two configs
- Lerp colors (`hemiSky`, `hemiGround`, `sunColor`) using THREE.Color.lerp
- Lerp `sunPosition` components

Since Lighting returns JSX elements with inline props, compute the lerped values in the component body and pass them directly to the light elements. No canvas/texture is involved -- this is purely numeric/color interpolation.

### 4. Modify `packages/frontend/src/game/systems/BackgroundDecor.tsx`

Add optional transition props:

```typescript
interface BackgroundDecorProps {
  theme: BackgroundTheme;
  playerXRef: React.RefObject<{ x: number; y: number }>;
  nextTheme?: BackgroundTheme | null;
  transitionFactor?: number;
}
```

When transitioning:
- Lerp `cloudColor` between current and next theme's decor config
- Lerp `mountainColor` and `mountainDarkColor`
- Cross-fade the `hasMountains` flag: if current has mountains and next does not, fade mountain opacity from 1 to 0 using transitionFactor (and vice versa)
- Cross-fade star count/visibility for night/space transitions

Implementation: the `useMemo` arrays for clouds and mountains are based on `theme` which is stable within a biome. During transitions, modify the material colors/opacity in the `useFrame` loop using the transition factor, without recreating the cloud/mountain arrays.

### 5. Utility: lerp helpers

Create a small set of lerp helpers at the top of BiomeTransition.tsx or in a shared util:

```typescript
function lerpNum(a: number, b: number, t: number): number {
  return a + (b - a) * t;
}

function lerpVec3(
  a: [number, number, number],
  b: [number, number, number],
  t: number
): [number, number, number] {
  return [lerpNum(a[0], b[0], t), lerpNum(a[1], b[1], t), lerpNum(a[2], b[2], t)];
}
```

### Gotchas

- **Skybox texture performance.** Creating a new CanvasTexture every frame will cause GC pressure and frame drops. Cache the texture and only regenerate when the transition factor changes significantly (threshold: 0.05). During a 2-chunk transition at normal play speed, the factor changes ~10 times, which means ~10 texture updates -- acceptable.
- **Dispose old textures.** When creating a new blended texture, dispose the previous one to prevent memory leaks. The existing cleanup in the `useEffect` return handles this, but with transitions the effect dependencies change more frequently.
- **BackgroundDecor cloud/mountain arrays.** Do NOT re-create these arrays during transitions. Only modify material colors via refs in `useFrame`. Re-creating arrays causes React reconciliation to unmount/mount mesh components, which is expensive.
- **Stars visibility.** Stars should appear gradually when transitioning TO night/space and fade out when transitioning FROM night/space. Use material opacity for the fade.
- **When not transitioning** (transitionFactor === 0 or nextTheme === null), all three systems should behave identically to their current implementation. No visual difference when transitions are not active.
- **Backward compatibility.** The existing `<Skybox theme={theme} />` signature must continue to work. New props are optional.

## Test Scenarios

- **No transition:** `<Skybox theme="forest" />` renders identically to current behavior
- **Full transition:** `<Skybox theme="forest" nextTheme="desert" transitionFactor={0.5} />` renders a sky with colors halfway between forest and desert
- **Edge:** `transitionFactor={0}` = fully current theme, `transitionFactor={1}` = fully next theme
- **Night stars:** Transitioning to "night" at factor 0.5 shows stars at ~50% opacity
- **Space no mountains:** Transitioning from forest to space fades mountains to 0 opacity
