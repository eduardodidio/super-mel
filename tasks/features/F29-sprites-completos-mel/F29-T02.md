# F29-T02 — Criar Sprites Faltantes (Crouch, Look Up, Fly)

**Wave:** 1
**Type:** frontend / assets
**Depends on:** F29-T01
**Status:** blocked (precisa artista criar PNGs: crouch.png, look_up.png, fly_1.png, fly_2.png)

## User Story

As a player, I want unique sprites for crouch, look up, and fly actions, so that each state looks distinct and recognizable.

## Objective

Criar os sprites P0 (essenciais) que substituem placeholders: crouch, look_up, fly. Usar sprites existentes como base, editando pose/posicao.

## Dev Notes

### Sprites a criar (P0 — essenciais)

1. **`crouch.png`** (base: sit.png)
   - Mel agachada mas em posicao "pronta" (diferente de sentada)
   - Corpo mais baixo, patas dobradas, olhar pra frente
   - Diferenca de sit: sit e relaxada, crouch e tensa/pronta

2. **`look_up.png`** (base: idle_right.png)
   - Mel na posicao idle mas com cabeca/focinho apontando pra cima
   - Corpo reto, olhar direcionado para o ceu

3. **`fly_1.png`** (base: jump_air.png)
   - Mel com corpo esticado, patas abertas, postura de voo
   - Leve inclinacao pra cima

4. **`fly_2.png`** (base: fly_1.png)
   - Variacao leve: patas em posicao diferente para ciclo de animacao
   - Efeito visual de "batendo asas" ou flutuando

### Especificacoes tecnicas
- Formato: PNG com transparencia (alpha channel)
- Dimensoes: 224x168 pixels (mesmo que sprites existentes)
- Paleta: mesma paleta de cores da Mel (marrom yorkshire, olhos escuros, nariz preto)
- Estilo: pixel art consistente com sprites existentes

### Abordagem de criacao
- Opção 1: Editar manualmente os sprites base usando canvas/imagemagick
- Opção 2: Usar script para gerar variantes (rotacao de partes, offset)
- Opção 3: Pedir ao usuario/artista para criar (se a qualidade manual nao for suficiente)

### Destino dos arquivos
`packages/frontend/public/sprites/mel/`
