# F29-T04 — Adicionar Frames Intermediarios (Walk, Run, Idle)

**Wave:** 2
**Type:** frontend / assets
**Depends on:** F29-T02
**Status:** blocked (precisa artista criar PNGs: idle_right_b/c, walk_right_c/d, run_right_c/d)

## User Story

As a player, I want smooth walk, run, and idle animations with more frames, so that Mel's movement looks fluid instead of choppy.

## Objective

Criar sprites intermediarios para idle (2-3 frames), walk (4 frames), e run (4 frames) para eliminar o efeito "travado" da movimentacao.
