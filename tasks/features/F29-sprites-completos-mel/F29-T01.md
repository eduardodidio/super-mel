# F29-T01 — Auditoria Completa de Sprites + Plano de Criacao

**Wave:** 0
**Type:** frontend / docs
**Depends on:** —
**Status:** done

## User Story

As a developer, I want a complete audit of all Mel sprites showing what exists, what's missing, and what needs to be created, so that the team can plan sprite creation efficiently.

## Objective

Documentar em detalhe todos os sprites existentes, gaps, e produzir um plano de criacao para os sprites faltantes com especificacoes visuais.

### Abordagem para criacao
- Usar sprites existentes como base (mesmo estilo, mesmas dimensoes 224x168)
- Sprites sao pixel art com fundo transparente
- Editar variantes dos sprites existentes (ex: idle_right_b = idle_right com olhos fechados)
- Manter consistencia de paleta de cores e proporcoes da Mel
