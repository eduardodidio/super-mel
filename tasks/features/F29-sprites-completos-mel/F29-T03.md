# F29-T03 — Corrigir Mapeamentos Errados no SpriteAnimator

**Wave:** 1
**Type:** frontend
**Depends on:** F29-T01
**Status:** done

## User Story

As a player, I want each animation state to use the correct sprite frames, so that the character looks right in every situation.

## Objective

Corrigir bugs de mapeamento no SpriteAnimator onde estados usam sprites errados ou ignoram sprites que existem.

## Dev Notes

### Bugs a corrigir

1. **`jump_land` mapeia para animacao "jump" (ERRADO)**
   - **Arquivo:** `packages/frontend/src/game/systems/SpriteAnimator.ts` line 85
   - **Atual:** `jump_land: "jump"` → mostra jump_rise + jump_air
   - **Correto:** criar animacao "land" com frames `[jump_fall, jump_land]` ou `[jump_land]`
   - O sprite `jump_land.png` EXISTE mas nunca e usado

2. **`hurt_heavy` nao usa hurt_heavy.png**
   - **Atual:** hurt_heavy state usa mesma animacao "hurt" que mostra hurt_light + hurt_medium
   - **Correto:** criar animacao "hurt_heavy" com frames `[hurt_medium, hurt_heavy]`
   - O sprite `hurt_heavy.png` EXISTE mas so e usado em "death" animation

3. **`crouch` usa animacao "sit" (placeholder)**
   - **Apos T02:** substituir por novo `crouch.png`
   - Atualizar ANIMATIONS para usar `[crouch]` (ou `[crouch, crouch_walk]` se disponivel)

4. **`look_up` usa animacao "idle" (placeholder)**
   - **Apos T02:** substituir por `[look_up]`

5. **`fly` usa frame unico jump_air (placeholder)**
   - **Apos T02:** substituir por `[fly_1, fly_2]` com loop

### Arquivos a modificar

  - `ANIM_NAME_MAP` (line 79-92): corrigir jump_land, hurt_heavy
