# Task F43-T07 -- GameScene3D Wiring + TestLevelData Enemy Entities

**Feature:** F43
**Wave:** 2
**Type:** frontend
**Depends on:** F43-T04 (EnemyManager), F43-T05 (Mel stomp bounce + Projectile enemy hit), F43-T06 (ChunkGenerator enemies + LevelSceneConverter enemies)
**Status:** planned

## User Story

As a player, I want all enemy systems to work together seamlessly -- enemies appear in both infinite and level modes, I can stomp or shoot them, they drop coins, and damage me on lateral contact -- so that the full enemy experience is integrated.

## Objective

Wire EnemyManager, Mel's stomp bounce, and ProjectileManager's enemy hit detection together inside GameScene3D. Add enemy entities to the test level (TestLevelData) for development testing. This is the integration task that connects all previous F43 tasks into a working whole.

**3. Track enemy data from chunks (infinite mode):**

```typescript
const [chunkEnemies, setChunkEnemies] = useState<EnemySpawnData[]>([]);

const handleEnemiesUpdate = useCallback((enemies: EnemyChunkData[]) => {
  setChunkEnemies(
    enemies.map(e => ({
      id: `chunk-enemy-${e.x}-${e.y}`,
      subtype: e.subtype,
      x: e.x,
      y: e.y,
    }))
  );
}, []);
```

Pass `onEnemiesUpdate={handleEnemiesUpdate}` to `<ChunkRenderer>`.

**4. Get enemy data from level mode:**

Use the `sceneObjects.enemies` field (from T06):
```typescript
const levelEnemies: EnemySpawnData[] = useMemo(() => {
  if (!sceneObjects?.enemies) return [];
  return sceneObjects.enemies.map(e => ({
    id: e.id,
    subtype: e.subtype,
    x: e.x,
    y: e.y,
  }));
}, [sceneObjects]);
```

**5. Merge enemy sources:**

```typescript
const activeEnemies = levelData ? levelEnemies : chunkEnemies;
```

**6. Enemy callbacks:**

```typescript

  handleDamage(); // reuse existing damage handler

  melRef.current?.stompBounce();
}, []);

const handleEnemyCoinDrop = useCallback((x: number, y: number, count: number) => {
  spawnDroppedCoins(x, y, count, DROP_VELOCITY_Y);
```

**7. Projectile enemy hit:**

Add a handler for projectile enemy hits and pass it to ProjectileManager:
```typescript
const enemyManagerRef = useRef<{ onProjectileHitEnemy: (name: string) => void }>(null);

const handleProjectileEnemyHit = useCallback((enemyName: string) => {
  // Parse enemy ID from rigid body name: "enemy-{subtype}-{id}" -> "{id}"
  // Actually EnemyManager can handle the full name or just the id.
  enemyManagerRef.current?.onProjectileHitEnemy(enemyName);
}, []);
```

Update `<ProjectileManager>`:
```tsx
<ProjectileManager
  controlsRef={controlsRef}
  playerPosRef={playerPosRef}
  facingRightRef={facingRightRef}
  onBlockHit={handleBlockHit}
  onEnemyHit={handleProjectileEnemyHit}
```

**8. Render EnemyManager:**

Add to the JSX, after `<ProjectileManager>`:
```tsx

  playerPosRef={playerPosRef}
  onMelDamage={handleEnemyDamage}
```

### Gotchas

- **Mel forwardRef compatibility:** The existing `stateRef` prop is separate from the forwardRef. Both must work simultaneously. The `stateRef` is a MutableRefObject passed as a prop; the `ref` is the forwardRef for `MelHandle`. They are independent.
- **Level mode vs infinite mode enemies:** Use `levelData ? levelEnemies : chunkEnemies` to pick the right source. In infinite mode (no levelData), enemies come from ChunkRenderer's callback. In level mode, they come from sceneObjects.
- **TestLevelData both formats:** The `generateTestLevel()` (chunk format) and `generateTestLevelV2()` (LevelDataV2 format) both need updating. The chunk format is used when `testMode=true` and no `levelData` is provided; the V2 format is used by the editor test mode. Update both for consistency.
- **Screen shake on enemy defeat:** Consider adding `shake(0.06, 0.1)` when an enemy is defeated (stomp or projectile). This is optional polish -- reuse the existing `shake` function.
- **No double damage:** When Mel stomps an enemy, the `onContactMel` callback reports `isStompable=true`. The EnemyManager calls `onMelStompBounce()` (bounce) and NOT `onMelDamage()`. Ensure these callbacks are mutually exclusive per contact event.
