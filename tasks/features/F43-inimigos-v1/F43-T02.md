# Task F43-T02 -- EnemyPigeon Component (Pombo)

**Feature:** F43
**Wave:** 0
**Type:** frontend
**Depends on:** F37 (EntityType "enemy" in LevelDataV2)
**Status:** planned

## User Story

As a player, I want to encounter flying pigeon enemies that move in sine wave patterns so that I face aerial hazards that require timing my jumps or using the Bola do Infinito.

## Objective

Create the Pombo enemy component -- a gray-blue bird that flies in a sine wave along the X axis. It damages Mel on any contact but can be defeated by stomping from above or by the Bola do Infinito.

## Dev Notes

### 1. Create `packages/frontend/src/game/entities/EnemyPigeon.tsx`

Props interface:
```typescript
interface EnemyPigeonProps {
  id: string;
  position: [number, number, number];
  onContactMel: (enemyId: string, isStompable: boolean) => void;
  defeated?: boolean;
}
```

### 2. Visual: Pigeon Bird

Build from simple geometries:
- **Body:** Box (0.5 x 0.35 x 0.35), gray-blue color (`#7B8FA1`), slight metalness for sheen
- **Head:** Smaller box (0.2 x 0.2 x 0.2) offset forward and slightly up, color `#6B7F91`
- **Beak:** Tiny box (0.08 x 0.06 x 0.06) in orange-yellow (`#FF8C00`) at the front of the head
- **Wings:** Two thin planes (0.4 x 0.15 each) attached to the sides, slightly angled. Animate wing rotation in `useFrame` with `Math.sin(time * 12) * 0.4` to simulate flapping. Color slightly lighter than body.
- **Tail:** Small thin box trailing behind, same color as body
- Overall size: ~0.7 units wide (with wings), 0.4 tall

### 3. AI: Sine Wave Flight

Implement in `useFrame`:
- Move along X axis at `FLY_SPEED = 3` units/s in the initial facing direction (determined by a prop or default right)
- Y position oscillates: `baseY + Math.sin(time * WAVE_FREQ) * WAVE_AMPLITUDE` where `WAVE_FREQ = 2.1` (period ~3s) and `WAVE_AMPLITUDE = 2`
- `baseY` is the spawn Y position
- When the pigeon travels `PATROL_RANGE = 8` units from its spawn X, reverse direction
- Flip the mesh group's X scale when changing direction
- Wings flap faster during direction change (brief acceleration of flap frequency)

Constants:
```typescript
const FLY_SPEED = 3;
const WAVE_AMPLITUDE = 2;
const WAVE_FREQ = 2.1;
const PATROL_RANGE = 8;
```

### 4. Physics Body

- `RigidBody type="kinematicPosition"` -- position controlled by AI
- `CuboidCollider args={[0.2, 0.15, 0.15]}` -- tight hitbox, fair for a flying enemy
- `name={`enemy-pigeon-${id}`}` -- prefix "enemy-" for ProjectileManager detection
- `sensor={false}` -- solid body so Mel can stomp on it

Set position each frame with `rb.setNextKinematicTranslation()`.

### 5. Collision Detection

Same approach as EnemyVacuum (T01):
- `onCollisionEnter` checks for `"mel"`
- Stomp detection: Mel's velY < -1 AND contact from above
- Alternative: Use a separate top-surface sensor collider for stomp zone
- Call `onContactMel(id, isStompable)`

Note: Stomping a pigeon is intentionally harder than stomping a vacuum because the pigeon moves vertically. This is reflected in the higher coin reward (2-3 coins vs 1-2).

### 6. Defeat Animation

When `defeated` prop becomes true:
- Stop sine wave movement
- Play "fly away" animation: rapid upward translation (much faster than normal sine wave) + shrink scale to 0 over 0.5s
- Add brief sparkle effect: 3-5 small emissive spheres (#FFD700) that expand and fade
- After animation, parent removes the component

### Gotchas

- The pigeon NEVER lands. It always flies. Its Y is always computed from the sine wave, not from physics gravity.
- Wing flapping should be cosmetic only -- do not use physics for wings.
- The pigeon should be visible from a distance to give the player time to react. Consider adding a slight emissive glow or a shadow on the ground below.
- Collision handling is fire-once per contact (use a cooldown ref of ~0.5s to prevent rapid re-triggers during the same collision).
