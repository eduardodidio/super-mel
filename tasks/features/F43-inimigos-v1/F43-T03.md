# Task F43-T03 -- EnemyBee Component (Abelha)

**Feature:** F43
**Wave:** 0
**Type:** frontend
**Depends on:** F37 (EntityType "enemy" in LevelDataV2)
**Status:** planned

## User Story

As a player, I want to encounter bee enemies that chase me when I get too close so that I face a more dangerous and dynamic threat that keeps me on my toes.

## Objective

Create the Abelha enemy component -- a small yellow-black bee that hovers idle until Mel enters its detection radius, then chases Mel slowly. It damages Mel on any contact and can be defeated by stomping or Bola do Infinito.

## Dev Notes

### 1. Create `packages/frontend/src/game/entities/EnemyBee.tsx`

Props interface:
```typescript
interface EnemyBeeProps {
  id: string;
  position: [number, number, number];
  playerPosRef: React.RefObject<{ x: number; y: number }>;
  onContactMel: (enemyId: string, isStompable: boolean) => void;
  defeated?: boolean;
}
```

Note: Unlike Vacuum and Pigeon, the Bee needs `playerPosRef` to chase Mel. The other enemies do not need to know where Mel is.

### 2. Visual: Yellow-Black Bee

Build from simple geometries:
- **Body:** Sphere (radius 0.18) or box (0.4 x 0.3 x 0.3). Use 3 alternating horizontal stripes: yellow (`#FFD700`) and black (`#1A1A1A`). Achieve stripes with 3 thin box segments stacked:
  - Top stripe: box (0.4 x 0.1 x 0.3), yellow
  - Middle stripe: box (0.4 x 0.1 x 0.3), black
  - Bottom stripe: box (0.4 x 0.1 x 0.3), yellow
- **Wings:** Two transparent planes (0.25 x 0.12) on top, tilted outward. `opacity: 0.4`, color white/light blue. Rotate at high speed in useFrame: `Math.sin(time * 25) * 0.3` for a buzzing effect.
- **Stinger:** Small cone or thin box trailing behind, dark gray
- **Eyes:** Two tiny spheres on the front, white with black pupil (or just red emissive dots for simplicity)
- **Glow:** Subtle emissive yellow on body, `emissiveIntensity: 0.3`, to make bee visible against dark backgrounds
- Overall size: ~0.5 units wide, 0.35 tall (smallest enemy)

### 3. AI: Idle + Chase

Implement in `useFrame` with a simple state machine:

```
State: "idle" | "chasing" | "returning"
```

**Idle:**
- Hover in place with gentle oscillation: `y += Math.sin(time * 3) * 0.15`, `x += Math.sin(time * 1.5) * 0.1`
- Every frame, check distance to Mel: `dist = sqrt((beeX - melX)^2 + (beeY - melY)^2)`
- If `dist < DETECT_RADIUS (6 units)`, transition to "chasing"

**Chasing:**
- Move toward Mel at `CHASE_SPEED = 2.5` units/s
- Direction vector: `normalize(melPos - beePos)`, then scale by CHASE_SPEED * delta
- Maintain gentle vertical oscillation even while chasing (looks more natural)
- If `dist > LOSE_RADIUS (10 units)`, transition to "returning"

**Returning:**
- Move back toward spawn position at `RETURN_SPEED = 1.5` units/s
- When within 0.5 units of spawn, transition to "idle"

Constants:
```typescript
const CHASE_SPEED = 2.5;
const RETURN_SPEED = 1.5;
const DETECT_RADIUS = 6;
const LOSE_RADIUS = 10;
```

### 4. Physics Body

- `RigidBody type="kinematicPosition"` -- position controlled by AI
- `CuboidCollider args={[0.18, 0.13, 0.13]}` -- tight hitbox for small body
- `name={`enemy-bee-${id}`}` -- prefix "enemy-" for ProjectileManager
- `sensor={false}` -- solid body for stomp detection

### 5. Collision Detection

Same pattern as T01/T02:
- `onCollisionEnter` checks for `"mel"`
- Stomp detection from above (hardest to execute -- bee is small and moves)
- Call `onContactMel(id, isStompable)`

### 6. Defeat Animation

When `defeated` becomes true:
- Stop chasing
- Play "fly away" animation: spiral upward (rotate + translate up) + shrink over 0.5s
- Sparkle particles: 4-6 small emissive spheres (#FFD700) bursting outward and fading
- After animation, parent removes the component

### 7. Visual State Indicator

To give the player fair warning:
- **Idle:** Wings buzz gently, body has soft yellow glow
- **Chasing:** Wings buzz faster (higher frequency), body glow intensifies (emissiveIntensity: 0.8), optionally tint body slightly red
- **Returning:** Same as idle but fading back to normal

### Relevant Files

- `packages/frontend/src/game/entities/EnemyVacuum.tsx` (T01) -- same structural pattern
- `packages/frontend/src/game/entities/EnemyPigeon.tsx` (T02) -- flight animation reference
- `packages/frontend/src/game/hooks/useGameFrame.ts` -- pause-aware frame hook

### Gotchas

- The bee needs `playerPosRef` passed down from the parent (EnemyManager). This is the same ref used by DroppedCoin and ProjectileManager.
- Chase speed must be SLOWER than Mel's walk speed (6 units/s) so the player can always outrun the bee. The bee is threatening because it is persistent, not because it is fast.
- The detection radius should be generous enough that the player sees the bee start chasing from a distance, giving time to react.
- When returning to spawn, the bee should not deal damage (debatable -- for now, it still damages on contact even while returning, for simplicity).
- Do not use actual pathfinding. Simple "move toward player" is sufficient for v1.
