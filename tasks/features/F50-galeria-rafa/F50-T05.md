**Feature:** F50

**Type:** frontend

## User Story

As a level creator, I want a "Custom" tab in the editor palette where I can upload images, see them as thumbnails, select one to place as a custom block or custom sign, and manage (delete) my uploaded assets.

## Objective

1. Add a 4th "Custom" tab to `EditorUI.tsx` with a sub-palette showing uploaded asset thumbnails and an upload button.
2. Create `CustomAssetPalette.tsx` as the content for this tab.
3. Update `EditorWrapper.tsx` to manage `customAssets` state and wire it into the editor.
4. Add `"custom_block"` and `"custom_sign"` to the `EditorTool` union.
5. Update `EditorScene3D.tsx` to render custom blocks with custom textures.

### 3. Update `packages/frontend/src/game/scenes/EditorWrapper.tsx`

Add state:
```typescript
const [customAssets, setCustomAssets] = useState<CustomAsset[]>([]);
const [selectedCustomAssetId, setSelectedCustomAssetId] = useState<string | null>(null);
const [showImageUploader, setShowImageUploader] = useState(false);
```

Handle upload flow:
```typescript
const handleCustomAssetUpload = useCallback(() => {
  if (customAssets.length >= 10) return;
  setShowImageUploader(true);
}, [customAssets.length]);

const handleImageUploaderConfirm = useCallback((asset: CustomAsset) => {
  setCustomAssets(prev => [...prev, asset]);
  setShowImageUploader(false);
  setSelectedCustomAssetId(asset.id);
  setSelectedTool("custom_block");
}, []);

const handleRemoveCustomAsset = useCallback((assetId: string) => {
  setCustomAssets(prev => prev.filter(a => a.id !== assetId));
  // Also remove any custom blocks/entities referencing this asset
  setBlocks(prev => prev.filter(b => {
    if (b.type !== "custom") return true;
    // Check if there's a custom_block_asset entity at this position referencing the removed asset
    // This is handled through entities cleanup
    return true;
  }));
  setEntities(prev => prev.filter(e => {
    if (e.type === "custom_block_asset" && e.props?.customAssetId === assetId) return false;
    if (e.type === "sign" && e.props?.customAssetId === assetId) {
      // Remove the custom image from the sign, but keep the sign
      return true; // sign stays, but props.customAssetId is removed in a separate step
    }
    return true;
  }));
  if (selectedCustomAssetId === assetId) {
    setSelectedCustomAssetId(null);
    setSelectedTool("stone");
  }
}, [selectedCustomAssetId]);
```

Handle custom tool selection:

const handleSelectCustomAsset = useCallback((assetId: string, mode: "block" | "sign") => {

### Gotchas

- The `custom_block_asset` entity at (x,y) pairs with the `custom` block at (x,y). If either is missing, the custom block falls back to the purple placeholder. This is the same pattern as `item_block_content` pairing with `item_block`.
- When erasing a custom block, also remove the `custom_block_asset` entity at the same position. The existing eraser logic in `EditorScene3D` already removes both blocks and entities, so this should work automatically.
- The `customAssets` array is passed down but NOT mutated by child components. Only `EditorWrapper` manages the array.
- `custom_sign` places only an entity (no block). `custom_block` places both a block and an entity.
