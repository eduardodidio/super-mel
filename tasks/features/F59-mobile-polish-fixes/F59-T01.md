# F59-T01 — Parallax Background Infinito

**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a player, I want the parallax background to scroll infinitely as I advance through the level, so that I never see the background end or disappear.

## Objective

Fix the parallax background mesh to follow the camera/player position dynamically, ensuring the background is always visible regardless of how far the player travels.

## Dev Notes

**Root cause:** The parallax mesh is a static plane (200 units wide) centered at origin `[0, 5, -35]`. As the player moves beyond ~100 units, the plane exits the camera frustum and the background disappears.

**Key file:** `packages/frontend/src/game/systems/ParallaxImageBackground.tsx`

**Current constants:**
- `PLANE_WIDTH = 200`
- `PLANE_HEIGHT = 40`
- `PLANE_Z = -35`
- `PLANE_Y = 5`
- `REPEAT_X = 4`
- `PARALLAX_FACTOR = 0.002`

**Current behavior (useFrame loop):**
- Reads `playerXRef.current.x`
- Sets `texture.offset.x = px * PARALLAX_FACTOR`
- Mesh position never changes

**Camera offset (from CameraRig.tsx):** `[0, 3, 18]` — camera is 18 units forward (Z) from player.

Veja `tasks/features/F59-_tmp-brief.md` para contexto completo.

## Implementation Details

1. **In the `useFrame` callback of ParallaxImageBackground.tsx:**
   - After reading `playerXRef.current.x`, also update the mesh group's position.x to track the player:
     ```tsx
     // Inside useFrame:
     const px = playerXRef.current.x;
     // Reposition mesh to follow player
     if (groupRef.current) {
       groupRef.current.position.x = px;
     }
     // Keep texture offset for parallax effect (relative to player movement)
     currentMatRef.current.map.offset.x = px * PARALLAX_FACTOR;
     ```
   - This ensures the 200-unit plane is always centered around the player, no matter how far they travel.

2. **Add a ref to the mesh group** if not already present:
   ```tsx
   const groupRef = useRef<THREE.Group>(null!);
   ```

3. **Verify Y-axis:** If player can go very high (double jump, etc.), consider also following Y within reasonable bounds, clamped to keep horizon alignment.
