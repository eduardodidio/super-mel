# F59-T05 — Fix PWA Install

**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a mobile user, I want to install Super Mel on my home screen as an app, so that I can launch it quickly without opening the browser.

## Objective

Fix the PWA installation flow: service worker activation, manifest correctness, icon validation, and install prompt handling. The user tried to install but couldn't find the app on their phone.

## Dev Notes

**Root cause candidates (from investigation):**

1. **sw.js health check failure:** Line ~28-29 and ~51-52 do `fetch("/api/health").catch(() => {})`. On static deploy (Render static site), `/api/health` returns 404. The error is caught silently but may prevent SW activation.

2. **Icon issues:** manifest.json references icons that may not exist at the expected paths or sizes.

3. **beforeinstallprompt timing:** `usePWAInstall.ts` captures the browser's install prompt event, but if SW registration fails, this event may never fire.

**Key files:**
- `packages/frontend/public/sw.js` — service worker
- `packages/frontend/public/manifest.json` — PWA manifest
- `packages/frontend/src/hooks/usePWAInstall.ts` — install prompt hook
- `packages/frontend/public/icons/` — app icons
- `packages/frontend/src/main.tsx` — SW registration (lines ~11-22)

## Implementation Details

1. **Fix sw.js — remove or fix health check:**
   - Remove the `/api/health` fetch from `activate` and `install` events
   - Or replace with a self-fetch: `fetch('/').catch(() => {})` to pre-cache the app shell
   - The SW should NOT depend on backend availability to activate

2. **Verify icons exist and are correct:**
   ```bash
   ls -la packages/frontend/public/icons/
   # Must have: icon-192.png (192x192), icon-512.png (512x512), icon-maskable-512.png (512x512)
   ```
   - If any icon is missing, generate it from existing game assets
   - Maskable icon must have 40% safe area (content centered in inner 60% of canvas)
   - Verify file sizes are reasonable (not 0 bytes, not corrupt)

3. **Add theme_color and background_color to manifest.json:**
   ```json
   {
     "theme_color": "#1a1a2e",
     "background_color": "#1a1a2e"
   }
   ```
   These are required by some browsers for install eligibility.

4. **Fix usePWAInstall.ts — add debug logging:**
   ```tsx
   useEffect(() => {
     console.log('[PWA] Registering beforeinstallprompt listener');

     const handler = (e: Event) => {
       console.log('[PWA] beforeinstallprompt fired');
       e.preventDefault();
       setDeferredPrompt(e as BeforeInstallPromptEvent);
       setCanInstall(true);
     };

     window.addEventListener('beforeinstallprompt', handler);

     // Check SW registration status
     navigator.serviceWorker?.ready.then((reg) => {
       console.log('[PWA] SW ready, scope:', reg.scope);
     });

     return () => window.removeEventListener('beforeinstallprompt', handler);
   }, []);
   ```

5. **Verify SW registration in main.tsx:**
   - Registration should happen after page load
   - Check for any error handling that swallows registration failures
   - Add console.log for registration success/failure

6. **Add appinstalled event listener:**
   ```tsx
   window.addEventListener('appinstalled', () => {
     console.log('[PWA] App installed successfully');
     setCanInstall(false);
   });
   ```

7. **Test manifest serving:**
   - After build, verify `<link rel="manifest" href="/manifest.json">` is in the HTML head
   - Verify manifest.json is served with `Content-Type: application/manifest+json`

## Acceptance Criteria

- [ ] Service worker registers and activates without errors (check DevTools > Application > Service Workers)
- [ ] manifest.json is reachable and valid (check DevTools > Application > Manifest)
- [ ] All 3 icons load correctly (no 404s in network tab)
- [ ] "Install" button appears in game menu on Chrome Android
- [ ] Clicking install triggers the browser's native install prompt
- [ ] After install, app appears on home screen with correct icon and name
- [ ] Opening installed app shows fullscreen game (no browser chrome)
- [ ] Console shows PWA debug logs for troubleshooting

## Testing

**Framework:** Manual testing on Chrome Android + DevTools Application panel
**Command:** `cd packages/frontend && npx vite build && npx vite preview --host` (PWA requires served build, not dev mode)

## Test Scenarios

1. **Happy path — Chrome Android install:** Open site, wait for SW to register, tap "Install" in menu. App should install and appear on home screen.
2. **Happy path — launch installed app:** Open from home screen. Should launch fullscreen, no browser chrome.
3. **Edge case — offline:** After install, enable airplane mode. App should show cached shell (at minimum the loading screen).
4. **Edge case — re-install:** Uninstall app, revisit site. Install prompt should appear again.
5. **DevTools audit:** Run Lighthouse PWA audit. All installability checks should pass.
6. **Error case — missing icon:** Temporarily rename an icon file. Verify graceful degradation (app still works, just can't install).
7. **Safari iOS:** Test "Add to Home Screen" flow. Verify icon and name appear correctly.
