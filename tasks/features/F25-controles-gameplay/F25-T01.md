# Task F25-T01 — Expandir Controls Interface + Remapear Teclas

**Feature:** F25
**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a player, I want arrow keys to control direction (left/right/down/up) and Space to jump/fly, so that the controls feel like a classic platformer.

## Objective

Expand the Controls interface with `down` and `up` booleans, remap keyboard bindings so ArrowUp is "look up" (not jump), and Space is the sole jump key.

## Dev Notes

- File: `packages/frontend/src/game/hooks/useControls.ts`
- Current interface: `{ left, right, jump, shoot }` — add `down: boolean` and `up: boolean`
- Current key map:
  - ArrowLeft/KeyA -> left (KEEP)
  - ArrowRight/KeyD -> right (KEEP)
  - Space/ArrowUp/KeyW -> jump (CHANGE: remove ArrowUp and KeyW from jump)
  - KeyZ/KeyJ -> shoot (KEEP)
- New key map:
  - ArrowDown/KeyS -> down (NEW)
  - ArrowUp/KeyW -> up (NEW — was jump, now look up)
  - Space -> jump (ONLY Space triggers jump now)
- Add `e.preventDefault()` on ArrowDown to prevent page scroll
- Initialize new booleans as `false` in useRef default

## Testing

- Manual: press ArrowUp — should NOT trigger jump, should set `up: true`
- Manual: press ArrowDown — should set `down: true`
- Manual: press Space — should trigger jump
- Verify no regressions: left/right/shoot still work

## Implementation details

- File: `packages/frontend/src/game/hooks/useControls.ts`
- Add `down: boolean` and `up: boolean` to `Controls` interface (line 3-8)
- Update useRef default (line 11): add `down: false, up: false`
- onKeyDown switch: add `ArrowDown`/`KeyS` case for `down`, add `ArrowUp`/`KeyW` case for `up`, remove ArrowUp/KeyW from Space case
- onKeyUp switch: mirror the same changes
- Keep `e.preventDefault()` on ArrowDown and ArrowUp to prevent scrolling

## Acceptance criteria

- [ ] Controls interface has 6 booleans: left, right, jump, shoot, down, up
- [ ] ArrowUp sets `up: true` (not jump)
- [ ] ArrowDown sets `down: true`
- [ ] Space is the only key that sets `jump: true`
- [ ] KeyW sets `up: true` (not jump)
- [ ] KeyS sets `down: true`
