# Task F25-T03 — Mel Movement: Crouch + Fly + Look Up Physics

**Feature:** F25
**Wave:** 1
**Type:** frontend
**Depends on:** F25-T01, F25-T02
**Status:** planned

## User Story

As a player, I want crouching to shrink Mel's hitbox, flying to let me hover by holding Space, and looking up to shift my view, so that gameplay has depth and variety.

## Objective

Implement crouch, fly, and look-up mechanics in Mel.tsx, wiring the new Controls fields (down, up) and AnimInput fields (crouching, lookingUp, flying) into the game loop.

## Dev Notes

### File: `packages/frontend/src/game/entities/Mel.tsx`

**New constants:**
```ts
const FLY_FORCE = 8;          // upward force while holding space in air
const FLY_GRAVITY_SCALE = 0.4; // reduced gravity while flying
const FLY_MAX_VEL_Y = 4;      // cap upward velocity during fly
const CROUCH_SPEED_MULT = 0.4; // movement speed multiplier while crouching
```

**New refs:**
```ts
const flying = useRef(false);      // true while fly mode is active
const crouching = useRef(false);   // true while crouch is held
const lookingUp = useRef(false);   // true while up is held
```

**Crouch mechanics (inside useFrame):**
- If `ctrl.down && grounded.current`: set `crouching.current = true`
- Else: `crouching.current = false`
- When crouching: multiply targetVelX by CROUCH_SPEED_MULT
- Collider change: dynamically adjust the invisible collider mesh scale Y (0.9 -> 0.5) and reposition. Note: Rapier cuboid colliders are set at mount time, so use `rb.setNextKinematicTranslation` or just offset sprite. Simpler approach: reduce the sprite position offset and keep same physics collider (visual-only crouch for now, unless we add dynamic collider resizing).
- **Simplest approach**: visual crouch (sprite ducks, speed reduced) without collider change. This avoids Rapier complexity. Can add collider resizing in a future iteration.

**Fly mechanics (inside useFrame):**
- After jump logic: if `ctrl.jump` (Space held) and `!grounded.current` and `jumping.current` (was in a jump): set `flying.current = true`
- While `flying.current && ctrl.jump && !grounded.current`:
  - Apply upward force: `vel.y + FLY_FORCE * delta`, capped at FLY_MAX_VEL_Y
  - Reduce effective gravity (set linvel with reduced downward pull)
- **Landing disables fly**: if `grounded.current && flying.current`: `flying.current = false`
- If `!ctrl.jump`: `flying.current = false` (release Space stops fly)
- Fly is only possible after a jump (can't fly from ground without jumping first)

**Look up mechanics:**
- If `ctrl.up && grounded.current && !ctrl.left && !ctrl.right`: `lookingUp.current = true`
- Else: `lookingUp.current = false`
- Look up is visual only (camera handles the shift in T04)
- Expose `lookingUp` state via a new callback: `onLookUp?: (looking: boolean) => void`

**AnimInput update (line ~162):**
- Add `crouching: crouching.current`, `lookingUp: lookingUp.current`, `flying: flying.current` to the AnimInput object passed to `stateMachine.current.update()`

**MelProps update:**
- Add `onLookUp?: (looking: boolean) => void` to MelProps interface
- Call `onLookUp?.(lookingUp.current)` each frame (only when value changes to avoid spam)

## Acceptance criteria

- [ ] Holding ArrowDown while grounded: crouching activates (speed reduced by 60%)
- [ ] Releasing ArrowDown: crouch deactivates
- [ ] Cannot crouch while airborne
- [ ] Jump then hold Space: fly activates (gentle upward movement)
- [ ] Fly caps at FLY_MAX_VEL_Y (no rocket launch)
- [ ] Release Space during fly: fly deactivates, normal gravity resumes
- [ ] Landing while flying: fly automatically deactivates
- [ ] Must jump first to fly (can't fly from standing)
- [ ] ArrowUp while grounded+stationary: look_up state activates
- [ ] Moving cancels look_up
- [ ] AnimInput correctly passes crouching/lookingUp/flying to state machine
- [ ] Attack (Z) still works during crouch
- [ ] No regression on existing jump, walk, run mechanics

## Test scenarios

- **Happy path:** Run right, press down -> slows to crouch speed, releases -> normal
- **Happy path:** Jump, hold space -> rises slowly, release -> falls

- **Edge case:** Fly into ceiling block -> velocity capped, no glitch
