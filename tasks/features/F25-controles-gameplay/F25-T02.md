# Task F25-T02 — Animation States: crouch, look_up, fly

**Feature:** F25
**Wave:** 0
**Type:** frontend
**Depends on:** (none)
**Status:** planned

## User Story

As a player, I want Mel's animations to reflect crouching, looking up, and flying, so that visual feedback matches my inputs.

## Objective

Add `crouch`, `look_up`, and `fly` states to the AnimationStateMachine and corresponding animation definitions in SpriteAnimator. Use existing sprites as placeholders (sit for crouch, idle for look_up, jump_air for fly).

## Dev Notes

### AnimationStateMachine.ts (`packages/frontend/src/game/systems/AnimationStateMachine.ts`)

- Add to `AnimState` type union: `"crouch"`, `"look_up"`, `"fly"`
- Add to `AnimInput` interface: `crouching: boolean`, `lookingUp: boolean`, `flying: boolean`
- Add to `ANIM_NAME_MAP`:
  - `crouch: "crouch"`
  - `look_up: "look_up"`
  - `fly: "fly"`
- Update `update()` method priorities (insert between existing priorities):
  - After Priority 4 (jump/airborne): if `input.flying && !input.grounded` -> transition to `"fly"`
  - After Priority 7 (walk), before Priority 8 (sit): if `input.crouching && input.grounded` -> `"crouch"`, if `input.lookingUp && input.grounded` -> `"look_up"`
- `crouch` and `look_up` are interruptible (do NOT add to NON_INTERRUPTIBLE set)
- `fly` is interruptible
- `canStartAttack()`: add `"crouch"` to the allowed list (can attack while crouching)

### SpriteAnimator.ts (`packages/frontend/src/game/systems/SpriteAnimator.ts`)

- Add to ANIMATIONS record:
  ```
  crouch: { name: "crouch", frames: ["sit"], fps: 4, loop: true }       // placeholder: reuse sit sprite
  look_up: { name: "look_up", frames: ["idle_right"], fps: 4, loop: true } // placeholder: reuse idle
  fly: { name: "fly", frames: ["jump_air"], fps: 8, loop: true }        // placeholder: reuse jump_air
  ```
