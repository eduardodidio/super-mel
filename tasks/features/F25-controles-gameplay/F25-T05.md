# Task F25-T05 — Mobile Touch Controls: 4-Direction D-Pad

**Feature:** F25
**Wave:** 1
**Type:** frontend
**Depends on:** F25-T01
**Status:** planned

## User Story

As a mobile player, I want a 4-direction D-pad and action buttons, so that I can crouch, look up, jump/fly, and attack on touchscreen.

## Objective

Update TouchControls3D to have a 4-directional D-pad (left, right, up, down) and maintain A (jump/fly) + B (attack) action buttons.

## Dev Notes

### File: `packages/frontend/src/game/systems/TouchControls3D.tsx`

- Current D-pad: 2 buttons (left, right) in a horizontal flex row
- New D-pad layout: cross/plus shape with 4 buttons:
  ```
       [UP]
  [LEFT]  [RIGHT]
      [DOWN]
  ```
- Use CSS grid or absolute positioning within a fixed-size container
- Button handlers:
  - UP: `onTouchStart={set("up", true)}` / `onTouchEnd={set("up", false)}`
  - DOWN: `onTouchStart={set("down", true)}` / `onTouchEnd={set("down", false)}`
  - LEFT/RIGHT: unchanged
- Action buttons (right side): keep A (jump) and B (shoot) as-is
- A button: holding = fly (same as Space hold on desktop) — no code change needed since it maps to `jump` which the fly logic in Mel.tsx uses
- Increase touch area slightly for comfort (72px for directional buttons)
- Add `touchAction: "none"` to prevent browser gestures

### Styles:
- D-pad container: ~180x180px, position relative
- UP button: centered top
- LEFT button: left middle
- RIGHT button: right middle
- DOWN button: centered bottom
- Use distinct arrows: up triangle, down triangle, left triangle, right triangle

## Testing

- Manual (mobile/devtools): tap each D-pad direction -> correct boolean sets
- Manual: hold A button in air -> fly activates
- Manual: tap D-pad down -> crouch activates
