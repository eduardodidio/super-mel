# Task F25-T04 — Camera Look-Up Offset

**Feature:** F25
**Wave:** 1
**Type:** frontend
**Depends on:** F25-T01
**Status:** planned

## User Story

As a player, I want the camera to pan up when I press ArrowUp, so that I can see what's above Mel.

## Objective

Add a vertical camera offset when the player is looking up, smoothly interpolating the camera position upward to reveal overhead platforms and obstacles.

## Dev Notes

### File: `packages/frontend/src/game/systems/CameraRig.tsx`

- Current CameraRig props: `{ targetRef, offset, lerpSpeed, deadzone }`
- Add new prop: `lookUpOffset?: number` (default: 5 — units to shift camera up)
- Add new prop: `isLookingUp?: boolean` (default: false)
- In the useFrame update:
  - When `isLookingUp`: interpolate the Y component of the camera target by adding `lookUpOffset` to the target Y
  - Use a separate lerp for the look-up offset to create smooth pan: `currentLookOffset = THREE.MathUtils.lerp(currentLookOffset, isLookingUp ? lookUpOffset : 0, lerpSpeed)`
  - Add `currentLookOffset` ref to track the smooth interpolation
- The offset should feel natural: ~0.5s to pan up fully, same to pan back down

### File: `packages/frontend/src/game/scenes/GameScene3D.tsx`

- Add state to track look-up: `const [isLookingUp, setIsLookingUp] = useState(false)`
- Pass to Mel: `onLookUp={setIsLookingUp}`
- Pass to CameraRig: `isLookingUp={isLookingUp} lookUpOffset={5}`

## Testing

- Manual: hold ArrowUp while standing -> camera smoothly pans up ~5 units
- Manual: release ArrowUp -> camera smoothly returns to normal offset
- Manual: move while looking up -> look up cancels, camera returns

## Implementation details

- File 1: `packages/frontend/src/game/systems/CameraRig.tsx` — add props + lerp logic
- File 2: `packages/frontend/src/game/scenes/GameScene3D.tsx` — wire isLookingUp state

## Acceptance criteria

- [ ] Camera pans up smoothly when ArrowUp held (grounded, stationary)
- [ ] Camera returns smoothly when ArrowUp released
- [ ] Pan distance is ~5 units (configurable via prop)
- [ ] Smooth interpolation (no snap/jitter)
- [ ] No interference with existing deadzone/tracking behavior

## Test scenarios

- **Happy path:** Stand still, hold Up -> camera pans up over ~0.5s
- **Edge case:** Rapidly tap Up -> camera bounces smoothly, no jitter
- **Edge case:** Jump while looking up -> look up cancels, camera follows jump normally
