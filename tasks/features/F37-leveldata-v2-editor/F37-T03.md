# Task F37-T03 -- Backend Validation for v2 Format

**Feature:** F37
**Wave:** 1
**Type:** backend
**Depends on:** F37-T01
**Status:** planned

## User Story

As a player saving a level, I want the server to validate my level data so that corrupted or malicious payloads are rejected before being stored in the database.

## Objective

Add structural validation of LevelDataV2 to the backend POST and PUT routes in `packages/backend/src/routes/levels.ts`. Auto-migrate v1 data to v2 on GET responses.

## Dev Notes

### 1. Create `packages/backend/src/validation/levelValidation.ts`

This file contains the validation logic, separate from the route handler for testability.

```typescript
import type { EntityType, LevelDataV2 } from "@super-mel/shared";

const VALID_ENTITY_TYPES: Set<string> = new Set([
  "coin", "heart", "goal", "checkpoint", "spawn",
  "item_block_content", "sign", "bone", "enemy",
]);

const VALID_BLOCK_TYPES: Set<string> = new Set([
  "empty", "stone", "sand", "wood", "iron", "dirt",
  "brick", "glass", "leaf", "water", "lava", "item_block",
]);

interface ValidationResult {
  valid: boolean;
  errors: string[];
}

/**
 * Validate that `data` conforms to LevelDataV2 structural requirements.
 *
 * Checks:
 * - version === 2
 * - grid is a 2D array (exists, is array of arrays)
 * - width and height are positive integers
 * - entities is an array
 * - Each entity has a valid type, numeric x, numeric y
 * - At most 1 spawn entity
 * - At most 1 goal entity
 * - Grid dimensions: width <= 200, height <= 100 (sane limits)
 * - Entity count <= 500 (prevent abuse)
 *
 * Does NOT deep-validate:
 * - Block types in every grid cell (too slow for large grids)
 * - Entity positions within grid bounds (client responsibility)
 * - props object contents (opaque by design)
 */
export function validateLevelDataV2(data: unknown): ValidationResult {
  const errors: string[] = [];

  if (!data || typeof data !== "object") {
    return { valid: false, errors: ["data must be an object"] };
  }

  const obj = data as Record<string, unknown>;

  // Version
  if (obj.version !== 2) {
    errors.push("data.version must be 2");
  }

  // Grid
  if (!Array.isArray(obj.grid)) {
    errors.push("data.grid must be an array");
  } else {
    // Check first row is array (shallow check)
    if (obj.grid.length > 0 && !Array.isArray(obj.grid[0])) {
      errors.push("data.grid must be a 2D array (grid[0] is not an array)");
    }
  }

  // Dimensions
  if (typeof obj.width !== "number" || obj.width <= 0 || obj.width > 200) {
    errors.push("data.width must be a positive number <= 200");
  }
  if (typeof obj.height !== "number" || obj.height <= 0 || obj.height > 100) {
    errors.push("data.height must be a positive number <= 100");
  }

  // Entities
  if (!Array.isArray(obj.entities)) {
    errors.push("data.entities must be an array");
  } else {
    if (obj.entities.length > 500) {
      errors.push("data.entities exceeds maximum of 500 entities");
    }

    let spawnCount = 0;
    let goalCount = 0;

    for (let i = 0; i < obj.entities.length; i++) {
      const e = obj.entities[i];
      if (!e || typeof e !== "object") {
        errors.push(`data.entities[${i}] must be an object`);
        continue;
      }
      const ent = e as Record<string, unknown>;

      if (typeof ent.type !== "string" || !VALID_ENTITY_TYPES.has(ent.type)) {
        errors.push(`data.entities[${i}].type "${ent.type}" is not a valid EntityType`);
      } else {
        if (ent.type === "spawn") spawnCount++;
        if (ent.type === "goal") goalCount++;
      }

      if (typeof ent.x !== "number") {
        errors.push(`data.entities[${i}].x must be a number`);
      }
      if (typeof ent.y !== "number") {
        errors.push(`data.entities[${i}].y must be a number`);
      }
    }

    if (spawnCount > 1) {
      errors.push("data.entities must contain at most 1 spawn entity");
    }
    if (goalCount > 1) {
      errors.push("data.entities must contain at most 1 goal entity");
    }
  }

  // Optional: theme
  if (obj.theme !== undefined) {
    const validThemes = ["forest", "desert", "night", "space", "ocean"];
    if (typeof obj.theme !== "string" || !validThemes.includes(obj.theme)) {
      errors.push(`data.theme "${obj.theme}" is not a valid BackgroundTheme`);
    }
  }

  return { valid: errors.length === 0, errors };
}
```

### 2. Update `packages/backend/src/routes/levels.ts`

Import the validation function and the migration function, then apply them to routes.

**POST `/` (create level):**

```typescript
import { validateLevelDataV2 } from "../validation/levelValidation";
import { migrateLevelData } from "@super-mel/shared";

// Inside the POST handler, before prisma.level.create:
// 1. Try to migrate data to v2 (handles v1 input)
let levelData: LevelDataV2;
try {
  levelData = migrateLevelData(data);
} catch (err: any) {
  return reply.status(400).send({ error: `Invalid level data: ${err.message}` });
}

// 2. Validate v2 structure
const validation = validateLevelDataV2(levelData);
if (!validation.valid) {
  return reply.status(400).send({
    error: "Invalid level data",
    details: validation.errors,
  });
}

// 3. Store the v2 data (always store as v2 going forward)
const level = await prisma.level.create({
  data: {
    creatorId,
    name,
    data: levelData as any, // Prisma Json type
    background: background || (levelData.theme ?? "forest"),
  },
});
```

**PUT `/:id` (update level):**

Same validation pattern for the `data` field, but only if `data` is present in the request body (partial updates may not include data).

```typescript
if (request.body.data !== undefined) {
  let levelData: LevelDataV2;
  try {
    levelData = migrateLevelData(request.body.data);
  } catch (err: any) {
    return reply.status(400).send({ error: `Invalid level data: ${err.message}` });
  }

  const validation = validateLevelDataV2(levelData);
  if (!validation.valid) {
    return reply.status(400).send({
      error: "Invalid level data",
      details: validation.errors,
    });
  }

  // Replace raw data with migrated v2
  request.body.data = levelData;
}
```

**GET `/:id` (read level):**

Auto-migrate v1 data in the response so clients always receive v2.

```typescript
app.get<{ Params: { id: string } }>("/:id", async (request, reply) => {
  const { id } = request.params;
  try {
    const level = await prisma.level.findUnique({ where: { id } });
    if (!level) return reply.status(404).send({ error: "Fase nao encontrada" });

    // Auto-migrate data to v2 in response
    try {
      const migratedData = migrateLevelData(level.data);
      return { ...level, data: migratedData };
    } catch {
      // If migration fails, return raw data (don't break existing levels)
      return level;
    }
  } catch {
    return reply.status(503).send({ error: "Banco indisponivel" });
  }
});
```

### 3. Import setup

The backend needs to import from `@super-mel/shared`. Check that the workspace resolution works:
- `packages/backend/package.json` should have `"@super-mel/shared": "workspace:*"` in dependencies
- If the shared package exports via `src/index.ts`, the migration function must be re-exported there (done in T01)
- If imports fail, the developer should add the dependency and ensure tsconfig paths are configured

### 4. Error response format

All validation errors return HTTP 400 with body:

```json
{
  "error": "Invalid level data",
  "details": ["data.version must be 2", "data.entities[0].type \"invalid\" is not a valid EntityType"]
}
```

This helps frontend developers debug save failures.

## Test Scenarios

- **Happy path:** POST valid v2 data -> 200
- **Happy path:** POST valid v1 data -> migrated and stored as v2 -> 200
- **Validation error:** POST with version:3 -> 400
- **Validation error:** Entity with type "dragon" -> 400
- **Validation error:** 2 spawn entities -> 400
- **Validation error:** entities not an array -> 400
- **Edge case:** PUT without data field -> no validation, update other fields normally
- **Edge case:** GET v1 level -> response has version:2 with migrated entities
- **Graceful degradation:** GET level with unmigrateable data -> returns raw (no crash)
