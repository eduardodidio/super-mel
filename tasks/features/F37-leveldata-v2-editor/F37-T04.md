# Task F37-T04 -- Editor Palette Tabs UI

**Feature:** F37
**Wave:** 1
**Type:** frontend (UI)
**Depends on:** F37-T01
**Status:** planned

## User Story

As a level creator, I want the editor palette organized into tabs (Blocos, Itens, Especiais) so that I can easily find and select blocks, collectible items, and special markers to place in my level.

## Objective

Refactor `EditorUI.tsx` to replace the single block-only palette with a tabbed palette that also includes entity tools for coins, hearts, item_block content, spawn, checkpoint, and goal.

## Dev Notes

### 1. New tool type

The current `selectedTool` type is:
```typescript
Exclude<BlockType, "empty"> | "eraser" | "spawn"
```

Expand it to include entity types. Define a unified tool type:

```typescript
// In EditorUI.tsx (or a shared editor types file)
export type EditorTool =
  // Block tools (existing)
  | Exclude<BlockType, "empty">
  | "eraser"
  // Entity tools (new)
  | "entity_coin"
  | "entity_heart"
  | "entity_item_block"   // places item_block block + item_block_content entity
  | "entity_spawn"
  | "entity_checkpoint"
  | "entity_goal";
```

Note: the "spawn" tool is renamed to "entity_spawn" for consistency. The `selectedTool` prop and `onSelectTool` callback must use this expanded type.

### 2. Tab state

type PaletteTab = "blocos" | "itens" | "especiais";

### 5. Item block content state

When "entity_item_block" tool is selected, show a small dropdown below the palette:

```typescript
const [itemBlockContent, setItemBlockContent] = useState<"coin" | "heart" | "power_up">("coin");
```

The dropdown options:
- Moeda (coin) -- default
- Coracao (heart)
- Power-up (power_up)

This content value is passed up to the parent via a new callback or exposed via a ref. The simplest approach: add an optional `onItemBlockContentChange?: (content: string) => void` prop, or include it in the tool selection: when selecting "entity_item_block", the parent also gets the content type.

**Recommended approach:** Expand the tool selection to include content:

```typescript
// In parent component, store:
const [selectedTool, setSelectedTool] = useState<EditorTool>("stone");
const [itemBlockContent, setItemBlockContent] = useState<string>("coin");
```

Pass both to EditorScene3D so it knows what entity props to attach.
