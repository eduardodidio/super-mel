As a player, I want to see a stamina bar on screen when Mel is flying so I know exactly how much flight time remains before I fall.

## Objective

- Cape icon (CSS-drawn or Unicode)
- Animated bar that drains as flight time depletes
- Color transitions (blue -> yellow -> red)
- Remaining time text
- Fade-out animation after landing

#### 3. Add StaminaBar sub-component

Create a `StaminaBar` component inside `HUD3D.tsx` (before the `HUD3D` export):

```typescript
const MAX_FLY_TIME = 5;
const FADE_DELAY_MS = 1500;

function StaminaBar({ isFlying, timeRemaining }: { isFlying: boolean; timeRemaining: number }) {
  const [visible, setVisible] = useState(false);
  const [opacity, setOpacity] = useState(0);
  const fadeTimerRef = useRef<number | null>(null);

  useEffect(() => {
    if (isFlying) {
      // Show immediately when flying starts
      setVisible(true);
      setOpacity(1);
      if (fadeTimerRef.current !== null) {
        clearTimeout(fadeTimerRef.current);
        fadeTimerRef.current = null;
      }
    } else if (visible) {
      // Start fade-out after landing
      fadeTimerRef.current = window.setTimeout(() => {
        setOpacity(0);
        // Hide after fade transition completes
        fadeTimerRef.current = window.setTimeout(() => {
          setVisible(false);
          fadeTimerRef.current = null;
        }, 500);
      }, FADE_DELAY_MS);
    }
    return () => {
      if (fadeTimerRef.current !== null) {
        clearTimeout(fadeTimerRef.current);
      }
    };
  }, [isFlying]);

  if (!visible) return null;

  const fraction = timeRemaining / MAX_FLY_TIME; // 1.0 = full, 0.0 = empty
  const barColor = fraction > 0.5
    ? `rgb(${Math.round((1 - fraction) * 2 * 255)}, ${Math.round(100 + fraction * 155)}, 255)`  // blue -> yellow
    : `rgb(255, ${Math.round(fraction * 2 * 200)}, ${Math.round(fraction * 2 * 50)})`;           // yellow -> red

  return (
    <div style={{
      display: "flex",
      alignItems: "center",
      gap: 6,
      marginTop: 6,
      opacity,
      transition: "opacity 0.5s ease-out",
    }}>
      {/* Cape icon */}
      <span style={{
        fontSize: "16px",
        filter: "drop-shadow(1px 1px 1px rgba(0,0,0,0.5))",
        color: "#88bbff",
      }}>
        {/* Wing/cape symbol */}
        &#9978;
      </span>

      {/* Bar container */}
      <div style={{
        width: 120,
        height: 10,
        background: "rgba(0,0,0,0.5)",
        borderRadius: 5,
        border: "1px solid rgba(255,255,255,0.2)",
        overflow: "hidden",
        position: "relative",
      }}>
        {/* Bar fill */}
        <div style={{
          width: `${fraction * 100}%`,
          height: "100%",
          background: barColor,
          borderRadius: 4,
          transition: "width 0.1s linear",
          boxShadow: `0 0 4px ${barColor}`,
        }} />
      </div>

      {/* Time text */}
      <span style={{
        color: barColor,
        fontSize: "11px",
        fontWeight: "bold",
        fontFamily: "monospace",
        textShadow: "1px 1px 0 #000",
        minWidth: 30,
      }}>
        {timeRemaining.toFixed(1)}s
      </span>
    </div>
  );
}
```

### Color math explanation

The color gradient uses linear interpolation:
- `fraction > 0.5` (2.5-5s remaining): blue-ish -> yellow (green+red increase, blue stays)
- `fraction <= 0.5` (0-2.5s remaining): yellow -> red (green decreases, blue gone)

This gives an intuitive "safe blue -> warning yellow -> danger red" gradient.

### Cape icon alternatives

The primary choice is Unicode `&#9978;` (heavy six pointed star with chevron) which renders like a badge/cape. If it does not render well across browsers, fallback options:
- `&#128747;` (small airplane)
- A simple CSS triangle/wing shape
- Text label "FLY" in styled span

The developer should check rendering in Chrome and Firefox and pick the best option.

### Fade-out behavior

1. Flight starts -> bar appears instantly (opacity 1)
2. Flight ends (land or release Space) -> bar stays visible for 1.5s at full opacity
3. After 1.5s -> fade to opacity 0 over 0.5s CSS transition
4. After fade completes -> `visible=false`, component unmounts from DOM

This lets the player see their "last known" stamina level briefly after landing.
