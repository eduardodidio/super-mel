# Task F34-T01 — Expose fly state from Mel via callback

**Feature:** F34
**Wave:** 0
**Type:** frontend (entity)
**Depends on:** (none)
**Status:** planned

## User Story

As a developer wiring the HUD, I need Mel to expose its internal flight state (flying boolean and time remaining) so that parent components can display stamina information to the player.

## Objective

Add a new optional callback prop `onFlyStateUpdate` to the `Mel` component. Call it every frame during `useFrame` with the current flying state and time remaining.

### 3. Call the callback in useFrame (after line ~178)

After the existing fly logic block (lines 158-178) and the `onPositionUpdate` call (line 180), add the fly state callback. Place it right after `onPositionUpdate`:

```typescript
onPositionUpdate?.(pos.x, pos.y);
onFlyStateUpdate?.(flying.current, Math.max(0, MAX_FLY_TIME - flyTimer.current));  // NEW
```

### Design decisions

- **timeRemaining (not timeElapsed):** The HUD needs "time remaining" to fill the bar. Computing `MAX_FLY_TIME - flyTimer` here avoids leaking the internal constant.
- **Called every frame:** Same pattern as `onPositionUpdate`. The parent can debounce or use zustand selectors to avoid unnecessary re-renders.
- **Optional prop:** Backward-compatible. Existing call sites that don't pass `onFlyStateUpdate` are unaffected.
- **Math.max(0, ...):** Prevents negative values if flyTimer slightly overshoots MAX_FLY_TIME within a frame.

## Test Scenarios

- **Happy path:** Fly (hold Space after jump) — callback reports `flying=true`, timeRemaining counting down from 5.0
- **Happy path:** Land on ground — callback reports `flying=false`, timeRemaining=5.0 (timer resets)
- **Edge case:** Fly until stamina runs out — timeRemaining reaches 0, flying flips to false
- **Edge case:** Release Space mid-flight — flying=false, timeRemaining stops at whatever value it had
- **Regression:** Jump without flying — flying stays false, timeRemaining stays 5.0
- **Regression:** All existing Mel mechanics (move, jump, crouch, attack, look up) unaffected
