## User Story

As the HUD component, I need fly state available in the global zustand store so I can reactively display the stamina bar without prop-drilling through the Canvas boundary.

## Objective

### Design decisions

- **Zustand over prop-drilling:** HUD3D is rendered outside the Canvas in Game3D.tsx, so we cannot pass refs through the R3F scene tree. Zustand is the established pattern (lives, score, coins all use it).
- **`setFlyState` as a single action:** Avoids two separate `set()` calls per frame. One zustand update = one state merge = one potential re-render.
- **Default flyTimeRemaining = 5:** Matches `MAX_FLY_TIME` in Mel.tsx. When not flying, the bar should show "full" briefly before fading out.
- **Reset in resetGame/startTestMode:** Prevents stale fly state from a previous session leaking into a new game.
