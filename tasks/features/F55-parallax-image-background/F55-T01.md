## User Story

As a player, I want to see a beautiful mountain landscape behind the game world,
so that the game feels more immersive with depth and visual richness.

## Objective

Move parallax image assets to the public folder for Vite static serving, and
create the `ParallaxImageBackground` React Three Fiber component that renders a
textured plane at deep Z with horizontal tiling and slow parallax scrolling.

### Component: `ParallaxImageBackground.tsx`

Location: `packages/frontend/src/game/systems/ParallaxImageBackground.tsx`

Key design:

- **Single textured plane** at Z = -30 (behind BackgroundDecor mountains at Z ~ -18 to -26)
- Load texture via `useLoader(THREE.TextureLoader, url)` or `useMemo` + `TextureLoader`
- Set `texture.wrapS = THREE.RepeatWrapping` for horizontal tiling
- Set `texture.colorSpace = THREE.SRGBColorSpace` for correct colors
- Set `texture.magFilter = THREE.LinearFilter` (smooth, not pixelated)
- The plane should be very wide (e.g. 200 units) and tall enough (~40 units) to fill viewport
- Position Y slightly above ground level (e.g. Y=5) so mountains align with horizon

### Parallax scrolling

- Use `useFrame` to update `texture.offset.x` based on `playerXRef.current.x * PARALLAX_FACTOR`
- `PARALLAX_FACTOR` should be very small (~0.001 to 0.003) for deep background feel
- The repeat count on X should be enough to cover the wide plane (e.g. `texture.repeat.set(3, 1)`)

### Props interface

```typescript
interface ParallaxImageBackgroundProps {
  theme: BackgroundTheme;
  playerXRef: React.RefObject<{ x: number; y: number }>;
  nextTheme?: BackgroundTheme | null;
  transitionFactor?: number;
}
```

### Theme-to-image mapping

```typescript
const THEME_IMAGES: Record<BackgroundTheme, string> = {
  forest: "/backgrounds/montanhas.jpg",

  night: "/backgrounds/montanhas.jpg",
  space: "/backgrounds/deserto.jpg",
  ocean: "/backgrounds/montanhas.jpg",
```

### Cross-fade during biome transitions

When `nextTheme` is set and `transitionFactor > 0`:
- Render TWO planes (current + next theme image)
- Current plane: opacity = `1 - transitionFactor`
- Next plane: opacity = `transitionFactor`, positioned at same Z (or Z-0.1)
- Both use `transparent: true` on the material
- When `transitionFactor` reaches 1, only render the next theme's plane

### Existing patterns to follow

- Same ref pattern as `BackgroundDecor.tsx` lines 8-9 (`playerXRef`)
- Same transition interface as `Skybox.tsx` lines 80-84 (theme + nextTheme + transitionFactor)
- Use `meshBasicMaterial` (not `meshStandardMaterial`) — background doesn't need lighting
