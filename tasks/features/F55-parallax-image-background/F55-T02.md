# F55-T02: Integration with BackgroundDecor + BiomeTransition

**Wave:** 1
**Type:** frontend
**Depends on:** F55-T01
**Status:** done

## User Story

As a player, I want the parallax background to appear automatically in every
game mode (infinite, level, test), so that the visual depth is consistent
across all gameplay experiences.

## Objective

Wire `ParallaxImageBackground` into the existing rendering pipeline so it
appears behind all procedural decor in both infinite mode (via BiomeTransition)
and level/test mode (via BackgroundDecor directly in GameScene3D).

## Dev Notes

### Integration point 1: `BackgroundDecor.tsx`

File: `packages/frontend/src/game/systems/BackgroundDecor.tsx`

Add `ParallaxImageBackground` as the **first element** in the JSX return
(line ~183), before the clouds group. This ensures it renders behind everything.

```tsx
import { ParallaxImageBackground } from "./ParallaxImageBackground";

// In the return JSX, add BEFORE the clouds group:
<ParallaxImageBackground
  theme={theme}
  playerXRef={playerXRef}
  nextTheme={nextTheme}
  transitionFactor={transitionFactor}
/>
```

The `BackgroundDecor` already receives `theme`, `playerXRef`, `nextTheme`, and
`transitionFactor` props (lines 6-11), so these pass straight through.

### Integration point 2: `BiomeTransition.tsx`

File: `packages/frontend/src/game/systems/BiomeTransition.tsx`

Since `BiomeTransition` renders `BackgroundDecor` (line 31), the parallax
image will automatically appear in infinite mode too — no changes needed
to `BiomeTransition.tsx` itself.

However, verify that the `BackgroundDecor` already passes through the
`nextTheme` and `transitionFactor` props correctly (it does, lines 32-35).

### Integration point 3: `GameScene3D.tsx`

File: `packages/frontend/src/game/scenes/GameScene3D.tsx`

The non-infinite path (line 561) renders:
```tsx
<BackgroundDecor theme={theme} playerXRef={playerPosRef} />
```

This does NOT pass `nextTheme`/`transitionFactor` — that's fine because
level/test mode uses a fixed theme. The `ParallaxImageBackground` inside
`BackgroundDecor` will just show the static image for that theme.

**No changes needed to `GameScene3D.tsx`.**

### Z-depth ordering verification

Ensure the parallax image plane (Z = -30) is behind:
- Procedural mountains: Z = -18 to -26 (BackgroundDecor lines 73-78)
- Clouds: Z = -12 to -27 (BackgroundDecor lines 62-63)
- Stars: Z = -20 to -30 (BackgroundDecor lines 91-92)

If stars overlap (Z up to -30), adjust the parallax plane to Z = -35.

### Fog interaction

The `Skybox` sets scene fog (Skybox.tsx line 161). The parallax plane at Z = -30
to -35 will be partially fogged, which actually helps the depth illusion.
If it's too fogged out, reduce fog far distance slightly or move the plane
closer (Z = -28). Test visually and adjust.
