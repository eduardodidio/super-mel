# F58-T07: Editor Integration -- Palette, Tools, Visuals, Property Inputs

**Feature:** F58
**Wave:** 3
**Type:** frontend
**Depends on:** F58-T05, F58-T06
**Status:** planned

## User Story

As a level creator, I want to place springs, moving platforms, and spikes in
the level editor with configurable properties, so that I can design levels
that use these new mechanical elements.

## Objective

Add the 3 new elements to the editor: new palette tab "MECA" (Mecanicas),
new EditorTool entries, property input controls for each element, hover colors,
entity visual markers in EditorScene3D, and entity-to-tool mapping.

```typescript
const [movingPlatformDirection, setMovingPlatformDirection] = useState<"horizontal" | "vertical">("horizontal");

```

Pass these to both EditorUI (with change callbacks) and EditorScene3D (values only).
