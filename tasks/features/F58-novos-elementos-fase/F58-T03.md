# F58-T03: Moving Platform Entity (Plataforma Movel)

**Feature:** F58
**Wave:** 1
**Type:** frontend
**Depends on:** F58-T01
**Status:** planned

## User Story

As a player, I want to ride moving platforms that carry me horizontally or
vertically, so that I can cross gaps and reach areas that are otherwise
inaccessible.

## Objective

Create the `MovingPlatform.tsx` entity component: a kinematic rigid body that
oscillates between two positions (start and start+range) using smooth
sinusoidal motion. Mel can stand on top and ride the platform via physics
contact.

## Dev Notes

### New file

`packages/frontend/src/game/entities/MovingPlatform.tsx`

### Props interface

```typescript
interface MovingPlatformProps {
  position: [number, number, number];  // start position (center of oscillation)
  direction?: "horizontal" | "vertical";  // default "horizontal"
  speed?: number;     // oscillation speed, default 3
  range?: number;     // distance in blocks from center, default 4
}
```

### Physics setup

Follow the `EnemyVacuum.tsx` pattern (kinematicPosition + setNextKinematicTranslation):

```typescript
<RigidBody
  ref={rbRef}
  type="kinematicPosition"
  position={position}
  colliders={false}
  name="moving-platform"
>
  <CuboidCollider args={[1.0, 0.15, 0.4]} />  // 2 blocks wide, 0.3 blocks tall
  {/* Visual mesh group */}
</RigidBody>
```

Key: Use `kinematicPosition` (NOT `kinematicVelocity`). This is the same
approach as `EnemyVacuum.tsx` line 145. Kinematic position bodies push
dynamic bodies (Mel) via physics contact, so Mel naturally rides on top.

### Movement pattern

Smooth sinusoidal oscillation:

```typescript
useGameFrame((_, delta) => {
  if (!rbRef.current) return;
  timeRef.current += delta;

  const offset = Math.sin(timeRef.current * speed) * range;
  const pos = rbRef.current.translation();

  if (direction === "horizontal") {
    rbRef.current.setNextKinematicTranslation({
      x: position[0] + offset,
      y: position[1],
      z: position[2],
    });
  } else {
    rbRef.current.setNextKinematicTranslation({
      x: position[0],
      y: position[1] + offset,
      z: position[2],
    });
  }
});
```

Use `useGameFrame` (not `useFrame`) so the platform pauses when game is paused.
The `useGameFrame` hook is imported from `../hooks/useGameFrame` -- same as
`EnemyVacuum.tsx` line 4.

### Visual design

Wider flat platform with metallic texture and directional arrows:
- Size: 2 blocks wide (1.8 units), 0.3 blocks tall (0.25 units), 0.8 depth
- Material: metallic gray-blue (#5577AA), metalness=0.5, roughness=0.3
- Edge trim: thin dark border boxes on sides (#334466)
- Direction arrows: small triangle meshes on the surface showing movement direction
  - Horizontal: left/right arrows
  - Vertical: up/down arrows
  - Use a contrasting color (#AACCFF) with emissive glow

### Mel interaction notes

- The kinematic body's `setNextKinematicTranslation` naturally pushes Mel's
  dynamic body when in contact. This is the standard Rapier pattern.
- Mel does NOT get pushed through walls because Mel's own dynamic body will
  collide with walls and stop. The kinematic body just applies force.
- If Mel is between the platform and a wall, the platform might compress Mel.
  This is acceptable behavior for the initial implementation (same as most
  platformers). A future improvement could detect and damage Mel if crushed.

## Test Scenarios

- **Happy path (horizontal):** Place horizontal platform, Mel stands on it, Mel moves left and right with the platform
- **Happy path (vertical):** Place vertical platform, Mel stands on it, Mel moves up and down
- **Speed variation:** Platform with speed=1 moves slowly, speed=6 moves fast
- **Range variation:** Platform with range=2 has short travel, range=8 has long travel
- **Jump off:** Mel can jump off the platform at any point during its travel
- **Edge case - gap crossing:** Platform carries Mel across a gap that is too wide to jump
- **Edge case - wall contact:** If platform pushes Mel toward a wall, Mel stops at the wall (physics collision)
- **Pause:** Pausing the game freezes the platform in place, unpausing resumes
