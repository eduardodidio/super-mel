### 1. Architecture Diagram

Create: `docs/diagrams/F58-architecture.mmd`

Mermaid flowchart showing:

### 2. User Journey Diagram

Create: `docs/diagrams/F58-journey.mmd`

BPMN-style flow showing two user journeys:

**Player journey:**
1. Player loads a level
2. Level data parsed by LevelSceneConverter
3. Springs, platforms, spikes rendered
4. Player encounters spring -> bounces high
5. Player rides moving platform -> crosses gap
6. Player avoids spikes (or takes damage)

**Editor journey:**
1. Creator opens editor
2. Selects MECA tab
3. Chooses element (Spring/Platform/Spikes)
4. Configures properties (if applicable)
5. Places on grid
6. Tests level
7. Saves and publishes

### 3. README.md Update

Update `README.md` in the project root, "Features Entregues" section:

```markdown
### F58 -- Novos Elementos de Fase (Mola + Plataforma Movel + Espinhos)
- 3 novos elementos de level design: Spring (mola), Moving Platform (plataforma movel), Spikes (espinhos)
- Spring: lanca Mel para cima com forca configuravel (padrao 18, acima do pulo normal de 10)
- Moving Platform: plataforma que oscila horizontal ou verticalmente com velocidade e alcance configuraveis
- Spikes: obstaculos perigosos que causam 1 coracao de dano, podem apontar em 4 direcoes
- Todos os elementos sao posicionaveis no editor de fases (aba MECA)
- Propriedades configuraveis via dropdowns no editor
```
