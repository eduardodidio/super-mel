# F58-T01: Shared Types Extension (EntityType + ENTITY_TYPES)

**Feature:** F58
**Wave:** 0
**Type:** shared
**Depends on:** (none)
**Status:** planned

## User Story

As a developer, I want the shared type system to include "spring",
"moving_platform", and "spikes" entity types, so that all downstream
components (entities, converter, editor) can reference them with full
type safety.

## Objective

Extend the `EntityType` union and `ENTITY_TYPES` array in the shared
package to include the 3 new element types. This is a prerequisite for
all other tasks in F58.

## Dev Notes

### File to modify

`packages/shared/src/types.ts`

### Changes

1. **EntityType union** (line 30-40): Add 3 new members to the union:

export const ENTITY_TYPES: readonly EntityType[] = [

### Patterns to follow

- The `EntityType` union uses string literal types separated by `|`
- The `ENTITY_TYPES` array mirrors the union exactly and is marked `as const`
- Props for each entity type are defined in `EntityData.props` as `Record<string, unknown>` (no separate prop interfaces needed in shared -- the entity components handle their own prop parsing)

### Gotchas

- Do NOT change `EntityData` interface -- the existing `props?: Record<string, unknown>` is flexible enough to hold spring/platform/spikes props
- Do NOT modify any other types or constants in this file
- Ensure the array and union stay in sync
