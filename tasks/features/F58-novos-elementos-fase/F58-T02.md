**Feature:** F58
**Wave:** 1
**Type:** frontend
**Depends on:** F58-T01
**Status:** planned

## User Story

As a player, I want to land on a spring that bounces me high into the air,
so that I can reach elevated platforms and explore vertical level sections.

## Objective

Create the `Spring.tsx` entity component: a fixed rigid body with a sensor
collider that detects Mel landing on it from above and applies a strong
upward impulse. Includes a squash/stretch animation on bounce.

## Dev Notes

### Props interface

interface SpringProps {

### Physics setup

Follow the `Checkpoint.tsx` pattern (RigidBody fixed + sensor):

```typescript
<RigidBody
  type="fixed"
  position={position}
  colliders={false}
  name="spring"
>
  <CuboidCollider
    args={[0.45, 0.15, 0.3]}   // 1 block wide, 0.3 blocks tall sensor zone on top
    position={[0, 0.4, 0]}      // sensor sits above the spring visual
    sensor
    onIntersectionEnter={(payload) => {
      if (payload.other.rigidBodyObject?.name === "mel") {
        // Only bounce if Mel is coming from above (moving downward)
        const melRb = payload.other.rigidBody;
        if (melRb) {
          const melVel = melRb.linvel();
          if (melVel.y < -0.5) {
            onBounce(bounceForce);
            // trigger squash animation
          }
        }
      }
    }}
  />
  {/* Visual mesh group here */}
</RigidBody>
```

### Visual design

Compressed spring shape -- metallic red cylinder with decreasing radius:
- Size: 1 block wide (0.9 units), 0.5 blocks tall
- Base plate: flat box (0.9 x 0.1 x 0.6), dark gray metallic
- Spring coils: 3-4 stacked cylinders/tori with decreasing radius, metallic red (#CC2222)
- Top plate: flat box (0.7 x 0.08 x 0.5), lighter gray

Use simple box/cylinder geometries (voxel style consistent with the game).

### Squash/stretch animation

- Use `useRef` for animation state (not useState -- avoid re-renders)
- On bounce trigger: set squash phase (scaleY = 0.5, scaleXZ = 1.3) over ~0.05s
- Then stretch phase (scaleY = 1.4, scaleXZ = 0.8) over ~0.1s
- Then ease back to default (scaleY = 1.0) over ~0.2s
- Use `useFrame` with lerp (same pattern as Checkpoint scale pulse, lines 53-66)

### Mel integration (MelHandle extension)

The `onBounce` callback will be wired in GameScene3D (T06) to call
`melRef.current?.springBounce(force)`.

This requires adding `springBounce(force: number)` to `MelHandle` in `Mel.tsx`:

```typescript
export interface MelHandle {
  stompBounce: () => void;
  springBounce: (force: number) => void;  // NEW
}

// In the useImperativeHandle:
springBounce(force: number) {
  if (!rigidBodyRef.current) return;
  const vel = rigidBodyRef.current.linvel();
  rigidBodyRef.current.setLinvel(
    { x: vel.x, y: force, z: 0 },
    true,
  );
}
```

This follows the same pattern as `stompBounce()` (line 95-101 of Mel.tsx)
but with a configurable Y velocity instead of the fixed STOMP_BOUNCE_FORCE.

## Test Scenarios

- **Happy path:** Mel jumps onto a spring, bounces much higher than a normal jump
- **Side contact:** Mel walks into the spring from the side -- no bounce occurs
- **Custom force:** Spring with bounceForce=25 launches Mel even higher
- **Animation:** Visual squash is visible on contact, followed by stretch and recovery
- **Repeated bounces:** Landing on the spring multiple times works consistently
- **Edge case:** Mel standing still on a block next to the spring, then walking onto it -- should not bounce (no downward velocity)
