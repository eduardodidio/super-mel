# Task F45-T03 -- Level Missions Hook + LevelClearOverlay Integration

**Feature:** F45
**Wave:** 1
**Type:** frontend (React hook + UI)
**Depends on:** F45-T01 (GameEventBus), F45-T02 (MissionTracker)
**Status:** done

## User Story

As a player completing a level, I want to see which missions I accomplished (e.g., "collect 30 coins", "no damage") on the result screen, so that I have reasons to replay levels and aim for 100% completion.

## Objective

1. Create `useLevelMissions` hook that reads `LevelDataV2.missions[]`, creates a MissionTracker, subscribes to GameEventBus, and exposes mission completion state.
2. Update LevelClearOverlay to display missions with checkmarks.
3. Update star calculation: 3 stars = all missions complete (when level defines missions).
4. Persist completed missions in progress backend via `data.levelMissions`.

## Dev Notes

### 1. useLevelMissions.ts (`packages/frontend/src/game/hooks/useLevelMissions.ts`)

```typescript
import { useEffect, useRef, useState } from "react";
import { gameEventBus } from "../systems/GameEventBus";
import { MissionTracker, type MissionStatus } from "../systems/MissionTracker";
import type { Mission } from "@super-mel/shared";

interface UseLevelMissionsResult {
  missions: MissionStatus[];
  allComplete: boolean;
}

export function useLevelMissions(
  levelMissions: Mission[] | undefined,
  active: boolean  // true when scene === "playing" and gameMode === "level"
): UseLevelMissionsResult {
  const trackerRef = useRef<MissionTracker | null>(null);
  const [status, setStatus] = useState<MissionStatus[]>([]);

  // Create tracker when level starts
  useEffect(() => {
    if (!active || !levelMissions?.length) {
      trackerRef.current = null;
      setStatus([]);
      return;
    }

    const tracker = new MissionTracker(levelMissions);
    trackerRef.current = tracker;

    // Subscribe to GameEventBus
    const unsubs = [
      gameEventBus.on("coin_collected", () => tracker.onCoinCollected()),
      gameEventBus.on("block_destroyed", (d) => tracker.onBlockDestroyed(d.blockType)),
      gameEventBus.on("damage_taken", () => tracker.onDamageTaken()),
      gameEventBus.on("heart_collected", () => tracker.onHeartCollected()),
      gameEventBus.on("bone_collected", () => tracker.onBoneCollected()),
      gameEventBus.on("distance_reached", (d) => tracker.onDistanceReached(d.distance)),
      gameEventBus.on("fly_tick", (d) => tracker.onFlyTick(d.deltaSeconds)),
      gameEventBus.on("stomp_enemy", () => tracker.onEnemyStomped()),
      // level_complete: snapshot final status
      gameEventBus.on("level_complete", (d) => {
        tracker.onTimeTick(0); // ensure elapsed is up to date
        setStatus(tracker.getStatus());
      }),
    ];

    // Time tick: use a RAF loop to feed elapsed time
    let lastTime = performance.now();
    let rafId: number;
    const tickTime = () => {
      const now = performance.now();
      const delta = (now - lastTime) / 1000;
      lastTime = now;
      tracker.onTimeTick(delta);
      rafId = requestAnimationFrame(tickTime);
    };
    rafId = requestAnimationFrame(tickTime);

    return () => {
      unsubs.forEach(fn => fn());
      cancelAnimationFrame(rafId);
      // Snapshot final status on cleanup
      if (trackerRef.current) {
        setStatus(trackerRef.current.getStatus());
      }
    };
  }, [active, levelMissions]);

  const allComplete = status.length > 0 && status.every(s => s.completed);

  return { missions: status, allComplete };
}
```

### 3. Persistence (progress backend)

On level complete, save completed mission IDs to progress:

In `LevelClearOverlay.tsx` (in the existing `useEffect` that POSTs score):

```typescript
// Also sync mission completions to progress
const completedIds = missionStatus
  ?.filter(ms => ms.completed)
  .map(ms => ms.mission.id) ?? [];

if (completedIds.length > 0 && !isGuest()) {
  const token = localStorage.getItem("supermel_token");
  if (token) {
    fetch("/api/progress", {
      method: "PUT",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${token}`,
      },
      body: JSON.stringify({
        data: {
          levelMissions: { [levelId]: completedIds },
        },
      }),
    }).catch(() => {});
  }
}
```

The backend's `mergeProgressData` will union the arrays under `data.levelMissions[levelId]`.

### 4. Wiring in Game3D.tsx

The `useLevelMissions` hook will be called in Game3D.tsx (or a wrapper component) and the result passed to `LevelClearOverlay`:

```tsx
const levelMissions = useLevelMissions(
  currentLevelData?.missions,
  scene === "playing" && useGameState.getState().gameMode === "level"
);

// ...

{scene === "levelclear" && (
  <LevelClearOverlay missionStatus={levelMissions.missions} />
)}
```

Note: The hook captures status while the scene is "playing" and holds it when transitioning to "levelclear". The `level_complete` event triggers the final snapshot.

- Level with `missions: undefined` -- same as above
- Mission with `find_bone` condition -- will always be incomplete (no Bone entity yet)
