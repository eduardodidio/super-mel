# Task F45-T02 -- MissionCondition Types + MissionTracker Engine

**Feature:** F45
**Wave:** 0
**Type:** shared + frontend (pure logic)
**Depends on:** (none)
**Status:** planned

## User Story

As a developer, I need a reusable mission evaluation engine that can determine whether a set of gameplay events satisfies a mission condition, so that both level missions and infinite missions use the same logic.

## Objective

1. Add `MissionConditionType` and `MissionCondition` types to `shared/types.ts`.
2. Tighten the existing `Mission.condition` field from `Record<string, unknown>` to `MissionCondition`.
3. Create `MissionTracker.ts` -- a pure-logic class that accumulates gameplay event counters and evaluates mission conditions against them.

## Dev Notes

### 1. shared/types.ts changes

**Add new types (after the existing `Mission` interface):**

```typescript
export type MissionConditionType =
  | "collect_coins"       // params: { count: number }
  | "no_damage"           // params: {} -- complete run/level without taking damage
  | "find_bone"           // params: {} -- collect at least one bone entity
  | "time_limit"          // params: { seconds: number } -- finish under N seconds
  | "break_blocks"        // params: { blockType?: BlockType; count: number }
  | "fly_duration"        // params: { seconds: number } -- cumulative fly time in run
  | "reach_distance"      // params: { meters: number }
  | "no_damage_distance"  // params: { meters: number } -- reach distance without any damage
  | "stomp_enemies";      // params: { count: number }

export interface MissionCondition {
  type: MissionConditionType;
  params: Record<string, unknown>;
}
```

**Update the existing Mission interface:**

```typescript
export interface Mission {
  id: string;
  description: string;
  condition: MissionCondition;  // was Record<string, unknown>
}
```

This is backward-compatible because `LevelDataV2.missions` is optional and no existing levels populate it.

### 2. MissionTracker.ts (`packages/frontend/src/game/systems/MissionTracker.ts`)

A pure-logic class with NO React or Zustand dependencies.

**Event counters (internal state):**

```typescript
interface EventCounters {
  coinsCollected: number;
  blocksDestroyed: number;           // total
  blocksDestroyedByType: Record<string, number>; // per blockType
  damageTaken: number;
  heartsCollected: number;
  bonesCollected: number;
  distanceReached: number;
  flyTimeSeconds: number;
  enemiesStomped: number;
  elapsedSeconds: number;
}
```

**Public API:**

```typescript
class MissionTracker {
  private counters: EventCounters;
  private missions: Mission[];

  constructor(missions: Mission[]) { ... }

  // Called by hooks to feed events into the tracker
  onCoinCollected(): void;
  onBlockDestroyed(blockType: string): void;
  onDamageTaken(): void;
  onHeartCollected(): void;
  onBoneCollected(): void;
  onDistanceReached(distance: number): void;
  onFlyTick(deltaSeconds: number): void;
  onEnemyStomped(): void;
  onTimeTick(deltaSeconds: number): void;

  // Evaluate all missions and return completion status
  getStatus(): MissionStatus[];

  // Reset counters (for new run)
  reset(): void;

  // Get raw counters (for debug/display)
  getCounters(): Readonly<EventCounters>;
}

interface MissionStatus {
  mission: Mission;
  completed: boolean;
  progress: number;   // 0.0 to 1.0 (for progress bars)
  progressText: string; // e.g., "15/30 moedas" or "42s/60s"
}
```

**Condition evaluation logic:**

```typescript
private evaluate(mission: Mission): { completed: boolean; progress: number; progressText: string } {
  const { type, params } = mission.condition;
  const c = this.counters;

  switch (type) {
    case "collect_coins": {
      const target = (params.count as number) || 1;
      return {
        completed: c.coinsCollected >= target,
        progress: Math.min(1, c.coinsCollected / target),
        progressText: `${c.coinsCollected}/${target}`,
      };
    }
    case "no_damage":
      return {
        completed: c.damageTaken === 0,
        progress: c.damageTaken === 0 ? 1 : 0,
        progressText: c.damageTaken === 0 ? "Sem dano!" : `${c.damageTaken} dano(s)`,
      };
    case "find_bone":
      return {
        completed: c.bonesCollected > 0,
        progress: c.bonesCollected > 0 ? 1 : 0,
        progressText: c.bonesCollected > 0 ? "Encontrado!" : "0/1",
      };
    case "time_limit": {
      const target = (params.seconds as number) || 60;
      // Note: for time_limit, completion is checked at level_complete -- here we report progress
      return {
        completed: c.elapsedSeconds <= target,
        progress: Math.min(1, Math.max(0, 1 - c.elapsedSeconds / target)),
        progressText: `${Math.floor(c.elapsedSeconds)}s/${target}s`,
      };
    }
    case "break_blocks": {
      const target = (params.count as number) || 1;
      const blockType = params.blockType as string | undefined;
      const actual = blockType
        ? (c.blocksDestroyedByType[blockType] || 0)
        : c.blocksDestroyed;
      return {
        completed: actual >= target,
        progress: Math.min(1, actual / target),
        progressText: `${actual}/${target}`,
      };
    }
    case "fly_duration": {
      const target = (params.seconds as number) || 5;
      return {
        completed: c.flyTimeSeconds >= target,
        progress: Math.min(1, c.flyTimeSeconds / target),
        progressText: `${c.flyTimeSeconds.toFixed(1)}s/${target}s`,
      };
    }
    case "reach_distance": {
      const target = (params.meters as number) || 100;
      return {
        completed: c.distanceReached >= target,
        progress: Math.min(1, c.distanceReached / target),
        progressText: `${Math.floor(c.distanceReached)}/${target}m`,
      };
    }
    case "no_damage_distance": {
      const target = (params.meters as number) || 100;
      const valid = c.damageTaken === 0;
      return {
        completed: valid && c.distanceReached >= target,
        progress: valid ? Math.min(1, c.distanceReached / target) : 0,
        progressText: valid ? `${Math.floor(c.distanceReached)}/${target}m` : "Dano tomado!",
      };
    }
    case "stomp_enemies": {
      const target = (params.count as number) || 1;
      return {
        completed: c.enemiesStomped >= target,
        progress: Math.min(1, c.enemiesStomped / target),
        progressText: `${c.enemiesStomped}/${target}`,
      };
    }
    default:
      return { completed: false, progress: 0, progressText: "???" };
  }
}
```

### 3. Important notes

- `time_limit` missions: `elapsedSeconds` is tracked by the tracker via `onTimeTick()`. The hook that drives the tracker is responsible for calling `onTimeTick(delta)` each frame. For level missions, the `time_limit` condition is evaluated when the level is completed -- if the player takes longer than the target, the mission is marked incomplete.

- `no_damage` is a "negative condition" -- it starts as complete and becomes incomplete on the first damage event. The tracker handles this by checking `damageTaken === 0`.

- The MissionTracker does NOT subscribe to GameEventBus itself. The hooks (useLevelMissions, useInfiniteMissions) subscribe to the bus and call the tracker's methods. This keeps MissionTracker pure and testable.

- Empty missions array returns empty status array
- Unknown condition type returns `completed: false`
- Zero target values default to 1 (avoid division by zero)
- Multiple calls to same event correctly accumulate
