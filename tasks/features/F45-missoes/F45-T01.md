## User Story

As a mission system, I need a centralized stream of typed gameplay events (coins, blocks, damage, distance, etc.) so that I can track mission progress without coupling directly to every game callback.

## Objective

1. Create `GameEventBus.ts` -- a lightweight typed event emitter (mitt-style, zero dependencies) that emits structured gameplay events.
2. Wire GameScene3D.tsx to emit events on all relevant gameplay actions.
3. Emit a `run_start` event when a run begins and `run_end` when it ends, so subscribers know the session boundary.

## Dev Notes

### 1. GameEventBus.ts (`packages/frontend/src/game/systems/GameEventBus.ts`)

Create a new file with a module-level singleton event bus.

**Event types:**

```typescript
export interface GameEvents {
  run_start: { mode: "level" | "infinite"; levelId?: string };
  run_end: { mode: "level" | "infinite" };
  coin_collected: { x: number; y: number; source: "placed" | "dropped" | "item_block" };
  block_destroyed: { x: number; y: number; blockType: string };
  damage_taken: {};
  heart_collected: { x: number; y: number };
  bone_collected: { x: number; y: number };
  distance_reached: { distance: number };
  fly_tick: { deltaSeconds: number; continuous: boolean };
  stomp_enemy: { enemyType?: string };
  level_complete: { levelId: string; timeSeconds: number; coins: number; deaths: number };
  item_block_activated: { x: number; y: number; coinCount: number };
}
```

**Implementation pattern (no external deps):**

```typescript
type Listener<T> = (data: T) => void;

class EventBus<Events extends Record<string, unknown>> {
  private listeners = new Map<string, Set<Listener<any>>>();

  on<K extends keyof Events>(event: K, listener: Listener<Events[K]>): () => void {
    const key = event as string;
    if (!this.listeners.has(key)) this.listeners.set(key, new Set());
    this.listeners.get(key)!.add(listener);
    return () => this.listeners.get(key)?.delete(listener);
  }

  emit<K extends keyof Events>(event: K, data: Events[K]): void {
    const key = event as string;
    this.listeners.get(key)?.forEach(fn => fn(data));
  }

  reset(): void {
    this.listeners.clear();
  }
}

export const gameEventBus = new EventBus<GameEvents>();
```

### 2. GameScene3D.tsx changes

**Import:**
```typescript
import { gameEventBus } from "../systems/GameEventBus";
```

**Emit on existing callbacks:**

- `handleCoinCollected`: emit `coin_collected` with source `"placed"`
- `handleDroppedCoinCollect`: emit `coin_collected` with source `"dropped"`
- `handleBlockHit` (item_block branch): emit `item_block_activated` and `coin_collected` (source `"item_block"`) for each coin spawned
- `handleBlockHit` (destructible branch): emit `block_destroyed` with blockType
- `handleDamage`: emit `damage_taken`
- `handleHeartCollected`: emit `heart_collected`
- `handleGoalReached`: emit `level_complete` with stats from useGameState
- `handlePositionUpdate`: emit `distance_reached` when `maxX` increases past whole-number thresholds (throttle to avoid spam -- emit every 10m or every 1m depending on performance)

**Run lifecycle:**

Add a `useEffect` that emits `run_start` on mount and `run_end` on unmount:

```typescript
useEffect(() => {
  gameEventBus.emit("run_start", {
    mode: gameMode,
    levelId: gameMode === "level" ? useGameState.getState().levelId ?? undefined : undefined,
  });
  return () => {
    gameEventBus.emit("run_end", { mode: gameMode });
  };
}, [gameMode]);
```

**Fly tracking:**

In the existing `handleFlyStateUpdate` callback (or via a useFrame hook), emit `fly_tick` every frame that Mel is flying:

```typescript
// Inside the component, track flying state to emit fly_tick
const wasFlyingRef = useRef(false);
// In handleFlyStateUpdate or useFrame:
if (isFlying) {
  gameEventBus.emit("fly_tick", { deltaSeconds: delta, continuous: !wasFlyingRef.current ? false : true });
}
wasFlyingRef.current = isFlying;
```

Note: `fly_tick` emits the delta each frame so MissionTracker can accumulate total fly time.

**Distance throttling:**

To avoid excessive event emissions, only emit `distance_reached` when `maxX` crosses a new whole meter:

```typescript
const lastEmittedDistance = useRef(0);
// In handlePositionUpdate, after maxX update:
const currentMeters = Math.floor(maxX.current);
if (currentMeters > lastEmittedDistance.current) {
  gameEventBus.emit("distance_reached", { distance: currentMeters });
  lastEmittedDistance.current = currentMeters;
}
```

### Edge Cases
- `run_start` should fire exactly once per mount
- `run_end` should fire on unmount (scene change or remount)
- Distance events should not fire when walking backward
- No `bone_collected` or `stomp_enemy` events fire (no entities exist yet)
