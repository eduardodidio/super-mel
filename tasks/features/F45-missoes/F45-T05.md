## User Story

As a player, I want to see a celebratory notification pop up mid-gameplay when I complete a mission (e.g., "COMPLETA! Colete 20 moedas"), so that I feel immediate reward without leaving the game screen.

## Objective

1. Create `MissionToast.tsx` -- a toast notification overlay that shows "COMPLETA!" with the mission description when a mission is fulfilled during gameplay.
2. Wire all mission hooks (useLevelMissions, useInfiniteMissions) in Game3D.tsx.
3. Ensure the toast system handles both level and infinite mission completions.
4. Pass mission data from hooks to LevelClearOverlay and HUD3D.

## Dev Notes

### 1. MissionToast.tsx (`packages/frontend/src/game/systems/MissionToast.tsx`)

A React component that subscribes to `mission_completed` events on the GameEventBus and displays toast notifications.

**Design:**

```tsx
import { useState, useEffect, useCallback } from "react";
import { gameEventBus } from "./GameEventBus";
import type { Mission } from "@super-mel/shared";

interface ToastItem {
  id: number;
  description: string;
  reward: number;
  visible: boolean;
}

const TOAST_DURATION = 2500; // 2.5s display
const FADE_DURATION = 500;   // 0.5s fade out

export function MissionToast() {
  const [toasts, setToasts] = useState<ToastItem[]>([]);
  const idCounter = useRef(0);

  useEffect(() => {
    const unsub = gameEventBus.on("mission_completed", (data) => {
      const id = ++idCounter.current;
      const newToast: ToastItem = {
        id,
        description: data.mission.description,
        reward: data.reward,
        visible: true,
      };

      setToasts(prev => [...prev, newToast]);

      // Start fade after TOAST_DURATION
      setTimeout(() => {
        setToasts(prev =>
          prev.map(t => t.id === id ? { ...t, visible: false } : t)
        );
      }, TOAST_DURATION);

      // Remove after fade completes
      setTimeout(() => {
        setToasts(prev => prev.filter(t => t.id !== id));
      }, TOAST_DURATION + FADE_DURATION);
    });

    return unsub;
  }, []);

  if (toasts.length === 0) return null;

  return (
    <div style={styles.container}>
      {toasts.map((toast) => (
        <div
          key={toast.id}
          style={{
            ...styles.toast,
            opacity: toast.visible ? 1 : 0,
            transform: toast.visible
              ? "translateY(0) scale(1)"
              : "translateY(-10px) scale(0.95)",
          }}
        >
          <div style={styles.toastHeader}>MISSAO COMPLETA!</div>
          <div style={styles.toastDesc}>{toast.description}</div>
          {toast.reward > 0 && (
            <div style={styles.toastReward}>+{toast.reward} moedas</div>
          )}
        </div>
      ))}
    </div>
  );
}
```

### 3. Level missions toast integration

The `useLevelMissions` hook also needs to emit `mission_completed` events when a level mission is completed mid-gameplay. This is needed so the toast shows during level play, not just on the result screen.

In `useLevelMissions.ts`, add a check after each event subscription callback:

```typescript
// After each event handler, check if any mission newly completed
const checkCompletion = () => {
  const newStatus = tracker.getStatus();
  const prevStatus = lastStatusRef.current;
  for (let i = 0; i < newStatus.length; i++) {
    if (newStatus[i].completed && !prevStatus[i]?.completed) {
      gameEventBus.emit("mission_completed", {
        mission: newStatus[i].mission,
        reward: 0, // level missions reward on result screen, not mid-game
      });
    }
  }
  lastStatusRef.current = newStatus;
  setStatus(newStatus);
};
```

Call `checkCompletion()` after each event handler fires.
