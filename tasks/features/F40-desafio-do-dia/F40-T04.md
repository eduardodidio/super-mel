# F40-T04 — Frontend: daily mode state, menu button, baseSeed wiring

**Wave:** 1
**Type:** frontend
**Depends on:** F40-T02 (ChunkGenerator baseSeed param)
**Status:** planned

## User Story

As a player, I want to click "DESAFIO DO DIA" in the menu to start today's daily challenge with a unique map that's the same for everyone, so that I can compete fairly on the daily leaderboard.

## Objective

Adicionar daily mode ao useGameState, botao DESAFIO DO DIA no menu (Game3D.tsx), passar baseSeed por GameScene3D e ChunkRenderer, e atualizar GameOverScene3D para enviar mode/seed e mostrar resultado diario.

### 2. Game3D.tsx — menu button + eligibility check

- Arquivo: `packages/frontend/src/game/Game3D.tsx`
- Importar `getTodaySeed` de `../game/systems/ChunkGenerator`
- Adicionar state:
  ```ts
  const [canPlayDaily, setCanPlayDaily] = useState<boolean | null>(null);
  const [checkingDaily, setCheckingDaily] = useState(false);
  const startDailyMode = useGameState((s) => s.startDailyMode);
  ```
- useEffect no menu scene para checar elegibilidade:
  ```ts
  useEffect(() => {
    if (scene === "menu") {
      const playerId = localStorage.getItem("supermel_player_id");
      if (playerId) {
        setCheckingDaily(true);
        fetch(`/api/daily/can-play?playerId=${playerId}`)
          .then(r => r.json())
          .then(data => setCanPlayDaily(data.canPlay))
          .catch(() => setCanPlayDaily(true)) // offline = allow
          .finally(() => setCheckingDaily(false));
      } else {
        setCanPlayDaily(true);
      }
    }
  }, [scene]);
  ```
- Adicionar botao DESAFIO DO DIA no `buttonGroup`, entre JOGAR e FASE TESTE:
  ```tsx
  <button
    style={{
      ...styles.btnDaily,
      opacity: canPlayDaily === false ? 0.4 : 1,
    }}
    disabled={canPlayDaily === false || checkingDaily}
    onClick={() => {
      const seed = getTodaySeed();
      startDailyMode(seed);
    }}
  >
    {canPlayDaily === false ? "JA JOGOU HOJE" : checkingDaily ? "VERIFICANDO..." : "DESAFIO DO DIA"}
  </button>
  ```
- Adicionar estilo `btnDaily`:


## Test Scenarios

- **Happy path:** jogador clica DESAFIO DO DIA, joga, morre, ve ranking, volta ao menu, botao mostra "JA JOGOU HOJE"
- **Backward compat:** JOGAR funciona identico ao antes (baseSeed=0, mode=infinite)
- **Edge case:** backend offline — botao DESAFIO DO DIA habilitado (fallback), score salvo localmente
- **Edge case:** guest player (sem playerId) — pode jogar daily mas sem enforcement de 1x/dia
