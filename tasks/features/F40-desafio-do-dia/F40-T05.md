# F40-T05 — Daily Leaderboard UI

**Wave:** 2
**Type:** frontend
**Depends on:** F40-T03 (backend daily leaderboard API), F40-T04 (daily mode state)
**Status:** planned

## User Story

As a player, I want to see a daily leaderboard showing today's (and past days') rankings, so that I can compare my daily challenge performance with other players.

## Objective

Adicionar aba/filtro de "Diario" ao LeaderboardView existente, permitindo ver o ranking do desafio do dia de hoje ou de datas passadas.

## Dev Notes

### LeaderboardView.tsx — add daily tab

- Arquivo: `packages/frontend/src/components/LeaderboardView.tsx`
- Adicionar state para tab e data:
  ```ts
  const [tab, setTab] = useState<"infinite" | "daily">("infinite");
  const [dailyEntries, setDailyEntries] = useState<LeaderboardEntry[]>([]);
  const [dailyDate, setDailyDate] = useState<string>(() => {
    const d = new Date();
    return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
  });
  const [loadingDaily, setLoadingDaily] = useState(false);
  ```
- Funcao para fetch daily leaderboard:
  ```ts
  async function fetchDailyLeaderboard(date: string) {
    setLoadingDaily(true);
    try {
      const res = await fetch(`/api/daily/leaderboard?date=${date}`);
      if (res.ok) setDailyEntries(await res.json());
    } catch {} finally {
      setLoadingDaily(false);
    }
  }
  ```
- useEffect para buscar daily quando tab muda ou data muda:
  ```ts
  useEffect(() => {
    if (tab === "daily") fetchDailyLeaderboard(dailyDate);
  }, [tab, dailyDate]);
  ```
- Adicionar tab buttons acima da tabela:
  ```tsx
  <div style={styles.tabBar}>
    <button
      style={tab === "infinite" ? styles.tabActive : styles.tab}
      onClick={() => setTab("infinite")}
    >
      GERAL
    </button>
    <button
      style={tab === "daily" ? styles.tabActive : styles.tab}
      onClick={() => setTab("daily")}
    >
      DIARIO
    </button>
  </div>
  ```
- Quando tab="daily", mostrar seletor de data (input type="date" ou botoes prev/next):
  ```tsx
  {tab === "daily" && (
    <div style={styles.dateSelector}>
      <button onClick={() => {/* prev day */}}>◀</button>
      <span>{dailyDate}</span>
      <button onClick={() => {/* next day, max today */}}>▶</button>
    </div>
  )}
  ```
- Renderizar entries da tab ativa:
  - tab="infinite": entries existentes (fetchLeaderboard)
  - tab="daily": dailyEntries (fetchDailyLeaderboard)
- Destacar jogador atual na lista (ja existente, manter)

## Acceptance Criteria

- [ ] Tabs GERAL e DIARIO aparecem no LeaderboardView
- [ ] Aba GERAL mostra leaderboard infinito existente (sem regressao)
- [ ] Aba DIARIO mostra leaderboard filtrado por dia via API
- [ ] Seletor de data permite navegar entre dias (max: hoje)
- [ ] Jogador atual destacado na lista diaria
- [ ] Loading state enquanto busca dados
- [ ] Funciona offline (array vazio, sem crash)

## Test Scenarios

- **Happy path:** jogador abre RANKING, clica DIARIO, ve seu score e posicao
- **Edge case:** dia sem nenhum jogador — mostra mensagem "Nenhum score"
- **Edge case:** backend offline — mostra lista vazia
- **Boundary:** primeiro dia de implementacao — sem dados historicos, so dia atual
- **UX:** navegar para dia futuro nao e permitido (botao desabilitado)
