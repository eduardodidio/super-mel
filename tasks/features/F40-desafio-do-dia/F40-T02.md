# F40-T02 — ChunkGenerator: baseSeed parameter + daily seed function

**Wave:** 0
**Type:** frontend
**Depends on:** (none)

## User Story

As a player, I want the daily challenge to generate the same map for everyone on the same day, so that the leaderboard is fair and comparable.

## Objective

Adicionar parametro `baseSeed` a `generateChunk` (default 0 para backward compat) e criar funcao `dailySeed(dateStr)` que gera um hash numerico deterministico de uma string YYYYMMDD.

## Dev Notes

- Arquivo: `packages/frontend/src/game/systems/ChunkGenerator.ts`
- Funcao atual (linha 38):
  ```ts
  export function generateChunk(chunkIndex: number): Chunk {
    const rand = seededRandom(chunkIndex * 7919 + 31);
  ```
- Mudar assinatura para:
  ```ts
  export function generateChunk(chunkIndex: number, baseSeed: number = 0): Chunk {
    const rand = seededRandom(chunkIndex * 7919 + 31 + baseSeed);
  ```
- Com `baseSeed=0` o comportamento e identico ao atual (nenhuma regressao)
- Adicionar nova funcao exportada para gerar seed diaria:
  ```ts
  export function dailySeed(dateStr: string): number {
    // dateStr format: "YYYYMMDD" e.g. "20260930"
    // Simple numeric hash: sum of (charCode * position * prime)
    let hash = 0;
    for (let i = 0; i < dateStr.length; i++) {
      hash = (hash * 31 + dateStr.charCodeAt(i)) & 0x7fffffff;
    }
    return hash;
  }
  ```
- Funcao `getTodaySeed()` helper:
  ```ts
  export function getTodaySeed(): number {
    const d = new Date();
    const dateStr = `${d.getFullYear()}${String(d.getMonth() + 1).padStart(2, '0')}${String(d.getDate()).padStart(2, '0')}`;
    return dailySeed(dateStr);
  }
  ```
- IMPORTANTE: nao alterar nenhuma outra logica do ChunkGenerator. Apenas adicionar o parametro e as funcoes.

## Test Scenarios

- **Happy path:** dois jogadores chamando `generateChunk(5, dailySeed("20260930"))` geram exatamente o mesmo chunk
- **Backward compat:** `generateChunk(5)` sem baseSeed gera chunk identico ao que gerava antes desta mudanca
- **Edge case:** `dailySeed("")` nao dah erro (retorna 0 ou hash valido)
- **Boundary:** `baseSeed` de valor muito grande (MAX_SAFE_INTEGER) nao causa overflow — bitwise AND garante 32-bit
