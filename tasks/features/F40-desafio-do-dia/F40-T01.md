# F40-T01 — Prisma Migration: campos mode e seed no Score

**Wave:** 0
**Type:** backend / infra
**Depends on:** (none)
**Status:** planned

## User Story

As a developer, I want the Score model to support game mode and seed fields, so that daily challenge scores can be distinguished from infinite mode scores and linked to a specific daily seed.

## Objective

Adicionar campos `mode` (String, default "infinite") e `seed` (Int?, optional) ao model Score no Prisma schema, e gerar + aplicar a migration.

## Dev Notes

- Arquivo do schema: `packages/backend/prisma/schema.prisma`
- Model Score atual (linhas 23-34):
  ```prisma
  model Score {
    id        String   @id @default(uuid()) @db.Uuid
    playerId  String   @map("player_id") @db.Uuid
    distance  Int
    levelId   String?  @map("level_id") @db.Uuid
    createdAt DateTime @default(now()) @map("created_at")
    player Player @relation(fields: [playerId], references: [id])
    level  Level? @relation(fields: [levelId], references: [id])
    @@map("scores")
  }
  ```
- Adicionar entre `distance` e `levelId`:
  ```prisma
  mode      String   @default("infinite") @db.VarChar(20)
  seed      Int?
  ```
- Usar String com default ao inves de Postgres enum para simplicidade e flexibilidade
- Todos os scores existentes receberao mode="infinite" e seed=null automaticamente pelo default
- Migration name sugerida: `add_score_mode_and_seed`
- Comando: `cd packages/backend && npx prisma migrate dev --name add_score_mode_and_seed`
- Apos migration, rodar `npx prisma generate` para atualizar o client
