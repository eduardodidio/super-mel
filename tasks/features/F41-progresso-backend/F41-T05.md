# F41-T05 -- Wire State Mutations to Progress Sync

**Wave:** 2
**Type:** frontend
**Depends on:** F41-T04
**Status:** planned

## User Story

As a registered player, I want all my progress-affecting actions (collecting coins, clearing levels, earning achievements) to trigger a backend save, so that nothing I earn is lost.

## Objective

Garantir que todas as mutations que afetam progresso (addCoin, e futuras como clearLevel, addAchievement) disparem a sincronizacao via useProgressSync. Tambem atualizar o campo `data` JSON no futuro, mas por ora o foco e totalCoins.

## Dev Notes

### Situacao atual

- `addCoin()` em `useGameState.ts` incrementa `coins` e `totalCoins`, salva em localStorage
- `useProgressSync` ja observa mudancas em `totalCoins` via `useGameState.subscribe`
- Portanto, `addCoin()` ja dispara o sync automaticamente -- nenhuma mudanca necessaria em addCoin

### O que esta task faz

1. **Verificar wiring end-to-end**: confirmar que o fluxo addCoin -> subscribe -> debounce -> PUT funciona
2. **Adicionar sync no resetGame**: garantir que resetGame nao dispara um PUT desnecessario (coins zera, mas totalCoins nao muda)
3. **Adicionar flush no handleLogout**: antes de limpar localStorage, fazer um sync final
4. **Documentar extensao para futuras mutations**: quando addAchievement, clearLevel etc forem criados, como extender o sync

### Arquivos a modificar

- `packages/frontend/src/game/Game3D.tsx` (flush no logout)
- `packages/frontend/src/game/hooks/useProgressSync.ts` (export flushProgress helper)

## Implementation Details

### Export flushProgress from useProgressSync

Adicionar funcao exportada para flush manual:

```typescript
export function flushProgress(): void {
  if (isGuest()) return;
  const token = getAuthToken();
  if (!token) return;
  const state = useGameState.getState();
  putProgress(token, { totalCoins: state.totalCoins });
}
```

### Game3D.tsx -- flush on logout

No `handleLogout`:

```typescript
import { flushProgress } from "./hooks/useProgressSync";

const handleLogout = () => {
  flushProgress(); // Sync before clearing
  localStorage.removeItem("supermel_token");
  localStorage.removeItem("supermel_player_id");
  localStorage.removeItem("supermel_player_name");
  window.location.reload();
};
```

### Validacao de nao-regressao

- `resetGame()` zera `coins` mas NAO muda `totalCoins` -> nao dispara PUT desnecessario

- `addCoin()` incrementa `totalCoins` -> dispara subscribe -> debounce -> PUT (correto)
