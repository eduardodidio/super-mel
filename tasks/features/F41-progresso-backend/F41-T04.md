# F41-T04 -- Frontend Sync: useProgressSync Hook

**Wave:** 1
**Type:** frontend
**Depends on:** F41-T01
**Status:** planned

## User Story

As a registered player, I want my progress to be automatically loaded from the server when I log in and saved periodically while I play, so that my progress is safe even if I switch devices or clear my browser.

## Objective

Criar hook `useProgressSync` que: (1) ao montar, le progresso do backend para usuarios registrados; (2) observa mudancas no Zustand e grava no backend com debounce 2s; (3) flush imediato em scene changes criticos (gameover, menu).

## Implementation Details

### useProgressSync.ts

```typescript
import { useEffect, useRef } from "react";
import { useGameState } from "./useGameState";

const DEBOUNCE_MS = 2000;
const PROGRESS_SCENES = ["gameover", "menu"]; // flush on these

function getAuthToken(): string | null {
  return localStorage.getItem("supermel_token");
}

function isGuest(): boolean {
  const token = getAuthToken();
  const playerId = localStorage.getItem("supermel_player_id") || "";
  return !token || playerId.startsWith("local-");
}

async function fetchProgress(token: string): Promise<{ totalCoins: number; data: Record<string, unknown> } | null> {
  try {
    const res = await fetch("/api/progress", {
      headers: { Authorization: `Bearer ${token}` },
    });
    if (!res.ok) return null;
    return res.json();
  } catch {
    return null;
  }
}

async function putProgress(token: string, payload: { totalCoins: number; data?: Record<string, unknown> }): Promise<void> {
  try {
    await fetch("/api/progress", {
      method: "PUT",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${token}`,
      },
      body: JSON.stringify(payload),
    });
  } catch {
    // Silently fail -- localStorage is still source of truth
  }
}

export function useProgressSync() {
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
  const lastSyncedCoins = useRef<number>(-1);

  // 1. Load progress from backend on mount (registered users only)
  useEffect(() => {
    if (isGuest()) return;
    const token = getAuthToken();
    if (!token) return;

    fetchProgress(token).then((progress) => {
      if (!progress) return;
      const state = useGameState.getState();
      // Backend is source of truth for registered users
      // Take the max of backend vs localStorage to avoid data loss
      const backendCoins = progress.totalCoins;
      const localCoins = state.totalCoins;
      const resolvedCoins = Math.max(backendCoins, localCoins);

      if (resolvedCoins !== state.totalCoins) {
        useGameState.setState({ totalCoins: resolvedCoins });
        try {
          localStorage.setItem("supermel_total_coins", String(resolvedCoins));
        } catch {}
      }

      // If local had more, push to backend
      if (localCoins > backendCoins) {
        putProgress(token, { totalCoins: localCoins });
      }

      lastSyncedCoins.current = resolvedCoins;
    });
  }, []);

  // 2. Subscribe to state changes and debounce writes
  useEffect(() => {
    if (isGuest()) return;

    const unsubscribe = useGameState.subscribe((state, prevState) => {
      // Only sync when totalCoins changes
      if (state.totalCoins === prevState.totalCoins) return;
      if (state.totalCoins === lastSyncedCoins.current) return;

      const token = getAuthToken();
      if (!token) return;

      // Clear previous debounce timer
      if (timerRef.current) clearTimeout(timerRef.current);

      timerRef.current = setTimeout(() => {
        const current = useGameState.getState();
        lastSyncedCoins.current = current.totalCoins;
        putProgress(token, { totalCoins: current.totalCoins });
      }, DEBOUNCE_MS);
    });

    return () => {
      unsubscribe();
      if (timerRef.current) clearTimeout(timerRef.current);
    };
  }, []);

  // 3. Flush immediately on scene changes (gameover, menu)
  useEffect(() => {
    if (isGuest()) return;

    const unsubscribe = useGameState.subscribe((state, prevState) => {
      if (state.scene === prevState.scene) return;
      if (!PROGRESS_SCENES.includes(state.scene)) return;

      const token = getAuthToken();
      if (!token) return;

      // Flush immediately
      if (timerRef.current) {
        clearTimeout(timerRef.current);
        timerRef.current = null;
      }

      const current = useGameState.getState();
      if (current.totalCoins !== lastSyncedCoins.current) {
        lastSyncedCoins.current = current.totalCoins;
        putProgress(token, { totalCoins: current.totalCoins });
      }
    });

    return () => unsubscribe();
  }, []);
}
```

## Acceptance Criteria

- [ ] `useProgressSync.ts` criado em `packages/frontend/src/game/hooks/`
- [ ] Hook chamado em Game3D.tsx
- [ ] Ao montar (usuario registrado): GET /api/progress e carregado no Zustand
- [ ] Conflict resolution: Math.max(backend, localStorage) para totalCoins
- [ ] Se local > backend, push to backend (reconciliacao)
- [ ] Zustand subscribe ativo: mudancas em totalCoins disparam debounce 2s
- [ ] Scene change para gameover/menu: flush imediato (cancela debounce)
- [ ] Guest: nenhuma chamada de rede, hook e no-op
- [ ] Cleanup: unsubscribe e clearTimeout nos effects
- [ ] Erros de rede nao crasham o jogo (catch silencioso)

## Testing

Validacao manual:
1. Login como usuario registrado
2. Coletar moedas no jogo
3. Esperar 2s -- verificar no backend (curl) que totalCoins atualizou
4. Morrer (gameover) -- verificar flush imediato
5. Recarregar pagina -- totalCoins carregado do backend

## Test Scenarios

- Happy path: login -> play -> collect coins -> debounce fires -> backend updated
- Flush on gameover: coins collected -> die -> immediate PUT before overlay
- Guest mode: no fetch, no PUT, localStorage-only
- Offline registered: fetch fails silently, localStorage continues working
- Conflict: localStorage=50, backend=30 -> resolves to 50, pushes 50 to backend
- Rapid coin collection: 10 coins in 1s -> only 1 PUT after 2s debounce
- Tab close during debounce: at most 2s of progress lost (acceptable)
