## User Story

As a developer, I need a Progress table in the database so that player progress (coins, levels cleared, achievements) can be stored server-side.

## Objective

Adicionar o modelo `Progress` ao schema Prisma com relacao 1:1 com Player. Gerar e aplicar a migration.

## Dev Notes

- Arquivo: `packages/backend/prisma/schema.prisma`
- Adicionar modelo Progress e relacao no Player
- Executar `npx prisma migrate dev --name add_progress_model`
- Verificar que `npx prisma generate` roda sem erros

### Modelo Progress

```prisma
model Progress {
  id         String   @id @default(uuid()) @db.Uuid
  playerId   String   @unique @map("player_id") @db.Uuid
  totalCoins Int      @default(0) @map("total_coins")
  data       Json     @default("{}")
  updatedAt  DateTime @updatedAt @map("updated_at")

  player Player @relation(fields: [playerId], references: [id])

  @@map("progress")
}
```
