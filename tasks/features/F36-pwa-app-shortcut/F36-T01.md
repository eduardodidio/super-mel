# Task F36-T01 -- Web App Manifest + PWA Icons

**Feature:** F36
**Wave:** 0
**Type:** frontend (static assets)
**Depends on:** (none)
**Status:** planned

## User Story

As a mobile player, I want the game to declare itself as an installable web app with proper icons so that when I add it to my home screen, it looks like a real app with the Mel portrait as the icon.

## Objective

Create the `manifest.json` Web App Manifest and generate PWA-compliant icons (192x192, 512x512, maskable) from the existing `ui_portrait.png` sprite.

## Dev Notes

### 1. Create `packages/frontend/public/manifest.json`

```json
{
  "name": "Super Mel",
  "short_name": "Super Mel",
  "description": "A Yorkshire Micro Heroina e sua Bola do Infinito",
  "start_url": "/",
  "display": "standalone",
  "orientation": "landscape",
  "theme_color": "#1a1a2e",
  "background_color": "#1a1a2e",
  "icons": [
    {
      "src": "/icons/icon-192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/icons/icon-maskable-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "maskable"
    }
  ],
  "categories": ["games", "entertainment"]
}
```

### 2. Create PWA Icons

Source image: `packages/frontend/public/sprites/mel/ui_portrait.png` (128x128 pixel art sprite of Mel).

Create directory `packages/frontend/public/icons/` with:

- **icon-192.png** (192x192): Resize ui_portrait.png to 192x192. Use nearest-neighbor scaling to preserve pixel art crispness. Add a small padding (e.g., 16px) with `#1a1a2e` background if desired.

- **icon-512.png** (512x512): Resize ui_portrait.png to 512x512. Same nearest-neighbor approach. Can center the 128px sprite at 4x scale (=512px) which maps perfectly.

- **icon-maskable-512.png** (512x512): Same as icon-512.png but with extra safe-zone padding. Maskable icons need the important content within the center 80% circle. Place the Mel sprite (scaled to ~360x360) centered on a 512x512 `#1a1a2e` background.

**Icon generation approach** (pick one):
- Option A: Use an online tool (realfavicongenerator.net) to generate from ui_portrait.png
- Option B: Use ImageMagick if available: `convert ui_portrait.png -filter Point -resize 512x512 icon-512.png`
- Option C: Use a simple canvas-based Node script
- Option D: Manually create in any image editor

The icons must be committed as actual PNG files, not placeholders.

### 3. Manifest Validation

After creation, validate:
- JSON is valid (no trailing commas, correct syntax)
- All icon paths resolve to actual files
- `start_url` is `/` (matches the SPA rewrite on Render)
- `display: "standalone"` removes browser chrome
- `orientation: "landscape"` matches the game's landscape layout

## Testing

- Verify all fields appear correctly
