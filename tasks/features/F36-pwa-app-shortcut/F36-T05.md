# Task F36-T05 -- PWA Install Prompt Hook + Menu Button

**Feature:** F36
**Wave:** 1
**Type:** frontend (React hook + UI)
**Depends on:** T01 (manifest.json exists), T03 (index.html has manifest link)

## User Story

As a mobile player on the menu screen, I want to see an "INSTALAR APP" button so that I can add Super Mel to my home screen with one tap, without having to find the option in the browser menu.

## Objective

1. Create a custom React hook `usePWAInstall` that captures the browser's `beforeinstallprompt` event and provides a function to trigger the native install prompt.
2. Add an "INSTALAR APP" button to the menu in `Game3D.tsx` that only appears when the install prompt is available.

## Dev Notes

### 1. Create `packages/frontend/src/hooks/usePWAInstall.ts`

```typescript
import { useState, useEffect, useCallback } from "react";

interface BeforeInstallPromptEvent extends Event {
  readonly platforms: string[];
  readonly userChoice: Promise<{ outcome: "accepted" | "dismissed"; platform: string }>;
  prompt(): Promise<void>;
}

/**
 * Hook that captures the browser's beforeinstallprompt event
 * and provides a way to trigger the native PWA install dialog.
 *
 * Returns:
 * - canInstall: true when the install prompt is available
 * - triggerInstall: function that shows the native install dialog
 * - isInstalled: true when running as a standalone PWA
 */
export function usePWAInstall() {
  const [deferredPrompt, setDeferredPrompt] = useState<BeforeInstallPromptEvent | null>(null);
  const [isInstalled, setIsInstalled] = useState(false);

  useEffect(() => {
    // Check if already running as installed PWA
    const isStandalone =
      window.matchMedia("(display-mode: standalone)").matches ||
      (navigator as any).standalone === true;

    if (isStandalone) {
      setIsInstalled(true);
      return;
    }

    const handler = (e: Event) => {
      // Prevent the mini-infobar from appearing on mobile
      e.preventDefault();
      setDeferredPrompt(e as BeforeInstallPromptEvent);
    };

    window.addEventListener("beforeinstallprompt", handler);

    // Listen for successful install
    window.addEventListener("appinstalled", () => {
      setDeferredPrompt(null);
      setIsInstalled(true);
      console.log("[PWA] App installed successfully");
    });

    return () => {
      window.removeEventListener("beforeinstallprompt", handler);
    };
  }, []);

  const triggerInstall = useCallback(async () => {
    if (!deferredPrompt) return;

    await deferredPrompt.prompt();
    const choiceResult = await deferredPrompt.userChoice;

    if (choiceResult.outcome === "accepted") {
      console.log("[PWA] Install accepted");
    } else {
      console.log("[PWA] Install dismissed");
    }

    // The prompt can only be used once
    setDeferredPrompt(null);
  }, [deferredPrompt]);

  return {
    canInstall: deferredPrompt !== null,
    triggerInstall,
    isInstalled,
  };
}
```

### 2. Modify `packages/frontend/src/game/Game3D.tsx`

Add the install button to the menu overlay. Changes:

**Import the hook:**
```tsx
import { usePWAInstall } from "../hooks/usePWAInstall";
```

**Inside `Game3D()` function, add hook call:**
```tsx
const { canInstall, triggerInstall, isInstalled } = usePWAInstall();
```

**In the menu overlay JSX (inside `buttonGroup` div), add after the SAIR button:**
```tsx
{canInstall && (
  <button style={styles.btnInstall} onClick={triggerInstall}>
    INSTALAR APP
  </button>

{isInstalled && (
  <p style={{ color: "#4a8a4a", fontSize: "12px", textAlign: "center", fontFamily: "monospace" }}>
```

### 3. Button Placement Strategy

The "INSTALAR APP" button should appear:
- Only when `canInstall` is true (browser supports install AND app is not already installed)
- In the menu overlay, visually prominent but after the primary game actions
- Suggested order: JOGAR > FASE TESTE > CRIAR FASE > RANKING > TEMA > INSTALAR APP > SAIR

When `isInstalled` is true (user is running as PWA), show a subtle "App instalado!" text instead.

### 4. Browser Compatibility Notes

- **Chrome (Android/Desktop):** Full `beforeinstallprompt` support. Button will appear.
- **Firefox:** Does not fire `beforeinstallprompt`. Button won't appear. Users can still manually install via browser menu.
- **Safari (iOS):** Does not fire `beforeinstallprompt`. Button won't appear. Users must use Share > Add to Home Screen. The `apple-mobile-web-app-capable` meta tag (from T03) ensures standalone behavior.
- **Samsung Internet:** Supports `beforeinstallprompt`. Button will appear.

The hook handles all cases gracefully -- when `beforeinstallprompt` doesn't fire, `canInstall` stays `false` and the button never shows.

### 5. TypeScript Considerations

The `BeforeInstallPromptEvent` interface is not in TypeScript's standard lib types. We define it locally in the hook file. Alternatively, it could go in a `types/pwa.d.ts` declaration file, but inline is simpler for a single usage.
