# Task F36-T03 -- index.html PWA Meta Tags

**Feature:** F36
**Wave:** 0
**Type:** frontend (HTML)
**Depends on:** (none)
**Status:** planned

## User Story

As a mobile player, I want the browser to recognize Super Mel as an installable PWA so that the install banner appears and the app looks correct when launched from the home screen.

## Objective

Add PWA-required meta tags and the manifest link to `packages/frontend/index.html`. This includes:
- `<link rel="manifest">`
- `<meta name="theme-color">`
- Apple-specific meta tags for iOS Safari (which doesn't fully support manifest.json)
- Apple touch icon link

## Dev Notes

### Modify `packages/frontend/index.html`

Add the following inside `<head>`, after the existing viewport meta tag:

```html
<!-- PWA Manifest -->
<link rel="manifest" href="/manifest.json" />

<!-- Theme color (status bar on Android, tab color on desktop) -->
<meta name="theme-color" content="#1a1a2e" />

<!-- iOS Safari PWA support -->
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
<meta name="apple-mobile-web-app-title" content="Super Mel" />
<link rel="apple-touch-icon" href="/icons/icon-192.png" />

<!-- Windows tile -->
<meta name="msapplication-TileColor" content="#1a1a2e" />
```

```html
  </body>

```

### Design Notes

1. **`apple-mobile-web-app-capable`**: iOS Safari does not read `display: "standalone"` from manifest.json. This meta tag is required for iOS PWA behavior (full-screen, no Safari chrome).

2. **`apple-mobile-web-app-status-bar-style`**: `black-translucent` makes the status bar transparent with white text, blending with the dark game background.

3. **`apple-touch-icon`**: iOS uses this for the home screen icon instead of manifest icons. We point to the 192x192 icon (iOS will downscale as needed).

4. **theme-color**: `#1a1a2e` matches the body background and the game's dark theme. This colors the Android status bar and Chrome tab.

5. **No `<noscript>` tag needed**: The entire game requires JavaScript. No benefit in adding a noscript fallback.
