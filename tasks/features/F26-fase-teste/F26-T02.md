# Task F26-T02 — Test Level Renderer Integration

**Feature:** F26
**Wave:** 1
**Type:** frontend
**Depends on:** F26-T01
**Status:** planned

## User Story

As a player, I want the test level to load and render with all blocks, coins, and hearts visible, so that I can play through the designed test course.

## Objective

Modify ChunkRenderer to accept an optional pre-built chunk array (from TestLevelData) instead of always generating procedural chunks. When in test mode, render the fixed level.

## Dev Notes

### File: `packages/frontend/src/game/systems/ChunkRenderer.tsx`

- Add optional prop: `testChunks?: Chunk[]`
- When `testChunks` is provided:
  - Skip the `useFrame` procedural chunk generation entirely
  - Initialize `chunks` state directly from `testChunks` on mount (via useState initializer or useEffect)
  - Still support block destruction, heart/coin collection (same logic)
  - `getVisibleChunkIndices` still works for culling — only render chunks near player
- When `testChunks` is undefined: existing behavior (procedural generation)

### File: `packages/frontend/src/game/scenes/GameScene3D.tsx`

- Accept optional prop: `testMode?: boolean`
- When `testMode`:
  - Import and call `generateTestLevel()` once (useMemo)
  - Pass result as `testChunks` to ChunkRenderer
- Mel spawn position: same (2, 5, 0) — works for test level too

## Testing

- Manual: load test level -> verify all 5 chunks render with correct blocks
- Manual: walk through level -> verify coins collectible, hearts collectible, blocks destructible
- Manual: verify procedural mode still works (normal game)

## Implementation details

- File 1: `packages/frontend/src/game/systems/ChunkRenderer.tsx`
  - Add `testChunks?` to ChunkRendererProps
  - Conditional in useFrame: skip generation if testChunks provided
  - Initialize from testChunks in useState
- File 2: `packages/frontend/src/game/scenes/GameScene3D.tsx`
  - Add `testMode?` prop
  - useMemo to generate test level data
  - Pass to ChunkRenderer
