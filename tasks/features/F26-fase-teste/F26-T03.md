# Task F26-T03 — Game State: Test Mode Flag

**Feature:** F26
**Wave:** 1
**Type:** frontend
**Depends on:** F26-T01
**Status:** planned

## User Story

As a player, I want to select "FASE TESTE" from the menu, so that I can enter the test level and return to the menu when done.

## Objective

Add a `testMode` flag to the game state store and a "FASE TESTE" button to the menu. Wire the flag through to GameScene3D.

## Dev Notes

### File: `packages/frontend/src/game/hooks/useGameState.ts`

- Add to GameState interface: `testMode: boolean`
- Add action: `setTestMode: (testMode: boolean) => void`
- Default: `testMode: false`
- Update `resetGame`: add optional param or create `startTestMode()`:
  ```ts
  startTestMode: () => set({ score: 0, lives: 3, coins: 0, scene: "playing", paused: false, testMode: true }),
  resetGame: () => set({ score: 0, lives: 3, coins: 0, scene: "playing", paused: false, testMode: false }),
  ```

### File: `packages/frontend/src/game/Game3D.tsx`

- Read `testMode` from useGameState
- Pass to SceneContent or directly: when scene="playing", pass `testMode` to GameScene3D
- Add "FASE TESTE" button in menu overlay (between JOGAR and CRIAR FASE):
  ```tsx
  <button style={styles.btn} onClick={() => startTestMode()}>
    FASE TESTE
  </button>
  ```
- Style: same as JOGAR button but with different color (e.g., blue `#4a4a8a`)

### File: `packages/frontend/src/game/scenes/GameScene3D.tsx`

- Read `testMode` from useGameState (or accept as prop)
- Pass `testMode` to ChunkRenderer as described in F26-T02

## Testing

- Manual: click "FASE TESTE" -> enters playing scene with test level
- Manual: click "JOGAR" -> enters playing scene with procedural level (testMode=false)
- Manual: game over in test mode -> returns to menu, testMode resets

## Implementation details

- File 1: `packages/frontend/src/game/hooks/useGameState.ts` — add testMode + startTestMode
- File 2: `packages/frontend/src/game/Game3D.tsx` — add menu button + wire testMode
- File 3: `packages/frontend/src/game/scenes/GameScene3D.tsx` — read testMode, pass to ChunkRenderer

## Acceptance criteria

- [ ] "FASE TESTE" button visible in main menu
- [ ] Clicking it starts game in test mode (testMode=true)
- [ ] "JOGAR" starts game in normal mode (testMode=false)
- [ ] testMode flag resets on game over
- [ ] GameScene3D passes testMode to ChunkRenderer correctly

## Test scenarios

- **Happy path:** Click FASE TESTE -> test level loads
- **Happy path:** Click JOGAR -> procedural level loads (no test chunks)
- **Edge case:** Die in test mode -> game over screen -> back to menu -> testMode=false
