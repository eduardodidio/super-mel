# Task F27-T02 — Fix Sprite Loading Errors & Deprecation Warnings

**Feature:** F27
**Wave:** 1
**Type:** frontend
**Depends on:** F27-T01
**Status:** planned

## User Story

As a player, I want the game to load without console errors, so that the browser isn't wasting resources on error handling and the game runs smoothly.

## Objective

Eliminate all sprite-related console warnings and 404 errors. Remove deprecated SpriteAnimator functions if unused. Ensure all referenced sprites exist or gracefully handle missing ones without console spam.

## Dev Notes

### File: `packages/frontend/src/game/systems/SpriteAnimator.ts`

**Problem 1: Missing sprite .png files**
- ANIMATIONS references frame names like `walk_right`, `run_right_b`, etc.
- If the corresponding .png files don't exist in `public/sprites/mel/`, every load attempt = console.warn + 404
- **Fix options:**
  a. Verify which .png files actually exist in `public/sprites/mel/` and update ANIMATIONS to only reference existing files
  b. For missing sprites, map them to existing ones in the ANIMATIONS definition (e.g., if `run_right_b` doesn't exist, use `run_right`)
  c. Reduce console.warn to a single summary warning instead of per-sprite

**Problem 2: Deprecated functions**
- `loadSpritesheet()` and `updateSpriteUV()` at lines 346-370 log warnings
- Check if any code still imports/calls them
- If nothing calls them: DELETE the functions entirely (per CLAUDE.md: "avoid backwards-compatibility hacks")
- If Mel.tsx still calls them: it shouldn't — Mel.tsx already uses `loadSprites()` + `getFrame()` (lines 64-67, 185-191)

**Problem 3: Error callback in loadTexture()**
- The error callback at line 144 tries to copy `fallback.image` to the failed texture — this can cause issues if fallback isn't loaded yet
- **Fix:** Instead of patching the failed texture, just return the fallback texture directly from `getFrame()` when the sprite isn't in cache

### Actions:
1. List actual files in `public/sprites/mel/`
2. Update ANIMATIONS frames to match existing files
3. Remove deprecated functions (`loadSpritesheet`, `updateSpriteUV`)
4. Clean up error handling: silent fallback (no console.warn spam), single init-time log if sprites missing
5. Remove `loadTexture()` error callback image-copy hack
