## User Story

As a player, I want the coins to be red instead of gold, so that they match the game's updated visual identity.

## Objective

Trocar todas as referencias de cor dourada (#FFD700, #FFA500) para uma paleta vermelha nas moedas (Coin entity).

## Dev Notes

### Paleta vermelha sugerida
- **Base color:** `#DC143C` (crimson red)
- **Emissive:** `#FF4444` (bright red glow)
- **Metalness:** manter 0.8
- **Roughness:** manter 0.3

### Arquivos a modificar

### Arquivos que NAO devem mudar
