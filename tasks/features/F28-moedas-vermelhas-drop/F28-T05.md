## User Story

As a player, I want the coin drop system fully connected in the game scene and the test level to include item_blocks with hidden coins, so that I can experience the complete feature.

## Objective

Conectar todos os componentes (CoinDropManager, item_block activation, ProjectileManager callbacks) na GameScene3D e adicionar item_blocks com moedas escondidas no TestLevelData.

## Dev Notes

### Wiring em GameScene3D.tsx

1. **Importar e instanciar CoinDropManager**
   - Adicionar state para dropped coins: `useState<DroppedCoinData[]>([])`
   - Renderizar `<CoinDropManager>` component no scene

2. **Conectar ProjectileManager → CoinDropManager**
   - Passar `onBlockHit` prop ao ProjectileManager (line 81-85 em GameScene3D)
   - onBlockHit recebe blockName + coords → decide se dropa moedas
   - Para blocos destrutiveis: chance de drop (via CoinDropManager)
   - Para item_blocks: ativar bloco + liberar moedas escondidas

3. **Conectar ChunkRenderer → onBlockDestroyed**
   - Passar callback que chama CoinDropManager.spawnDrop(x, y)

4. **Conectar dropped coins → addCoin**
   - Quando DroppedCoin e coletada → chamar addCoin() do useGameState

### TestLevelData.ts — Adicionar item_blocks

Adicionar item_blocks estrategicamente no nivel teste:
- **Chunk 0** (tutorial): 1 item_block visivel acima do caminho (ensinar mecanica)
- **Chunk 1** (gaps): 2 item_blocks sobre gaps (recompensa por explorar)
- **Chunk 2** (parede): 1 item_block escondido atras da parede de madeira
- **Chunk 3** (plataformas): 3 item_blocks em plataformas elevadas
