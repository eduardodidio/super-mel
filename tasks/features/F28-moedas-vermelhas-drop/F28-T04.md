# F28-T04 — item_blocks com Moedas Escondidas

**Wave:** 1
**Type:** frontend
**Depends on:** F28-T02
**Status:** done

## User Story

As a player, I want item_blocks (the blocks with "?") to release hidden coins when I hit them with my attack, so that I have incentive to explore and interact with special blocks.

## Objective

Dar funcao especial aos item_blocks: ao serem atingidos pelo ataque da Mel, liberam 1-3 moedas escondidas. O bloco muda de aparencia apos ser ativado (fica "vazio"/escuro).

## Dev Notes

### Estado atual dos item_blocks
- Definidos em `packages/shared/src/types.ts` line 91: `{ solid: true, destructible: true, dangerous: false, platform: false }`
- Visual em `BlockTextures3D.ts`: bloco com "?" no centro
- Spawnam em plataformas (30% chance) via `ChunkGenerator.ts` lines 117-122
- Atualmente se comportam como blocos destrutiveis comuns — sem funcao especial

### Solucao

1. **Mudar item_block para "ativavel" em vez de "destruivel"**
   - Em `types.ts`: adicionar campo opcional `activatable?: boolean` ao BlockProperties
   - item_block: `{ solid: true, destructible: false, activatable: true, dangerous: false, platform: false }`
   - Bloco nao e destruido, apenas ativado (muda visual, libera moedas)

2. **Criar estado "activated" para item_blocks** em `BlockTextures3D.ts`
   - Nova textura: bloco escuro/cinza sem "?" (ja foi usado)
   - `item_block_empty: { color: "#666666", emissive: "#333333", emissiveIntensity: 0.1 }`

3. **Logica de ativacao** no `Block.tsx` (ou componente de bloco equivalente)
   - Quando projetil atinge item_block:
     - Nao destruir o bloco
     - Marcar como "activated" (mudar textura para item_block_empty)
     - Emitir callback `onItemBlockActivated(x, y, coinsToRelease)`
   - coinsToRelease: 1-3 moedas (random)

4. **Spawn de moedas** via `CoinDropManager` (criado em T03)
   - Moedas saem do topo do bloco (y + 1)
   - Velocidade pra cima mais forte que drop normal (pop visivel)
   - Cada item_block so pode ser ativado UMA VEZ

5. **Metadata no ChunkGenerator**
   - Cada item_block gerado recebe `hiddenCoins: number` (1-3, random)
   - Guardar no chunk data para saber quantas moedas liberar

### Constantes sugeridas
```typescript
const ITEM_BLOCK_MIN_COINS = 1;
const ITEM_BLOCK_MAX_COINS = 3;
const ITEM_BLOCK_POP_VELOCITY = 8; // mais forte que drop normal
```

### Padrao de referencia
- Seguir mecanica classica do Mario: bloco "?" libera item ao ser atingido por baixo/ataque
- Visual: bloco muda de vermelho com "?" para cinza escuro sem "?"

## Acceptance Criteria

- [ ] item_blocks nao sao destruidos ao serem atingidos (mudam de visual)
- [ ] item_blocks liberam 1-3 moedas ao primeiro hit
- [ ] item_blocks so podem ser ativados uma vez (segundo hit nao faz nada)
- [ ] Visual muda para bloco cinza/vazio apos ativacao
- [ ] Moedas saem do topo do bloco com animacao de "pop"
- [ ] Moedas liberadas sao coletaveis e contam no counter
- [ ] Gerador procedural marca item_blocks com hiddenCoins metadata
- [ ] Sem regressao: outros blocos destrutiveis continuam quebrando normalmente

## Testing

Validacao manual: atingir item_block com Bola do Infinito → moedas saem.

## Test Scenarios

- Happy path: atingir item_block → moedas saem do topo, bloco fica cinza
- Happy path: coletar moedas liberadas → counter incrementa
- Edge case: atingir item_block ja ativado → nada acontece
- Edge case: atingir item_block com Mel (colisao corpo) → nada (so ataque)
- Regressao: blocos de madeira/vidro continuam sendo destruidos normalmente
- Boundary: 10+ item_blocks em sequencia → todos funcionam independentemente
