# F28-T03 — Sistema de Drop de Moedas ao Quebrar Blocos

**Wave:** 1
**Type:** frontend
**Depends on:** F28-T01
**Status:** done

## User Story

As a player, I want coins to sometimes drop when I break blocks with my attack, so that there's an extra reward for exploring and destroying the environment.

## Objective

Implementar sistema de drop de moedas quando blocos destrutiveis sao quebrados pelo ataque da Mel. Conectar o callback onBlockDestroyed que ja existe (mas nunca e chamado) ao sistema de spawn de moedas.

## Dev Notes

### Problema atual
- `ChunkRenderer.tsx` line 10: `onBlockDestroyed?: (x: number, y: number) => void` — prop existe mas NUNCA e passada/chamada
- `ProjectileManager.tsx` line 10: `onBlockHit?: (blockName: string) => void` — prop existe mas NAO conectada em GameScene3D (lines 81-85)
- Quando projetil destroi bloco, particulas aparecem mas nenhum callback dispara

### Solucao

1. **Criar `DroppedCoin` component** — moeda que spawna no ar e cai com gravidade leve, coletavel
   - Reutilizar visual do `Coin.tsx` (ja vermelho apos T01)
   - RigidBody dynamic com gravidade reduzida (gravityScale 0.5)
   - Sensor para colisao com player
   - Auto-destroy apos 8s se nao coletada (cleanup)
   - Animacao: "pop" pra cima + cai

2. **Criar `CoinDropManager`** em `packages/frontend/src/game/systems/CoinDropManager.tsx`
   - Recebe coordenadas (x, y) do bloco destruido
   - Decide quantas moedas dropar (0-2, chance 40% de dropar pelo menos 1)
   - Spawna `DroppedCoin` components nas coordenadas com velocidade inicial pra cima e leve random X
   - Mantém pool limitado (MAX_DROPPED_COINS = 20) para performance

3. **Conectar pipeline de destruicao** em `GameScene3D.tsx`:
   - Passar `onBlockHit` ao ProjectileManager
   - onBlockHit → obter coords do bloco → CoinDropManager.spawn(x, y)

### Constantes sugeridas

## Acceptance Criteria

- [ ] Callback onBlockDestroyed e chamado quando projetil destroi bloco
- [ ] Moedas dropam do local do bloco destruido (40% chance)
- [ ] Moedas dropadas fazem "pop" pra cima e caem com gravidade
- [ ] Moedas dropadas sao coletaveis pela Mel (sensor)
- [ ] Moedas dropadas coletadas incrementam coin counter (addCoin)
- [ ] Moedas dropadas despawnam apos 8s se nao coletadas
- [ ] Pool limitado a 20 moedas dropadas simultaneas
- [ ] Sem frame drops ao dropar muitas moedas

Validacao manual: destruir blocos e verificar drops.

## Test Scenarios

- Happy path: destruir bloco de madeira → moeda dropa e e coletavel
- Happy path: destruir bloco de vidro → moeda dropa
- Edge case: destruir 50+ blocos rapido → pool nao excede 20, sem crash
- Edge case: moeda dropa mas Mel nao coleta → despawna apos 8s
- Regressao: moedas normais (estaticas) continuam funcionando
- Regressao: hearts continuam funcionando
- Boundary: blocos nao-destrutiveis (pedra, ferro) NAO dropam moedas
